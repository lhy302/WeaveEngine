====================================================================
封装游戏 · 定向测试说明 (2026-08-22)
====================================================================
目标: 用【exe 版引擎】制作/封装游戏的标准链路验证:
  游戏材料(场景/脚本) → build_game.exe → 发布夹 = MyGame.exe + 游戏包.lsc
  (场景/脚本/配置混淆加密, 无明文; 玩家 exe 不含编辑器)

材料清单 (本目录):
  跳台试炼场景_明文.json   开发者明文场景 (Loom.exe 里做的, 未加密)
  scripts\reset_fall.py    游戏脚本 (跌出世界自动回出生点; 演示"脚本进包")
  以下工具在 Loom(编译版本)\Loom\ 下:
    Loom.exe               编辑器 (用于 Loom.exe 制作游戏的路线; 测试封装
                           可只用下面命令行工具)
    build_game.exe         构建器 (命令行列)
    player_runtime\       玩家运行时 (MyGame.exe + 运行库)

标准测试步骤 (建议顺序):
  1. 命令行发布 (Build):
     cd Loom(编译版本)\Loom
     build_game.exe --name 跳台试炼 --company "DSH实验室" ^
         --scene 封装测试材料\跳台试炼场景_明文.json ^
         --game-scripts 封装测试材料\scripts ^
         --output D:\游戏发布测试\跳台试炼
     预期日志: [1/4] 场景已读入 → [2/4] 游戏脚本: 1 个 → [4/4] 运行时已拷入
     → 构建完成 (含 MyGame.exe + 游戏包.lsc)。

  2. 发布夹检查 (防窥 验证):
     - 应只有 MyGame.exe + 游戏包.lsc (无 .py / 无 .json 明文);
     - 打开 游戏包.lsc 看到 LOOMSC1 混淆文本 (不是 JSON)。

  3. 玩家游玩:
     双击 发布夹\MyGame.exe → WASD 走 / 鼠标转视角 / 空格跳 (8 秒以上)。
     看两点: ① 碰到金球右上角计数 (内置脚本运行);
     ② 从平台走过落下超出世界 (跌出重置 脚本) → 玩家自动回起点
     (游戏脚本也在包里运行 = 脚本加密链路 ✓); 窗口标题 = 游戏名。

  4. 不可分离验证 (Unity _Data 语义):
     把 游戏包.lsc 改名 → 双击 MyGame.exe → 应立即报错提示
     "缺少游戏包…" (而不是黑屏/闪退)。

  5. Loom.exe 编辑器一键发布 (可选):
     打开 Loom.exe → 载入 跳台试炼场景_明文.json → [发布游戏] 按钮 →
     填游戏名/输出目录 → [构建] → 完成后自动打开 发布夹。
     (需要 Loom.exe 同目录有 build_game.exe + player_runtime\)

预期结果 = 以上全通过。
开发者脚本放哪: <引擎目录>\scripts\ 目录 (引擎启动自动加载, 检查器可挂);
  发布时被构建器收集加密打包进 游戏包.lsc。
