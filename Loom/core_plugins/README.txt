【核心插件 · 信任须知】(2026-08-27)
====================================================================
核心插件 = 替换/接管引擎核心部件 (渲染/物理/输入/界面等), 拥有引擎
全部权限 (等同引擎本体: 可读写任意文件/联网/启动进程)。

【目录结构 (按可替换功能分类)】
  core_plugins/<类别>/<插件目录>/
      plugin.json
      entry.py      def register(api): ...
      其它文件

【plugin.json 核心清单 (比普通插件更严, 缺失拒绝加载)】
  {"id": "com.dsh.my_core", "name": "...", "version": "1.0.0",
   "entry": "entry.py",
   "layer": "player" | "editor",     ← 必须显式声明注入哪一层!
   "capability": "render",           ← 替换哪个功能 (render/physics/input/...)
   "desc": "用途说明 (信任确认框展示)"}

【安装 = 信任确认 + 重启生效 (安全边界 = 人工把关)】
  1. 把插件目录放进 core_plugins\<类别>\ 后, 启动 Loom 会弹信任确认框:
     红字警告 "核心插件拥有引擎全部权限, 插件来源必须可信, 建议安装前
     阅读插件源码", 并列出 id/用途/来源目录;
  2. [确认信任] -> 全文件 SHA256 写入 插件信任.json -> 提示重启 -> 重启
     后加载生效; [本会话不加载] = 跳过不加载;
  3. 每次启动校验指纹: 插件被改过 (文件哈希变化) -> 拒绝加载 + 重新弹窗
     确认 (防"装完被偷换");
  4. 未信任/损坏的核心插件 = 不加载 + 回退官方, 不拖垮引擎;
  5. 想拔掉: 删插件目录 (信任记录应同步删除; 忘记删记录会提示失效)。

【与普通插件的区别】
  普通插件 (plugins/editor|player) = 受限环境、放进即装、不用确认;
  核心插件 = 全权、必须人工确认+重启。选哪条路: 只"加功能"用小件,
  "替换引擎"用大件且承担全程信任责任。

【⚠ 信任边界】此目录 = 全权限任意代码。只放你百分百信任的插件
(来源可靠 + 看过源码)。任何人能向你此目录投放文件 = 拿到你整台电脑。
