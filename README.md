# WeaveEngine

> **把创意织成可玩的梦。**

WeaveEngine 是一个 **Python 基座 + C 核心组件** 的轻量级 3D 游戏引擎，
自带编辑器、运行时与脚本系统，面向 **小游戏 / 原型 / 教学** 场景。

引擎核心采用 C ABI 动态库实现（数值内核、管线、脚本、物理），
Python 侧保留编辑器与业务逻辑的开发效率，兼顾**性能**与**上手速度**。

---

## 特性

**编辑器**
- 层级面板 / 属性检查器 / 视口 / 工具栏
- 场景序列化、撤销重做、运行时一键播放
- 配套启动器 **LoomHub**，支持多项目托管

**渲染**
- 基于 PBR 的光照与材质系统
- 法线贴图 / LOD / 天空盒 / 纹理压缩
- 视锥剔除、实例化批绘制、阴影管理

**脚本**
- 内嵌 **Lua 5.4.6**，脚本侧无 Python 依赖，C 层高速执行
- 覆盖生命周期、碰撞事件等常用钩子
- 官方示例脚本开箱即用

**物理**
- 支持刚体、碰撞检测、重力与摩擦
- 逻辑帧与渲染帧解耦，物理以固定子步稳定推进

**自动化**
- 内置 **MCP 协议**服务，可被 Claude / Cursor 等大模型工具驱动
- 本地命令服务器（EAI），支持脚本化操作编辑器

## 快速开始

**环境要求**
- Windows 10/11 x64
- Python 3.12

**安装依赖**

```bash
py -3.12 -m pip install -r requirements.txt
```

**启动编辑器**

```bash
cd Loom
py -3.12 Loom.py
```

**通过 LoomHub 启动（多项目托管）**

```bash
cd LoomHub
py -3.12 LoomHub.py
```

**接入大模型工具（MCP）**

```bash
cd Loom
py -3.12 Loom.py --agent
# 然后在 Claude Desktop / Cursor 中配置 loom_mcp.py
```
