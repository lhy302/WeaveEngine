〇、概念对照 (Unity -> Loom)
====================================================================
  Unity 场景 .unity        -> Loom 场景文件 .json (明文 / 保存时可用加密版 LOOMSC)
  GameObject               -> 物体 (层级面板里的立方体/球体/平面/导入 obj)
  Transform                -> 检查器 位置/旋转(度)/缩放 (数字输入或拖拽块/视口 gizmo)
  Material                 -> 材质资产 (检查器 材质区, 共享引用, 资源面板可拖)
  Light                    -> 层级面板 "— 光源 —" 区 (平行光=太阳 / 点光源=灯泡)
  Camera                   -> "— 摄像机 —" 区 (active_camera = 玩家视角)
  Rigidbody                -> 检查器 刚体 (受重力/不受重力)
  Collider                 -> 检查器 碰撞体 (启用/禁用; 形状自动派生)
  MonoBehaviour 脚本        -> 内置脚本 (脚本区下拉) + 自定义 scripts.py @register
  Input Manager / Actions  -> 输入动作层 ('向前'/'跳跃' 绑键, 输入配置.json 改键)
  uGUI / 画布               -> 运行时 UI (脚本 e.ui.text/button/bar, M33)
  Preview / Play Mode      -> 编辑器 [→播放] / [■停止] (所见即所得)
  Build Settings -> Build   -> [发布游戏]/build_game.exe: 纯玩家 exe + 游戏包.lsc (加密)
  *.prefab                 -> 资源面板 Prefab (选中物体, 工具栏 [存模板] 存成模板/
                            [放实例] 放进场景)

一、启动
====================================================================
  编辑器:  cd D:\my-project\Loom(py源代码)\Loom ; py Loom.py
           (或 LoomHub 里"新建项目/打开项目")
  播放器:  py Loom.py --run 场景.json          (直接跑一个场景, 脚本生效)

====================================================================
二、搭场景 (布置)
====================================================================
1. [新建] 开空场景。
2. 加物体: 顶部工具栏 [立方体][球体][平面] 按钮 —— 点一下出现在场景中心。
3. 摆放物体(三选一):
   a. 检查器 位置/旋转/缩放 数字框 —— 点数字框聚焦, 底部弹出拖拽块:
      按住左右拖动调值 (每像素=该行步长), 松手=一步撤销命令 (Ctrl+Z 撤)。
   b. 视口选中后拖 gizmo 手柄 (工具栏 [移动]/[旋转] 切换模式)。
   c. 层级里拖到另一个物体上 = 挂父 (子随父动, 世界位置自动保持);
      拖到空白 = 脱父; 行上右键 = 重命名/复制/删除/脱父。
4. 加光: 层级面板顶部按钮行 [+ 平行光](太阳)/[+ 点光源](灯泡), 检查器调 强度/颜色/
   方向(朝向/俯仰/倾斜) 与 阴影 [开/关] (默认开, 关 = 光穿墙)。
   ★ 没加光源场景是暗的 (设计如此, 提醒你自己加光)。
5. 材质: 检查器 材质区 [＋新建材质] 或选库中材质; 多物体共享; 资源面板
   可拖到物体上应用; [存材质为资产] 落 assets/。
6. 碰撞体 (M28): 检查器 [启用/禁用] —— 所有可被"挡住/承接"的物体默认启用;
   同一棵父子树互相不碰撞。
7. 刚体 (M31): 检查器 [＋加刚体] (受重力) / [移除刚体]; 想让物体坠落/滑动就加。

小技巧: 复制物体 [复制] 按钮(工具栏)或层级右键菜单; 撤销 Ctrl+Z (100 步);
  F11 在编辑器已禁用(窗口最大化即可), 封装后的游戏里 F11 = 假全屏切换。

====================================================================
三、给物体挂脚本 (行为) —— 内置脚本清单
====================================================================
选中物体 -> 检查器 "脚本" 区 -> 点脚本名挂上 (可挂多个, 参数分行调节):
  脚本名         script_id     作用
  自转          rotate        绕自身轴转 (参数: X/Y/Z速度°)
  公转          orbit         绕中心转圈 (参数: 中心/半径/速度)
  浮动          bob           上下正弦浮动 (参数: 幅度/频率)
  WASD移动      wasd_move     按 WASD 沿世界轴移动 (演示/待机角色)
  相机跟随      camera_follow 相机盯住物体 (参数: 高度偏移/距离)
  重力落地      fall          受重力落 (参数: 重力)
  弹跳          bounce        落地反弹 (参数: 重力/弹性)
  第一人称      first_person  玩家控制器: WASD(沿视角)+鼠标转向+跳跃(需刚体)
                              (参数: 速度/眼高/灵敏度/跳跃速度; Tab=鼠标锁定切换)
  第三人称      third_person  玩家控制器: 同款 + 相机在角色后方跟随
                              (参数: 速度/距离/高度/灵敏度; Tab=鼠标锁定)
  跳跃          jump          按'跳跃'动作向上给速度 (需刚体; 落地才能再跳)
  触碰计数彩球  count_touch   教学示例: 玩家碰到彩球 -> 彩球消失+HUD 计数
                              (参看 第五节"写自定义脚本")

★ 玩家角色标准件: 立方体/球体 + [＋加刚体] + [第一人称](或[第三人称])
  播放后 WASD 走动、鼠标转视角、空格/跳跃键跳 (需跳跃动作, 见第四节)。

====================================================================
四、输入动作层 (Unity Input System 简化)
====================================================================
  动作 = 玩家想做什么 ('向前'/'向后'/'向左'/'向右'/'跳跃'), 默认绑定:
     向前 w/Up, 向后 s/Down, 向左 a/Left, 向右 d/Right, 跳跃 space
  改键: 引擎目录 输入配置.json ({"向前": ["w","Up"], ...}), 缺失/坏文件
  回退默认。脚本恒写动作名, 改键不动脚本。

====================================================================
五、写自定义脚本 (Python 引擎的核心优势, 热加载)
====================================================================
打开 Loom\scripts.py (或插件系统内注册脚本类, 见《Loom插件系统分级方案.txt》), 加一个类:

  from engine import Point3D
  @register
  class MyHudScript(Script):
      script_id = 'my_hud'          # 小写蛇形, 场景序列化用
      name = '我的HUD'              # 检查器显示名
      params = (('n', '文字', 6.0, 0.0, 99.0, '%.0f'),)   # 参数定义(vmin/vmax)

      def on_start(self):           # 播放开始时
          self.v = 0.0              # 不用参数时省略

      def update(self, dt):         # 每帧 (dt 秒)
          e = self.engine           # 引擎句柄
          e.ui.text("你好游戏: %d" % self.v, 20, 60, 24)   # 运行时 HUD
          self.v += 1

  Script 基类 (scripts.py) 必备钩子:
    on_start()  播放开始 (建粒子/初始化)
    update(dt)  每帧 (dt=帧间隔秒)
    self.obj    挂载的物体   self.vals  参数字典   self.engine  引擎
  常用引擎 API (脚本里):
    e.get_action('跳跃') / e.is_key('w') / e.mouse_rel (未锁定时偏移)/ e.pressed
    e.move_with_collision(obj, dx, dy, dz)   带碰撞移动
    e.get_collisions(obj)                    当前重叠物体列表
    e.add_model(...)/remove_model(obj)/e.play_sound(path, vol)/e.ui.text/button/bar
  保存后编辑器脚本下拉立刻出现 (不用重编译)。

六、播放试玩 (Unity Play Mode 对标)
====================================================================
  工具栏 [→播放] -> 脚本开始跑; [■停止] -> 场景还原成编辑样子
  (播放期改动全丢弃)。所见即所得: 摆好->挂脚本->播放->看->停->调->再播放。
  播放时操作: WASD/鼠标视角/转视角后不动鼠标; Tab 解锁/回锁鼠标;
  停止 = 点 [■停止]。

七、相机 (玩家视角)
====================================================================
  层级面板顶部按钮行 [+ 摄像机] 添加; 场景的"激活相机"(选中摄像机->[设为激活相机],
  再点=取消) 决定玩家看到什么 (没有就默认轨道视角)。
  预览: [用此相机预览] (再点/Esc 退出)。
  挂父: 摄像机行拖到物体行 = 随物体走 (如第一人称挂到玩家头上方 ->
  但第一/三人称脚本自带接管视角, 不需要显式摄像机; 挂父做法用于
  想"分镜头/车辆视角"时)。
  参数: yaw/pitch/roll(度, roll=侧头)/FOV/玩家可调/俯仰角限制。

八、封装发布 (Unity Build 对标) —— 2026-08-22 标准链路
====================================================================
整车流程 (标准要求):
  游戏材料(场景/物体/脚本/插件) → Loom.exe 编辑器制作 → [发布游戏]
  → 发布夹 = MyGame.exe(玩家运行时, 无编辑器) + 游戏包.lsc
    (场景+游戏脚本+插件+配置, 加密打包; 与 exe 同夹不可分离)
  → 玩家双击即玩, 无任何明文素材/脚本 (Unity _Data 对齐: 脚本进 Build 无源码)

8.1 材料开发 (exe 版引擎, 零源码依赖):
  - 用 Loom.exe 摆场景、挂内置脚本 (第二节~第六节);
  - 游戏自定义脚本: 放 Loom\scripts\ 目录 (如 Loom\scripts\reset_fall.py),
    引擎启动自动加载注册 → 检查器"脚本"区挂上 (Python 热加载);
  - [→播放] 试玩 → 保存 (开发期场景明文, 发布时才加密;
    退出确认三态: 保存/不保存/取消)。

8.2 发布 (二选一):
  A. Loom.exe 工具栏 [发布游戏] → 对话框 (游戏名/公司名/窗口标题/启动场景/
     游戏脚本目录/输出目录) → [构建]。
  B. 命令行 (CI 也可, 对齐 BuildPipeline):
     build_game.exe --name 跳台试炼 --company "DSH实验室" \
         --scene 场景_明文.json --game-scripts scripts --output 发布夹
     首次或引擎更新: build_game.exe --build-runtime (Nuitka 打玩家运行时)。
     安全模式: --protection secure|open (默认 secure = 插件加密+哈希互验防作弊;
     open = 插件明文放行 MOD, 场景/脚本不加密需再加 --no-encrypt-content)。

8.3 构建器内部做的事 (build_game.py):
  读明文场景 -> 收集游戏脚本目录 .py 源码 -> 加密打包 游戏包.lsc
  (form: config{name/company/version/title} + scene + scripts + externals
   + plugins_sha256 插件互验哈希) -> 拷贝玩家运行时 (MyGame.exe + 运行库)
  -> 组装 发布夹。

8.4 玩家启动链 (game_player.py, 顺序关键):
  load 游戏包.lsc (缺包报错 = _Data 缺失) -> register_sources(脚本注册,
  未注册脚本被引擎静默跳过) -> install_game_plugins (玩家插件 .lpc 装入,
  与 .lsc plugins_sha256 互验防改) -> PlayerApp(scene_data, title) 直接
  喂场景 (场景不出明文) -> 运行; 窗口标题 = 游戏名。

8.5 发布夹与玩家操作:
  MyGame.exe + 游戏包.lsc (同夹不可分离; obj/音频素材引用相对路径时整夹放)
  玩家: 双击即玩; WASD/鼠标视角/空格跳/Tab 鼠标锁/F11 全屏/关窗退出。

8.6 定向测试封装环节 (与《使用操作指南.txt》第七节 6 同款):
  ① 构建 → 发布夹无任何 .py/.json 明文; ② 双击玩 10s (彩球 HUD/跌出重置
  自动回出生点 = 包内脚本生效); ③ 改名 游戏包.lsc → 双击报错提示;
  ④ 玩家发布夹独立目录, 勿与 Loom.exe 同夹 (exe 旁有 游戏配置.json 时
  Loom.exe 会当玩家启动)。

8.7 限制: 单场景启动/无 exe 图标/多场景列表 v1 未做; 保护等级 =
  --protection secure|open (默认 secure: 全加密+哈希互验, 压缩+XOR+base64
  防窥非绝对加密; open: 明文+允许 MOD, 用 --no-encrypt-content)。
