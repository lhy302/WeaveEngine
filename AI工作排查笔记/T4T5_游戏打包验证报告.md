## 2. T4 适配: 游戏配置.json (游戏适配配置, 非打包阶段改动)

- 打包默认渲染 API = vulkan, 但 Vk 播放器尚无物理 (B1 未落主线) → 本游戏 (玩家刚体 + 彩球 count_touch 碰撞事件) 在 Vk 下脚本全 broken。
- 依据 game_player.py `_pick_backend`: `<exe目录>/游戏配置.json` 的键 `render_api` (值 `vulkan|opengl`) 优先于应用设置/默认 vulkan, 再经 run_player.resolve_backend 归一。
- build_game 未产出该文件 (构建输出= MyGame.exe + 游戏包.lsc + 运行时支持文件)。以普通文本编辑新建:
  `D:\my-project\游戏发布\跳台试炼\游戏配置.json` = `{"render_api": "opengl"}` (仅此一键; 包模式不读 scene/title 键, title 取自包内 config)。
- 已实测生效: T5 启动窗口标题=跳台试炼 且画面正常渲染 → GL 保底路径经 run_player.run_backend 成功。
