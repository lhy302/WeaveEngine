### A.2 真 Qt GUI 按钮点击确认 (p5_gui_float_probe.py, ALL PASS 复现)

按真实用户操作逐钮点击: 立方体 → ＋加刚体(受重力) → **碰撞器钮点 1 次** → →播放:
```
PASS 初始碰撞器按钮文本='碰撞器: 禁用' (启用状态却显示'禁用'= 措辞陷阱)
```

### A.3 根因 (两层)

1. **桥语义回归 (核心)**: `_build_one` 对"碰撞体无效"的动态体 (collider **禁用** /
   shape='none' / 无 collider) **不建体**; 桥世界重力=(0,0,0), 重力只经 R1 策略在
   已建体上手动累加 -> 不建体 = 永不受重力、永不动. 即 P2 落地说明 §4.7"已知差异"
   ("桥路径下该物体不再有重力/速度运动 (legacy 仍会)") 被用户命中. 而 **legacy /
   Unity 契约 = 刚体重力与碰撞体无关** (无碰撞体只是"不阻挡", 照常下落/运动) ——
   桥模块头自述"不改变任何契约语义", 此差异即违背.
2. **检查器按钮措辞陷阱**: "碰撞器: 禁用" 显示于 **已启用** 状态 (动作式措辞:
   点此禁用), 与其余行 (刚体: 受重力 / 循环: 开) 的状态式措辞相反 —— 用户把
   动作读作状态: 见"禁用"→点击以为启用→实际关掉; 点一次后按钮换为"碰撞器: 启用"
   (点此启用), 用户再读作"启用中" → 与报告原文"碰撞器选项启用时 仍然浮空"逐字吻合.

### A.4 修复

- **physics_bridge.py ① 无碰撞体动态体自由积分** (`_is_dynamic_free` +
  `_refresh_free` + pre_step 自由段): DYNAMIC (非 kinematic, rb 存在) 且碰撞体
  无效(禁用/none/None) → 不建 Jolt 体, Python 侧积分: `v.y += g·dt`(use_gravity)
  + `position += v·dt`(有速度时) —— 与 legacy "累加-移动"逐位一致 (legacy 对无碰撞体
  同样自由移动、不做任何碰撞, 两者行为完全重合). 名单于 build/ensure_models 每帧刷新
  (播放中开/关碰撞器即时切换, 配合既有差量重建: 恢复碰撞器→建体转 Jolt 路径).
- **loom_gui.py 检查器按钮措辞** (1 行, smallest diff): 状态+动作双显 ——
  "碰撞器: 启用中(点按禁用)" / "碰撞器: 已禁用(点按启用)".

## B. 滑动/滚动残速死带 (彻底停止)

### B.1 根因

Jolt 库仑摩擦对亚阈值相对速度 (0.0x m/s 级) 的接触不再显著做功 -> 指数尾巴,
可缓慢漂移数秒 = 用户"有减速但仍有极轻微缓慢移动" (滚动侧同: 滚动衰减
|ω|<0.06 起停写, 残 ω 微滚动). P1 衰减"不防睡眠停写"设计使尾巴天然存在.

### B.2 修复 (physics_bridge.py post_step, 滚动衰减之后)

死带: 清醒 DYNAMIC 体 **同时** 满足 |v_h|<V_STALL_EPS 且 |ω|<W_STALL_EPS 且
|vy|<VY_STOP_GATE → 水平速度+角速度当帧清 0 (双 set_* 写, 同滚动衰减处):
```python
V_STALL_EPS = 0.03    # 水平残速死带 (m/s; 可标定 0.02-0.05, 取中)
W_STALL_EPS = 0.3     # 角残速死带 (rad/s; 与 Jolt 睡眠角速阈同量级)
VY_STOP_GATE = 1.0    # |vy| 超该值=明显竖直运动, 死带不判 (下落/弹跳零影响)
```
- vy 不碰 (下落/弹跳不受影响); 竖直由 VY_STOP_GATE 独立保护.
- 写零实测不防睡 (P1-B-⑤) -> Jolt 自然入睡, 睡后 post_step 速度归零兜底,
  active=0 睡眠红利保持.

### B.3 标定数值表 (b_stall_calib_probe.py, 60fps, 死带开=0.03)
