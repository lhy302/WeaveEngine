# 问题清单 (只记录, 修复由主线程执行)

## P1 [音频 · 需修] game_audio 2.1.0 无法打开含**中文**的绝对路径 — AudioBackend 静默回退 pygame
- 现象: `mgr.load_sound(绝对路径含中文)` → `FileLoadException('File not found or cannot be opened: ...')`; 同文件纯 ASCII 绝对路径 loaded OK; 文本里中文路径也 OK (相对路径)
- 证据 (T1_ga_path_probe.py):
  ```
  ascii_no_paren_abs   OK   SoundHandle(1)   (C:\Windows\Temp\tone_test.wav)
  ascii_paren_abs      OK   SoundHandle(2)   (C:\Windows\Temp\a(b)\t1.wav)
  chin_no_paren_abs    FAIL FileLoadException('D:\my-project\测试目录\t1.wav')
  chin_paren_abs       FAIL FileLoadException('D:\my-project\Loom(py源代码-工作区)\Loom\tests\_tmp\tone_test.wav')
  rel_ascii            OK   SoundHandle(3)   (t1.wav, cwd=Loom\)
  ```
- 最小复现: 生成 `tone_test.wav` 到含中文目录 → `AudioBackend().load(abs_path)` → 返回 `{'kind':'py', 'obj':<pygame.Sound>}` (mode 仍报 `game_audio`)
- 影响面: **本项目所有保存目录/场景路径天然含中文** (`Loom(py源代码-工作区)\Loom\保存\`), 即引擎内真实音频资源全部走 pygame 回退在播放 — B2 换库的目标 (统一 game_audio 后端) 对实际项目路径未生效; 对听感/语义无明显差异 (回退可播放/停止), 但 loop 语义与并发策略是两套实现
- 代码位置: `audio_backend.py:107-112` (ga 加载失败 → per-file `_py_fallback` 静默降级, 无日志); 缺陷本体在第三方 `game_audio 2.1.0`
- 处置建议 (留给主线程): ga 侧查其原生层路径编码 (疑似 ANSI/UTF-8 字节问题); 或 AudioBackend 在 `try game_audio` 失败时打日志/主动探测
