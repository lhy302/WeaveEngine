# Loom 引擎 0.1.0.beta4 — 本版要点

本版是 **beta3 全量回补审计**后的修复版：6 个模块各派一个独立子代理按「粗筛 → 双向推演 → 四象限裁决」扫了 115 条疑似项（70 条证实、37 条确认为 beta3 修补引入的回归），逐条修完并做两轮独立复跑验收。

- **配置体系重建**：运行期配置改为「发布夹只读默认模板 + 用户层 delta（`%LOCALAPPDATA%\Loom\`）」。装到 `Program Files` 也能正常保存；旧配置自动迁移，坏文件先备份再重建
- **鼠标锁定默认关闭**（`mouse_lock_allowed` 默认 false）：之前吃豆人这类不用鼠标的游戏会被默认锁死、只能 Alt+F4。现在没人要求就不锁；要锁的游戏显式打开，并用 `set_ui_capture_mouse()` 自己决定何时给光标（不做「看到 UI 就自动解锁」——常驻 HUD 的视角类游戏会被它搞坏）
- **解锁可验证 + Win32 兜底**：解锁后回读 GLFW 模式、补 `ClipCursor/ShowCursor`，并打印 `[鼠标]` 状态行，修「光标出现但动不了」
- **多后端一致性**：VK 现在真正应用场景 `camera.fov`（此前被无条件复位 60°）；GL 播放器补上 UI 鼠标派发（此前通关面板只能看不能点）；VK 键位加载补 `import os`（此前一直静默失效）
- **撤销/批次**：Agent 批次 30 秒租约自动收口（断连不再锁死撤销），单条失败不再丢整批，批内 Ctrl+Z 有明确提示
- **发布闸门**：版本单一事实源（包名 = 包内元数据 = tag）；缺预置运行时默认失败；发布前默认先跑全套回归，非零即中止且零远端写
- **本版形态变更**：引擎本体改为 **Nuitka 编译版**（`Loom.exe` + `build_game.exe`），包内不再含 .py 源码与嵌入式 Python；包体 332 MB → 110 MB

> 已知未验证：GPU 像素级 A/B 基线、打包版真鼠标点击、部分 P-UNKNOWN 项（详见仓库 `docs/audit/_scan_beta3_summary.md` §9.3）。
