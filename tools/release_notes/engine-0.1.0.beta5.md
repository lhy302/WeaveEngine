# Loom 引擎 0.1.0.beta5（内测）

本版是**编译版引擎包**（Nuitka standalone 编辑器 + onefile 构建器 + 编译版播放器运行时），可直接安装/解压后由 LoomHub 添加为解释器（`kind=exe`）。

## 一、性能：38-41 FPS → 84-90 FPS，TPS 回到 30+

同一场景（`压测500混合`，501 物体 / 2 光源）实机实测：

| 指标 | 修前 | 本版 |
|---|---|---|
| FPS | 38-41（remote-mode 强开）／55-61（直连） | **84-90** |
| TPS（逻辑步/秒） | 23.7 | **30.2-30.5**（目标 30） |
| GPU 占用 | 31-34% | **56%** |

三条根因逐一修掉：

1. **逻辑时钟记账错误**：同步路径信任调用方 dt（基准传 1/120=8.3ms，实跑 94 FPS=10.6ms），每秒只累计 0.79 秒 → TPS = 30×0.79 = **23.7**（与现场读数逐位吻合）。
   现在 `engine._clock_advance()` 作为推进逻辑时钟的唯一入口，取 `max(调用方 dt, 实测墙钟)`，三路径统一。
2. **单核 GIL 饥饿**（修完口径后才暴露）：满载时逻辑线程每秒只被调度约 10 次，单逻辑步墙钟 15ms→39ms。
   - `loom_lighting`：AABB `visible_only=True` 同帧记忆化（504 物体 15.3ms/次 → 命中 0.35ms）
   - `loom_render._prepare_bucket_frame`：桶计划预生成 + 每帧一次 `fw32[order]` gather，删掉 38 次 ctypes pack
   → 主线程 buckets 4.22→2.30ms、pipe_wait 5.73→3.62ms，逻辑线程回血。
3. **暂停补欠账**：暂停期间墙钟点不更新，恢复首帧一帧连跑 9-10 个逻辑步。四条暂停路径各加重锚，恢复首帧 ≤1 步。

> `--bench` 现在同时输出 TPS 与 `ratio = 逻辑 dt 总和 / 墙钟总和`。注意 `ratio` 恒 ≥ 1（实现取 max），`ratio≈1` 说明缺口在每逻辑帧成本。

## 二、天空盒：默认蓝天 + 语义自洽

- **默认天空盒 = 蓝天 `(58,155,213)`**：新建场景自动注入；加载缺键/`null` 的场景同样按默认蓝天（此前是深色底 `(25,31,41)`）。
- **「清空天空盒」= 恢复默认蓝天**（`reset_to_default`）。要黑天空请显式设 `#000000`。
- **相机级天空盒优先**真正生效（此前有契约、有序列化、零渲染消费者）；按相机身份（guid）配对，不再按下标错配。
- **GL 与 VK 逐像素等价**：有/无天空盒均 MAE=0.000（0/38400 像素差）。
- **无效 cubemap 统一处理**：缺面/尺寸不一致 → 拒绝 + 告警一次 + 不画（删掉 GL 的 1×1 白兜底，VK 不再 IndexError 穿透终止渲染循环）。
- **失败可见**：`skybox_get` 返回 `valid/reason/scene_valid/active_camera_skybox/vk`；颜色只认 0..255（0-1 浮点会被明确拒绝并给出修复提示）。
- **路径可移植**：六面图存相对场景目录路径，并限制在场景目录内（`..` 越界与绝对路径拒绝）。

## 三、播放器与入口

- `LOOM_REMOTE_MODE=auto`：先按原生上屏运行，连续失败达阈值才降级为离屏回读，**只重启一次**并打印原因。
  上屏健康判据 `PresentHealth` 为单点实现，**GL 与 Vulkan 共用**（此前 VK 下 auto 是零输出 no-op）。
- `run()` 退出恢复 `glfw.terminate()`（此前一段提交误删该调用，播放器退出不释放 GLFW）。
- 逻辑线程停止：先 `ev.set()` 再清引用、循环用局部 `ev`、重复 start 复用（此前 stop 卡 2s、孤儿线程继续推步、再 start 变双线程）。
- `--bench` 结果改写用户目录 `%LOCALAPPDATA%\Loom\bench\bench_result.txt`（不再污染工作树）；场景不存在/帧数 ≤0 直接报错退出，不再先建窗再崩。

## 四、已知限制

- **`LOOM_REMOTE_MODE=auto` 的真实故障路径未复现**：单元级已验证（连续 3 次上屏失败判真、成功一次清零、只重启一次），但本机不白屏，无法人为制造 GPU 故障。
- **包体 125.94 MB**（上一版 109.34 MB）：VK 侧支持 remote 回退后，播放器运行时带入 PySide6 + Qt（解压约 +43 MB）。已由人类裁决接受。
- 示例场景 `PacMan2D` 的"地板"铺满整个正交视口，即使默认蓝天生效也看不到天空——这是场景内容，不是引擎缺陷。

## 五、安装

1. 解压到 `C:\Program Files\Loom\0.1.0.beta5\`（压缩包内含 `Loom\` 目录）
2. 打开 LoomHub → 扫描/导入该目录 → 解释器类型应为 `exe`（编译版）
3. 该目录需可写（配置与日志走 `%LOCALAPPDATA%\Loom\`，模板层只读）
