====================================================================
一、批5A — core_clock.py 重构 (单 accumulator + 物理子步, Unity 语义)
====================================================================
【裁决落地】双 accumulator 删除。新模型 = 一个逻辑 accumulator; 每逻辑帧
内部按 phys_substeps 跑 N 次物理子步, 子步 dt = phys_substep_dt (内部参数,
默认 1/60, Unity fixedDeltaTime 语义: 物理步长是物理引擎内部参数, 不是
用户频率旋钮)。"physics_fps" 从设置面撤下 (engine 兼容读旧键作内部参数
换算, 一代后移除)。

【N 的定案 — 编译期定常数, 不按穿透"自动"逐帧调】
  N = ceil(1/logic_fps / phys_substep_dt) = ceil(phys_substep_dt 倒数×fixed_dt)
  逻辑 30Hz + 子步 1/60 → N=2 (每逻辑帧 2 物理步, 物理 60Hz);
  逻辑 20Hz → N=3; 逻辑 60Hz → N=1; 逻辑 120Hz → N=1 但子步 dt 拉齐
  fixed_dt (当 N==1 时子步 dt:=fixed_dt, 物理与逻辑同拍 — 无穿透风险)。
  理由: 物理确定性要求步长恒定 (Jolt 数值只依赖 dt 序列); "按穿透自动定"
  会在运行中改 dt → 破坏同 seed 对拍与回放, 且穿透本身已由
  phys_substep_dt<=1/60 兜住 (Jolt 默认参数下 60Hz 步长安全, 现场即 60Hz)。
  N 计算放 set_fps 与 __init__, 运行中不变 (logic_fps 改动时重算)。
【余量处理】单 accumulator: advance 只在逻辑步边界排步; 物理 = 逻辑帧内
  子步循环, 无独立积压。maximum_logic_delta / max_steps_per_frame /
  time_scale / alpha 语义逐字保留。phys_steps = 最后一个逻辑帧内的子步数
  (HUD 观测用, 不再是独立调度单位)。
【回调语义】on_logic_step(fixed_dt) 不变; on_physics_step 取消 — engine
  侧 _physics_frame 保留为公开方法但由 _logic_frame 内子步循环直调
  (engine._physics_frame(phys_dt) 签名/内容一行不改, R1: 搬位置不改逻辑)。

```python
# -*- coding: utf-8 -*-
"""
core_clock.py — 逻辑帧/渲染帧分离核心时钟 (分离批5 架构重对齐, 2026-09-05)

FixedStepClock = Unity Player Loop 的 accumulator 模型 (批5 重构定案):
  - **单 accumulator**: 只有逻辑帧是调度单位 (整个场景的最高同步点);
    每逻辑帧内部按 phys_substeps 自动跑 N 次物理子步 (Unity 模型:
    物理步长 = 物理引擎内部参数 fixed_dt, 不是用户频率旋钮 — 双 accumulator
    与 physics_fps 设置为批1 的过度设计, 批5 移除);
  - phys_substep_dt: 物理子步固定步长 (默认 1/60, Jolt 穿透安全);
    N = ceil(fixed_dt / phys_substep_dt); N==1 时子步 dt:=fixed_dt
    (物理与逻辑同拍, 高逻辑帧率下不缩步长);
  - maximum_logic_delta: 单渲染帧计入的逻辑时间上限 (死亡螺旋保险,
    Unity Time.maximumDeltaTime 精神);
  - max_steps_per_frame: 单渲染帧逻辑步数上限, 超限丢积压 (Unity
    Time.maximumFixedTimestep 精神);
  - time_scale: 暂停=0 / 慢放=0.5 (Unity Time.timeScale 精神);
  - alpha: 渲染帧位于 curr 逻辑帧内的进度 [0,1), 插值层消费。

纯逻辑零依赖 (无 pygame/engine import), tests 单测直调。
LOOM_NO_SPLIT=1 由调用方判 (engine 侧逃生门), 本类不读环境变量
(split_enabled 除外 — 它是设置面判定函数, 一次性调用)。
"""
import os
import time


class FixedStepClock:
    """固定步长单 accumulator 时钟 (逻辑帧 = 最高同步点, 物理在帧内子步)."""

    def __init__(self, logic_fps=30.0, phys_substep_dt=1.0 / 60.0,
                 maximum_logic_delta=0.25, time_scale=1.0,
                 max_steps_per_frame=8):
        self.logic_fps = float(logic_fps)
        self.phys_substep_dt = float(phys_substep_dt)
        self.maximum_logic_delta = float(maximum_logic_delta)
        self.time_scale = float(time_scale)
        self.max_steps_per_frame = int(max_steps_per_frame)
        self.alpha = 0.0                 # 渲染帧插值系数 [0,1)
        self.steps = 0                   # 上渲染帧逻辑步数 (HUD/调试)
        self.phys_steps = 0              # 上渲染帧物理子步累计 (HUD/调试)
        self._acc = 0.0                  # 逻辑 accumulator (秒)
        self._last = None                # 上次 advance 时间戳 (None=首帧)
        # 逻辑帧回调: [fn(fixed_dt), ...] — 物理/脚本/音频/动画全在里面,
        # 由 engine._logic_frame 组织帧内段次序 (批5/批6 流水线挂点)
        self.on_logic_step = []
        self._recalc()                   # 算 sub_steps / sub_dt

    def _recalc(self):
        """由 logic_fps + phys_substep_dt 定每逻辑帧物理子步数 (编译期定常数):
        N = ceil(fixed_dt / sub_dt); N==1 时子步 dt 拉齐 fixed_dt (物理与逻辑
        同拍 — 子步不比逻辑步更细时保留更大步长, 与 Unity 单步语义一致)."""
        fdt = 1.0 / max(self.logic_fps, 1e-6)
        sdt = max(float(self.phys_substep_dt), 1e-6)
        n = int(math.ceil(fdt / sdt - 1e-9))
        if n < 1:
            n = 1
        self._sub_steps = n
        self._sub_dt = fdt if n == 1 else sdt

    # ---- 步长 (fps<=0 防御: 调用方逃生门不会进来, 这里兜底不除零) ----
    @property
    def fixed_dt(self):
        return 1.0 / max(self.logic_fps, 1e-6)

    def set_fps(self, logic_fps=None, phys_substep_dt=None):
        """运行中改频 (设置面板/脚本): 累积器按新步长继续 (小数余量保留,
        不追帧不跳步); 子步数随之重算 (下一逻辑帧生效)."""
        if logic_fps is not None and logic_fps > 0:
            self.logic_fps = float(logic_fps)
        if phys_substep_dt is not None and phys_substep_dt > 0:
            self.phys_substep_dt = float(phys_substep_dt)
        self._recalc()

    def reset(self):
        """边界对齐 (场景加载/进出播放): 清累积器+首帧重锚, alpha=0."""
        self._acc = 0.0
        self._last = None
        self.alpha = 0.0
        self.steps = self.phys_steps = 0

    def advance(self, render_dt=None):
        """每渲染帧调一次. render_dt=None 则内部实测墙钟 (首帧 0 步).
        返回 (steps, phys_steps) — phys_steps = 本帧子步累计 (兼容旧观测面)."""
        if render_dt is None:
            now = time.perf_counter()
            render_dt = 0.0 if self._last is None else now - self._last
            self._last = now
        # 死亡螺旋保险: 单帧计入时间封顶 (Unity maximumDeltaTime)
        dt = min(max(render_dt, 0.0), self.maximum_logic_delta) * self.time_scale
        self._acc += dt
        steps = 0
        psteps = 0
        fdt = self.fixed_dt
        while self._acc >= fdt and steps < self.max_steps_per_frame:
            for fn in tuple(self.on_logic_step):
                fn(fdt)                  # 逻辑帧 = 最高同步点 (物理子步在内)
            self._acc -= fdt
            steps += 1
            psteps += self._sub_steps
        if steps == self.max_steps_per_frame and self._acc >= fdt:
            self._acc = 0.0              # 积压丢弃 (死亡螺旋保险)
        self.steps = steps
        self.phys_steps = psteps
        # alpha: 渲染帧在 curr 逻辑帧内的进度 (插值层只看逻辑 alpha)
        self.alpha = self._acc / fdt if steps or self._acc > 0.0 else 0.0
        return steps, psteps

    # ---- 批5 公开只读面 (engine/driver 消费; 私有名只类内用) ----
    @property
    def sub_steps(self):
        """每逻辑帧物理子步数 N = ceil(fixed_dt / sub_dt) (编译期定常数)."""
        return self._sub_steps

    @property
    def sub_dt(self):
        """物理子步固定步长 (N==1 时 = fixed_dt, 物理与逻辑同拍)."""
        return self._sub_dt


def clock_from_settings(settings):
    """设置.json -> FixedStepClock (guiloader.load_settings('loom') 产物).
    逃生门判定也在这: logic_fps<=0 返回 None (调用方回退旧绑死模式).
    子步长来源 (批5 最终口径, §九#4):
      ① "phys_substep_dt" >0 直接用 (新内部参数键, 高级开发者);
      ② 旧键 "physics_fps" >=50 才换算 1/pf (<50 视为误设, 兜底 60Hz
         防薄地板穿透); 键已从用户面撤下, 一代后移除本段."""
    lf = float(settings.get("logic_fps", 30))
    if lf <= 0:
        return None
    sdt = float(settings.get("phys_substep_dt", 0) or 0)
    if sdt <= 0:
        pf = float(settings.get("physics_fps", 0))
        sdt = (1.0 / pf) if pf >= 50.0 else (1.0 / 60.0)
    return FixedStepClock(logic_fps=lf, phys_substep_dt=sdt)


def split_enabled(settings=None):
    """分离总开关: LOOM_NO_SPLIT=1 或 logic_fps<=0 = 旧绑死模式 (A/B 基线)."""
    if os.environ.get('LOOM_NO_SPLIT') == '1':
        return False
    if settings is None:
        try:
            import guiloader
            settings = guiloader.load_settings('loom')
        except Exception:
            settings = {}
    return float(settings.get("logic_fps", 30)) > 0
```

====================================================================
三、批5B — 渲染帧 prep 缓存化 (核心: 逐项"逻辑帧间不变性"分析与定案)
====================================================================
【总原则】渲染帧每段 prep 的数据源分两类:
  A 类 = 只依赖**逻辑位姿** (世界矩阵 _frame_world / 逻辑状态):
      逻辑帧之间不变 → 按逻辑帧算一次缓存, 渲染帧只读;
  B 类 = 依赖**渲染位姿** (插值平面 → _render_world):
      每渲染帧变 → 保留在渲染帧, 但只留"必留"的最小段。
  用户定调: 阴影 VP 等保守量用逻辑位姿算 (插值幅度 < 半逻辑步位移,
  包围盒 pad=1.5 已有余量, 视觉不可感); 渲染帧只消费。

【逐项判定表 (500 球播放态现场耗时)】
| prep 段                    | 现状锚点              | 耗时   | 类 | 定案 |
| aabbs 全量包围盒            | :2452 (_model_aabbs_par) | ~8.7ms | A | 逻辑帧缓存 |
| shadow_bounds (光源 VP)     | :2457 (_compute_light_vps) | ~15.3ms | A | 逻辑帧缓存 |
| shadow_cornerfill/matmul    | :2363-2403 内部       | 合计内 | A | 随 VP 缓存 |
| collide_pairs 碰撞对        | :2460 (_collision_pairs_parallel) | ~5ms | A | 逻辑帧缓存 |
| buckets 桶重排+实例上传      | :4300 (_prepare_bucket_frame) | ~7ms | A/B 拆 | 结构逻辑帧+矩阵渲染帧 |
| shadow map 绘制 / 主 pass   | :2514 / :4486         | GPU 段 | B | 留渲染帧 |
| interp 插值平面             | compute_render_matrices:2795 | ~1-2ms | B | 留渲染帧 |
| world_matrices (_frame_world)| compute_world_matrices:2729 | 0-2ms | A | 已有 _fw_cache |

【缓存失效键设计 (A 类共用, 定名 _logic_prep_cache)】

- 插值仍只进渲染矩阵 (_render_world), 不回写 GameObject (批2 红线不动)。

【静止场景零开销路径】
  逻辑帧没跑 (无位移/暂停/编辑态) → _logic_gen 不变 →
  aabbs/VP/碰撞对/桶结构 缓存全命中 → 渲染帧只跑:
  compute_world_matrices (_fw_cache 命中 ~0ms) → compute_render_matrices
  (static_frame() 命中时也跳重算, 复用上帧 _render_world 对象 — §四改2)
  → f32 cast+gather+GL write (桶 sig 命中时也跳, 批2 D4 闸已有) → 绘制。
  编辑器态 (is_playing=False): advance_logic 零逻辑 → 全部缓存命中,
  与现状编辑态行为一致。

```python
# -*- coding: utf-8 -*-
"""
physics_pipe.py — 常驻物理线程 v2 (分离批6 帧内流水线, 2026-09-05)

v2 流水线语义 (批6D): 主线程 post 提交子步后**不等待**, 先跑不依赖物理
的段 (音频/动画/prep 可并行部分), 到真正需要物理结果的同步点 (S1) 才
wait_pending() — "发指令不等待" (Panda3D 任务链 frameSync 模型).

生产者-消费者: pending 计数队列 (多子步连发不丢步); 全部桥状态
(Jolt _w/_entries/_last_sync) 只物理线程触碰; 主线程在 S1 后读模型属性
(回读由物理线程写, Event 置位 happens-before 安全).

三段 pre_step/step/post_step 原样搬线程, R1 红线一行不改.
超时降级: wait 超 timeout = RuntimeError → 调用方永久降级主线程直跑.
LOOM_NO_PIPE=1 = 线程永不建 (逃生门, A/B 基线).
"""
import threading


class PhysicsPipeThread:
    """常驻物理线程 (v2: pending 队列 + 同步点等待)."""

    def __init__(self, bridge, mask=0, timeout=1.0):
        self._br = bridge
        self._mask = int(mask or 0)
        self._timeout = float(timeout)
        self._lock = threading.Lock()
        self._go = threading.Event()      # 有活 (pending>0 或停止)
        self._done = threading.Event()    # 队列清空 (S1 同步点信号)
        self._pending = 0                 # 未消化子步数 (lock 内读写)
        self._jobs = []                   # [(models, dt, gravity, events), ...]
        self._err = None
        self._degraded = False
        self._stop = False
        self._t = threading.Thread(target=self._loop, name='loom-physics',
                                   daemon=True)
        self._t.start()

    def _loop(self):
        if self._mask:
            try:
                from parallel import pin_current_thread
                pin_current_thread(self._mask)
            except Exception:
                pass
        while True:
            self._go.wait()
            self._go.clear()
            while True:                   # 逐个消化队列 (不丢步)
                with self._lock:
                    if self._stop:
                        return
                    job = self._jobs.pop(0) if self._jobs else None
                if job is None:
                    break
                models, dt, g, ev = job
                try:
                    br = self._br
                    br.ensure_models(models)
                    br.pre_step(dt, g)
                    br.step(dt)           # C 层释放 GIL: 主线程跑 D 段真并行
                    br.post_step()
                    self._err = None
                except BaseException as e:
                    self._err = e
                finally:
                    with self._lock:
                        self._pending -= 1
                        empty = (self._pending <= 0)
                    if empty:
                        self._done.set()  # S1: 队列清空 → 唤醒主线程

    def post(self, models, dt, gravity, events):
        """主线程: 提交一个物理子步 (非阻塞, 可连发 N 子步)."""
        with self._lock:
            self._jobs.append((list(models), dt, gravity, events))
            self._pending += 1
            self._done.clear()
            self._go.set()

    def wait_pending(self):
        """同步点 S1: 等全部已提交子步完成. 超时 = 报错+永久降级."""
        if not self._done.wait(self._timeout):
            self._degraded = True
            raise RuntimeError("物理线程同步超时 (%.1fs) -> 降级主线程直跑"
                               % self._timeout)
        if self._err is not None:
            e, self._err = self._err, None
            raise e

    # 兼容 v1 调用方 (engine._update_physics_bridge 旧路径/测试桩)
    wait = wait_pending

    def pending(self):
        """未消化子步数 (诊断/断言用)."""
        with self._lock:
            return self._pending

    def stop(self):
        """停止: 哨兵 -> join. 幂等 (v1 同款)."""
        with self._lock:
            self._stop = True
            self._jobs = []
            self._pending = 0
            self._go.set()
        self._t.join(timeout=2.0)
```
设计说明:
- 队列消化循环内层 while + 外层 go.wait: 连发子步时物理线程连续消化,
  不经 Event 往返 (v1 每子步 2 次 Event 切换 → v2 N 子步 1 次);
- _done 语义 = "pending 归零"而非"单步完成" → wait_pending 天然是
  批量同步点 (主线程连发 2 子步后一次等齐, S1 每逻辑帧至多 1 次);
- stop 清队列置 _stop, 内层循环 return (join 干净, W3 验证同批4)。
