【关键定案 D1 — advance 放在 render() 内部, run() 一行不改】
报告 4.3A 原写 "run() 里调 advance 再 render"。现场定案改为: 时钟 advance
放进 engine.render() 开头 (逻辑推进段), run() 主循环零改动。理由:
1) 三条泵入路径全部汇于 render(): run() 主循环 / build_entry --bench

3) EditorApp.render 是完全覆写, 不受影响; 批3 再把同款模式抄进编辑器。
【关键定案 D2 — 双 accumulator 次序: 每渲染帧先排逻辑步后排物理步】
每渲染帧 advance(): ①逻辑 accumulator 排干 0~N 步 (每步=脚本→音频→动画);
②物理 accumulator 排干 0~M 步 (update_physics 原样)。理由:
- 保持 Loom 现状帧内次序 "脚本先于物理" (脚本本帧改 velocity 本帧被物理
  消费 —— engine.render 4241→4243 现状), 场景行为不漂移;
- Unity 是 FixedUpdate→Update 且两者同频耦合, 不存在 30/60 解耦情形;
  解耦后"先补逻辑帧再补物理帧"与现状逐帧次序最接近;
- Jolt 步长恒 = 1/60, 数值只依赖步数序列不依赖墙钟, 物理 accumulator
  独立累加独立排干, R1 语义零触碰 (只决定"何时以何 dt 调用")。
【关键定案 D3 — 插值只进渲染矩阵, _frame_world 保持逻辑位姿 (R3)】
_frame_world (碰撞事件/拾取/AABB 共享源) = 逻辑位姿矩阵, 现管道原样;
新增 _render_world = 插值位姿矩阵, 只喂 _prepare_bucket_frame (桶/实例/

【关键定案 D4 — 桶 _dirty 总闸挂 pose_gen+alpha】

```python
# -*- coding: utf-8 -*-
"""
core_clock.py — 逻辑帧/渲染帧分离核心时钟 (分离批1, 2026-09-05)

FixedStepClock = Unity Player Loop 的 accumulator 模型:
  - 每渲染帧 advance(render_dt): 按固定步长排干 0~N 个逻辑步 (steps 返回);
  - 双 accumulator: 逻辑 (logic_fps, 默认 30Hz, 脚本/音频/动画)
    + 物理 (physics_fps, 默认 60Hz, Jolt 桥) 独立累加独立排干;
    排干次序 = 先逻辑步后物理步 (保持引擎现状"脚本先于物理"帧内次序,
    见 实施设计 D2);
  - maximum_logic_delta: 单渲染帧计入的逻辑时间上限 (死亡螺旋保险,
    Unity Time.maximumDeltaTime 精神);
  - max_steps_per_frame: 单渲染帧步数上限, 超限丢积压 (Unity
    Time.maximumFixedTimestep 精神);
  - time_scale: 暂停=0 / 慢放=0.5 (Unity Time.timeScale 精神);
  - alpha: 渲染帧位于 curr 逻辑帧内的进度 [0,1), 插值层消费。

纯逻辑零依赖 (无 pygame/engine import), tests 单测直调。
LOOM_NO_SPLIT=1 由调用方判 (engine 侧逃生门), 本类不读环境变量。
"""
import os
import time


class FixedStepClock:
    """固定步长双 accumulator 时钟 (逻辑 + 物理)."""

    def __init__(self, logic_fps=30.0, physics_fps=60.0,
                 maximum_logic_delta=0.25, time_scale=1.0,
                 max_steps_per_frame=8, max_phys_steps_per_frame=8):
        self.logic_fps = float(logic_fps)
        self.physics_fps = float(physics_fps)
        self.maximum_logic_delta = float(maximum_logic_delta)
        self.time_scale = float(time_scale)
        self.max_steps_per_frame = int(max_steps_per_frame)
        self.max_phys_steps_per_frame = int(max_phys_steps_per_frame)
        self.alpha = 0.0                 # 渲染帧插值系数 [0,1)
        self.steps = 0                   # 上帧逻辑步数 (HUD/调试)
        self.phys_steps = 0              # 上帧物理步数
        self._acc = 0.0                  # 逻辑 accumulator (秒)
        self._pacc = 0.0                 # 物理 accumulator (秒)
        self._last = None                # 上次 advance 时间戳 (None=首帧)
        # 回调列表: 逻辑步 (dt 恒定 = fixed_dt) / 物理步 (dt 恒定 = phys_dt)
        self.on_logic_step = []          # [fn(fixed_dt), ...] 先排
        self.on_physics_step = []        # [fn(phys_dt), ...] 后排

    # ---- 步长 (fps<=0 防御: 调用方逃生门不会进来, 这里兜底不除零) ----
    @property
    def fixed_dt(self):
        return 1.0 / max(self.logic_fps, 1e-6)

    @property
    def phys_dt(self):
        return 1.0 / max(self.physics_fps, 1e-6)

    def set_fps(self, logic_fps=None, physics_fps=None):
        """运行中改频 (设置面板/脚本): 累积器按新步长继续 (小数余量保留,
        不追帧不跳步)."""
        if logic_fps is not None and logic_fps > 0:
            self.logic_fps = float(logic_fps)
        if physics_fps is not None and physics_fps > 0:
            self.physics_fps = float(physics_fps)

    def reset(self):
        """边界对齐 (场景加载/进出播放): 清累积器+首帧重锚, alpha=0."""
        self._acc = 0.0
        self._pacc = 0.0
        self._last = None
        self.alpha = 0.0
        self.steps = self.phys_steps = 0

    def advance(self, render_dt=None):
        """每渲染帧调一次. render_dt=None 则内部实测墙钟 (首帧 0 步).
        返回 (steps, phys_steps)."""
        if render_dt is None:
            now = time.perf_counter()
            render_dt = 0.0 if self._last is None else now - self._last
            self._last = now
        # 死亡螺旋保险: 单帧计入时间封顶 (Unity maximumDeltaTime)
        dt = min(max(render_dt, 0.0), self.maximum_logic_delta) * self.time_scale
        pdt = dt                         # 物理同源同缩放 (time_scale 一致)
        self._acc += dt
        self._pacc += pdt
        # ① 逻辑步 (脚本→音频→动画, 由 on_logic_step 列表定义)
        steps = 0
        fdt = self.fixed_dt
        while self._acc >= fdt and steps < self.max_steps_per_frame:
            for fn in tuple(self.on_logic_step):
                fn(fdt)
            self._acc -= fdt
            steps += 1
        if steps == self.max_steps_per_frame and self._acc >= fdt:
            self._acc = 0.0              # 积压丢弃 (死亡螺旋保险)
        # ② 物理步 (Jolt 三段, dt 恒 = phys_dt, R1: 只决定何时以何 dt 调)
        psteps = 0
        pdt_step = self.phys_dt
        while self._pacc >= pdt_step and psteps < self.max_phys_steps_per_frame:
            for fn in tuple(self.on_physics_step):
                fn(pdt_step)
            self._pacc -= pdt_step
            psteps += 1
        if psteps == self.max_phys_steps_per_frame and self._pacc >= pdt_step:
            self._pacc = 0.0
        self.steps = steps
        self.phys_steps = psteps
        # alpha: 渲染帧在 curr 逻辑帧内的进度 (物理步留一个有余量就跑,
        # 与 Unity FixedUpdate 语义一致; 插值层只看逻辑 alpha)
        self.alpha = self._acc / fdt if steps or self._acc > 0.0 else 0.0
        return steps, psteps


def clock_from_settings(settings):
    """设置.json -> FixedStepClock (guiloader.load_settings('loom') 产物).
    逃生门判定也在这: logic_fps<=0 返回 None (调用方回退旧绑死模式)."""
    lf = float(settings.get('logic_fps', 30))
    if lf <= 0:
        return None
    pf = float(settings.get('physics_fps', 60))
    return FixedStepClock(logic_fps=lf, physics_fps=pf)


def split_enabled(settings=None):
    """分离总开关: LOOM_NO_SPLIT=1 或 logic_fps<=0 = 旧绑死模式 (A/B 基线)."""
    if os.environ.get('LOOM_NO_SPLIT') == '1':
        return False
    if settings is None:
        try:
            import guiloader
            settings = guiloader.load_settings('loom')
        except Exception:
            settings = {}
    return float(settings.get('logic_fps', 30)) > 0
```

设计说明 (照 Unity 语义定案理由):
- advance 返回 (steps, phys_steps) 而非报告的 steps —— 物理 60Hz 独立
  accumulator 需要独立可观测 (HUD 分开显示), 且 bridge 插桩分段统计按
  物理步展开 (见 §四验证)。
- on_logic_step/on_physics_step 用回调列表而非写死四段: 批3 编辑器/批4
  物理线程化复用同一时钟不改类; tuple() 拷贝遍历防回调中改列表。
- time_scale 乘在 min() 之后: maximum_logic_delta 是真实墙钟上限,
  time_scale 只缩放"逻辑时间流速" (Unity 同义)。
- alpha 定义 = _acc/fdt: 渲染帧位置 = curr(最后完成逻辑帧) 与 prev 之间,
  与报告 4.2 一致; time_scale=0 (暂停) 时 dt=0, acc 不动, alpha 保持
  上一渲染帧值 —— 暂停画面静止但渲染照跑 (符合 Unity)。

```python
# -*- coding: utf-8 -*-
"""
interp_state.py — 逻辑帧双快照 + 渲染帧 numpy 插值 (分离批2, 2026-09-05)

InterpState = prev/curr 两个 (N,3) 平面快照 (position/rotation_euler/scale),
  - advance(): 逻辑帧翻页 prev<-curr, curr<-_grab() (照抄 engine.
    _transform_snapshot:2647 的 id 钉住三件对象模式, R6);
  - render_pose(alpha): 全 numpy 向量化插值平面 (pos/scl lerp, rot 小角度
    angdiff), 只喂渲染矩阵管道, **不回写 GameObject** (R3);
  - align(): curr=prev 强制对齐 (暂停/加载/toggle_play 边界, alpha=0);
  - 新增物体: prev 缺行用 curr 行填 (首帧不插值);
  - 缓冲 grow-only (R8): _prev/_curr 按容量复用, 扩容只在物体数增长帧。

双端共享: engine.GLEngine 与 scene_driver.SceneDriver 各持一个实例,
  本文件不 import 任何一端 (依赖倒置, 零循环导入)。
"""
import numpy as np


class InterpState:
    """prev/curr 变换快照 + alpha 插值 (numpy 平面, grow-only)."""

    def __init__(self, models):
        self._models_ref = models        # models 列表对象 (id 钉住判据用)
        self._ids = None                 # (N,) int64 上帧物体 id 序 (对齐用)
        self._prev = None                # (N,3) f64 pos/rot/scl 各三块
        self._prev_rot = None
        self._prev_scl = None
        self._curr = None
        self._curr_rot = None
        self._curr_scl = None
        self._out = None                 # 插值输出平面 (持久, R8)
        self._out_rot = None
        self._out_scl = None
        self.alpha = 0.0
        self._pend = None                # (id 标记, 抓取平面) 待翻页缓冲

    # ---------------- 抓取 (照抄 _transform_snapshot 钉住模式) ----------------
    def _grab(self, models):
        """当前变换 -> (ids, pos, rot, scl) 三个 (N,3) f64 平面.
        R6: ids 记录 id(m) 且把模型列表对象钉在 self._models_ref —— 与
        _transform_snapshot 的对象钉住同构: 钉住的对象不死, id 不可能被
        复用, ids 相等 ⟺ 同一批物体 ⟹ 行对齐成立."""
        n = len(models)
        ids = np.empty(n, dtype=np.int64)
        pos = np.empty((n, 3), dtype=np.float64)
        rot = np.empty((n, 3), dtype=np.float64)
        scl = np.empty((n, 3), dtype=np.float64)
        for i, m in enumerate(models):
            ids[i] = id(m)
            p = m.position; r = m.rotation; s = m.scale
            pos[i, 0] = p.x; pos[i, 1] = p.y; pos[i, 2] = p.z
            rot[i, 0] = r.x; rot[i, 1] = r.y; rot[i, 2] = r.z
            scl[i, 0] = s[0]; scl[i, 1] = s[1]; scl[i, 2] = s[2]
        return ids, pos, rot, scl

    def _fit(self, n):
        """grow-only 扩容 (R8): 只在 n > 当前容量时重分配 (2x 余量)."""
        def fit(buf):
            if buf is None or buf.shape[0] < n:
                cap = max(n, (buf.shape[0] * 2) if buf is not None else 64)
                return np.empty((cap, 3), dtype=np.float64)
            return buf
        self._curr = fit(self._curr); self._curr_rot = fit(self._curr_rot)
        self._curr_scl = fit(self._curr_scl)
        self._prev = fit(self._prev); self._prev_rot = fit(self._prev_rot)
        self._prev_scl = fit(self._prev_scl)
        self._out = fit(self._out); self._out_rot = fit(self._out_rot)
        self._out_scl = fit(self._out_scl)

    # ---------------- 逻辑帧翻页 ----------------
    def advance(self):
        """每逻辑帧末调 (engine._logic_frame / driver 逻辑步尾):
        prev <- curr; curr <- 新抓取."""
        models = self._models_ref
        ids, pos, rot, scl = self._grab(models)
        n = len(models)
        self._fit(n)
        # prev = curr (同容量平面整块拷, 与物体增删无关, 行不对齐没关系:
        # 对齐在 render_pose 按 ids 索引重建)
        if self._curr is not None and self._curr.shape[0] >= n and \
                self._prev.shape[0] >= n:
            self._prev[:n] = self._curr[:n]
            self._prev_rot[:n] = self._curr_rot[:n]
            self._prev_scl[:n] = self._curr_scl[:n]
        self._curr[:n] = pos
        self._curr_rot[:n] = rot
        self._curr_scl[:n] = scl
        self._ids = ids
        self._n = n

    def align(self):
        """边界强制对齐 (暂停/加载/进出播放): prev=curr, alpha=0 (无插值)."""
        if self._curr is not None and self._prev is not None:
            n = getattr(self, '_n', 0)
            if n:
                self._prev[:n] = self._curr[:n]
                self._prev_rot[:n] = self._curr_rot[:n]
                self._prev_scl[:n] = self._curr_scl[:n]
        self.alpha = 0.0
```

```python
    # ---------------- 渲染帧插值 ----------------
    def render_pose(self, alpha, models):
        """渲染帧调: 产出插值平面 (N,3)x3, 返回 (pos, rot, scl) 只读视图.
        全 numpy 向量化; 不回写 GameObject (R3).
        新增物体 (ids 匹配不到 prev 行): prev 行用 curr 行填 (首帧不插值);
        消失物体: 多余行不产出 (输出按当前 models 行序)."""
        self.alpha = float(alpha)
        n = len(models)
        if self._curr is None or n == 0:
            return None, None, None
        # 当前 models 的 id 序 + 每个物体在 _ids 里的行号 (-1=新增)
        cur_ids = np.fromiter((id(m) for m in models), dtype=np.int64, count=n)
        # self._ids 是上逻辑帧抓取序; curr 平面行序 == _ids 行序
        search = np.argsort(self._ids[:self._n])
        loc = search[np.searchsorted(self._ids[:self._n][search], cur_ids)]
        loc[cur_ids != self._ids[:self._n][np.minimum(loc, self._n - 1)]] = -1
        valid = loc >= 0
        rows = np.where(valid, np.minimum(loc, self._n - 1), 0)
        a = self.alpha
        # pos lerp (新增物体: prev 行=curr 行 → lerp 恒等 curr)
        np.subtract(self._curr[:n], self._prev[rows], out=self._out[:n])
        self._out[:n] *= a
        self._out[:n] += self._prev[rows]
        # rot 小角度 angdiff: d = (curr - prev + π) mod 2π - π
        d = self._curr_rot[:n] - self._prev_rot[rows]
        d = (d + np.pi) % (2.0 * np.pi) - np.pi
        self._out_rot[:n] = self._prev_rot[rows] + d * a
        # scl lerp
        np.subtract(self._curr_scl[:n], self._prev_scl[rows], out=self._out_scl[:n])
        self._out_scl[:n] *= a
        self._out_scl[:n] += self._prev_scl[rows]
        return self._out[:n], self._out_rot[:n], self._out_scl[:n]

    def interp_position(self, m):
        """单物体渲染帧位置 (脚本相机跟随便捷 API, 报告 4.5):
        先 render_pose 缓存平面, 再按物体查行. 逻辑状态零读取污染."""
        models = self._models_ref
        pos, _r, _s = self.render_pose(self.alpha, models)
        if pos is None:
            p = m.position
            return (p.x, p.y, p.z)
        try:
            i = models.index(m)          # 500 物体内 O(n) 可接受 (相机仅 1 次/帧)
        except ValueError:
            p = m.position
            return (p.x, p.y, p.z)
        return (float(pos[i, 0]), float(pos[i, 1]), float(pos[i, 2]))
```

   (RNE 与原 np.array(dtype=f32) 逐位同); GL 路径全程 f64 不变。
