  - FixedStepClock accumulator (Unity FixedUpdate 对齐): 逻辑帧固定

    maximum_logic_delta 死亡螺旋保险 + time_scale
  - 渲染帧位置 = prev/curr 两逻辑帧快照 numpy 插值 (alpha, ursina
    club_bear 模式), 插值只喂渲染矩阵不回写逻辑状态
  - 脚本 dt 语义已核实安全 (scripts.py 全 dt 驱动, 30Hz 转速不减半)
  - 三条路径全接: 播放器 pygame run() / 编辑器 Qt paintGL /
    Vulkan scene_driver (interp_state.py 单实现双端共享)
  - 帧内流水线 (第二阶段): 物理线程化优先 (Jolt step 释放 GIL,
    Panda3D 任务链三件套对齐), 纯 Python 段靠重叠不靠并行
  - 分批: 分离批1 (core_clock+播放器) → 分离批2 (插值层+vk) →
    分离批3 (编辑器 Qt) → 分离批4 (物理线程化 P-A) → 分批5+
  - 逃生门: LOOM_NO_SPLIT=1 / 'logic_fps'<=0 = 回退旧绑死模式
  - 红线 R1-R9 全适用; R3 逐位=逻辑状态零改动, 新增插值对拍

  P0 低风险四件套 (CPU 侧, 预期 40-50→85-110FPS, GPU% →65-80%):
    ① 静止世界矩阵/AABB 缓存 (与多物体批步6 同源, 合并做)
    ② shadow_bounds 下池 + 角点向量化 (与多物体批步1 同源, 合并做)
    ③ buckets 材质行 SoA 化 (1.22→0.3)
    ④ 网格线零上传 (shader uniform 传淡出, 消 6×13KB/帧)
  P1 中风险 (需用户逐项拍板): 法线矩阵逐顶点 inverse() 挪 CPU 预算
    (每帧省 100 万次 3×3 求逆) / 阴影 pass 恢复背面剔除 (历史 acne
    决策需靶场验证) / MSAA 4x 去留 (视觉决策, 关掉省 4x 带宽+resolve) /
    ortho 阴影盒被 104×104 地面撑大 2.7x 收紧。
