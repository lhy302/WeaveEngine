二、红线清单 (每一批都适用, 违反 = 重做)
--------------------------------------------------------------------
  R1 物理睡眠/唤醒语义 (physics_bridge P1 修复 _b①②) 一行不动:
     _free 自由积分 / 策略 R guard / 残速死带 / 睡眠体速度归零 /
     静态体被移动→KINEMATIC 销毁重建。
  R2 static-static 碰撞对不可按 motion type 跳过: 引擎几何碰撞与 Jolt
     无关, "静态体+脚本"今天收 on_collision_start 事件。broadphase 只能
     做几何超集剪枝, 不能按运动类型过滤。
  R3 逐位一致验收 (D6): "逐位 / 1e-7 内"。broadphase / 解析 AABB 等任何
     数值改动必须过逐位对拍; "保守放宽 AABB"捷径明确否决。
  R4 _AABB_PAR_MIN_MODELS=512 闸门不动: miss 行子集重算必须走串行 njit
     (n<512), 勿接 prange (spin 税教训, 组6 治理成果不可回退)。
  R5 禁 gc.disable: 脚本实例天然成环, disable=内存单调上涨 (GC 批铁律)。
  R6 id() 键必须钉住对象本体 (防 CPython id 复用): mesh / mesh.vertices /
     material._rgba 三处, 照抄 _transform_snapshot 铁律模式 (engine.py
     2477-2522)。
  R7 M23 共享材质: 同材质多实例同帧同值; 缓存按 id(material) 存值时必须
     钉住 _rgba 数组对象 (color setter 换新数组, engine.py:694-698)。
  R8 变长子集重算的堆叠缓冲必须 grow-only (按 (V组,线程) 最大 n 分配 +
     [:n] 切片), 防止按 (gi,n,V) 键各存一份的 O(N²V) 内存爆炸。
  R9 一组 = 一个改动单位: 改前全量测试绿+基线探针 → 只动工作区 → 改后
     全量测试 + A/B 截图 NCC ≥0.99 + 探针对照 → 汇报待用户实测。
  R10 编译/打包只在用户明确指令时做, 绝不主动问。
