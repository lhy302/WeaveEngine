## 三、改写硬规则

1. 凡本规则包覆盖的指标 → **一律替换为 §一 的数值**，并紧跟口径标签
   （探针名 + 帧数/秒数 + 场景），例如 `（editor_core_check 12s 播放口径）`。
2. 凡 §二 列出的作废值 → 删除或改写为「已作废（原因…，见 M2_权威数字表_20260908.md）」，
   **不得保留原值**，也不得改写成新的近似值。
3. 同一指标在多份文档里必须同值；口径不同必须显式标注，禁止并列成 A/B 结论。
4. 每处修改保留可回溯线索（产物文件名，如 `tests\_tmp\editor_core_verdict_r1.json`）。
5. 只做定点修改：**不重排、不美化、不删改与本规则无关的技术内容**。
6. 文件编码：一律 **UTF-8 无 BOM**（`M2_*` 文档与台账现状即如此，勿改）。
7. 不要修改 `M2_权威数字表_20260908.md` / `M2_审计问题关闭清单_20260908.md` 本身
   （它们是判据源）；也不要动 `tests\_tmp` 下的脚本与 json。
