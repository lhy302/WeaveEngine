2.1 新增脚本 ROOT\tests\_tmp\refresh_registry_sha.py (UTF-8 无 BOM, py_compile 0)
    · 参数: --root <引擎根>, 默认 = 脚本上两级目录 (tests\_tmp → tests → ROOT)。
    · 逐条目计算 path 所指文件 SHA256 (小写十六进制) 并写回 sha256 字段。

      自身 SHA256 (写回前 + 写回后)。

    ★path 基准实测校准 (实现偏差, 已按加载器语义修正):
      任务书写「以 registry.json 所在目录为基准解析 path」, 但实测该口径会得到
      core_components\core_components\module_ref.dll (不存在) → 首轮运行直接 ERROR。
      原因: module_registry.py::assemble(base_dir=None) → base_dir=_ENGINE_ROOT,
      _load_entry/_sha_gate 都是 os.path.join(self.base_dir, entry['path']),
      即真实 registry.json 里的 "core_components/module_ref.dll" 是**引擎根相对**。
      因此脚本采用「先 registry.json 目录、再引擎根」的双基准解析, 并在每条输出
      标注实际命中的基准 ([基准=引擎根]); 两种布局都能正确回填, 且与加载器一致。
