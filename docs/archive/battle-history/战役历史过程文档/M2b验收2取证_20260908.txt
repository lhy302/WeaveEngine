4.2 问题 a) 文档旧 A/B 行「ON 66.2% / 62.7% / 8.038 ms / 78 FPS / 379%」
         能否复现？—— **不能复现。**
   逐项对照（旧行值 → 本轮 ON 三轮实测 66.06/68.64/79.66 等）：
   * 最高核 busy% ：旧 66.2 vs 实测 66.06 / 68.64 / 79.66
                    仅 R1 接近（差 0.14），R3 偏离 +13.46；无稳定复现。
   * 主线程 busy% ：旧 62.7 vs 实测 64.76 / 66.71 / 64.50 —— 三轮**全部高于**旧值
                    （+2.06 / +4.01 / +1.80），方向性不符。
   * 主线程 ms/帧 ：旧 8.038 vs 实测 8.634 / 9.138 / 8.487 —— 三轮**全部高于**旧值
                    （+0.596 / +1.100 / +0.449）。
   * FPS         ：旧 78 vs 实测 75 / 73 / 76 —— 三轮**全部低于**旧值。
   * total_core% ：旧 379 vs 实测 212.33 / 209.01 / 303.62 —— 无一达到 379，
                    最大观测值仅 303.62（且出现在 ON R3）。
   旁证：历史 ON 物证 editor_core_on_pre_batch_20260908.json 为
         65.37 / 65.02 / 8.128 / 80 / 211.59 —— 同样与旧行不符。
   → 结论：旧 A/B 行在本机全部 4 次实测（历史 1 次 + 本轮 3 次）中均未复现，
     其中 379% 从未出现。该行数据无物证支撑，应作废。

4.3 问题 b) 是否存在「进程总并行度显著提升（如 379% vs 227%）」的证据？
   ON 与 OFF 的 total_core 实测：
     ON  : 212.33% / 209.01% / 303.62%   均值 241.65%   核当量 2.12 / 2.09 / 3.04
     OFF : 221.21% / 276.15% / 296.01%   均值 264.46%   核当量 2.21 / 2.76 / 2.96
   逐轮对比：R1 ON(212.33) < OFF(221.21)  −8.88 pt
             R2 ON(209.01) < OFF(276.15)  −67.14 pt
             R3 ON(303.62) > OFF(296.01)  +7.61 pt
   → 三轮中仅 1 轮 ON 略高（+7.61 pt），而 ON 档自身 total_core 的样本标准差高达
     53.69 pt（极差 94.61 pt），该 +7.61 pt 完全落在轮间噪声内。
   → ON 均值（241.65%）**低于** OFF 均值（264.46%），与「提升」方向相反。
   → **不存在**「并行度显著提升」的证据；文档所称 379% 与基线 227% 均未实测到
     （实测 OFF 均值 264.46%，亦非 227%）。「并行度翻倍」结论作废。
