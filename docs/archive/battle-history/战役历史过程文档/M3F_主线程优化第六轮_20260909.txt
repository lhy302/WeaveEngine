二、根因与改动 (engine._upload_lights)
--------------------------------------------------------------------
旧代码对每个平行光**无条件**取 VP:
    vp = (self._light_vps or {}).get(light.guid)
    if vp is None: vp = self._dir_light_vp(light)      # ← 内部算全场景 AABB
`_dir_light_vp` 会调 `_model_aabbs_par(self.models, ...)` (501 物体包围盒) +
场景界计算。当**没有任何光源开阴影**时 `_light_vps` 恒空 → 每帧重算 → 18 ms。

而着色器读 `u_light_ortho[i]` 只有两处:
  (a) `u_light_mode[i] > 0.5` (beam 光束截面遮罩);
  (b) `u_shadow_slot[i] >= 0` (阴影采样)。
⇒ full 模式且无阴影的平行光**根本不用**该 uniform。

**改动** (零视觉变化, 默认场景行为逐位不变):
    if light.shadow or light.mode == 'beam':
        vp = (self._light_vps or {}).get(light.guid)
        if vp is None: vp = self._dir_light_vp(light)
        if vp is not None: b['orthos'][i] = np.asarray(vp, dtype='f4').ravel()
