6. 环境/纪律速记 (前棒全有效, 本棒新增)
--------------------------------------------------------------------
- py 一律 -3.12; MSVC 2022 Community vcvars64; cl /nologo /utf-8 /O2 /LD /MD;
  禁 /fp:fast (保求和序)。
- .bat 必须 CRLF; .py/.c 用 LF; UTF-8 无 BOM。
- 引擎根路径含括号 → bat 里 pushd 后用 .\ 前缀, 勿把含括号变量塞进 if (...)。
- 探针惯例: BASE 三层 dirname + sys.path.insert(core_components) + os.chdir;
  结尾 ALL PASS/exit 0; 可能硬崩的调用一律子进程+超时。
- ★新: 子进程捕获输出时给子进程传 PYTHONIOENCODING=utf-8, 否则 GBK 输出按
  UTF-8 解码会丢中文标记; 探针 print detail 前做编码兜底 (见 module_fuzz_check
  的 _safe())。
- crash_reporter.write_dump 限流同分钟 2 个; 探针产生的 .dmp 堆积在 崩溃日志\
  (本棒清理过一次, 保留最近 3 个作证据)。
- build_all.bat skip_checks 有一条无害 stderr 噪音 ('nels.bat' is not recognized,
  疑与 build_ckernels.bat 的 LF 行尾解析有关, EXIT 仍 0) — 留待 M2 统一处理。
