# 历史归档说明

> ⚠️ **本目录下的文档是"过程记录"，不是"当前设计"。**
> 检索设计资料时请**排除本目录**，只读 `docs/design/` 与 `docs/guides/`。
> 这里的文档保留价值在于：追溯决策来龙去脉、复盘踩过的坑、查看某轮优化的原始取证。

---

## 目录内容

### `battle-history/` —— 战役历史过程文档（M1~M3）

DLL 化战役每"棒"的交接文档与验收报告。命名规律：
- `M1交接文档_*.txt` / `M1验收报告_*.txt` —— M1 契约层（自愈架构/注册表/加载器）
- `M2*_*.txt` —— M2 管线 C 化（pipeline.dll）全过程
- `M3*_*.txt` —— M3 主线程优化逐轮记录
- `_R3改写规则包/台账*` —— R3 文档改写规范
- `任务清单.txt` / `下阶段优化工作引导.txt` / `库性能优化*.txt` —— 阶段性任务与方向
- `DSH工作记忆.txt` —— 早期工作记忆

**用途**：想查"某个决策为什么这么定""某轮优化怎么做的"，来这里翻。当前状态请以 `docs/audit/` 与 `docs/handoff/` 为准。

### `engine-study/` —— 性能考察报告

第三方引擎（Panda3D/Ren'Py/pyglet 等）考察、性能优化实施设计、诊断报告。
- `考察报告/` —— 开源引擎可借鉴技术调研 + 各类优化实施规格
- `抢救_*.txt` —— 会话崩溃后抢救重写的内容
- `下载清单.txt` —— 考察素材下载清单

**用途**：想抄某个渲染/批处理技巧，或查某轮性能优化的设计依据，来这里翻。
