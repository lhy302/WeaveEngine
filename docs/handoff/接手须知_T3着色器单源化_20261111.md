## 5. 已踩过的坑（**看这一节能省一天**）

### 5.1 naga（wgpu 0.33）的能力边界

> **解释器警告**：以下结论全部在 `py -3.13`（3.13.15 + wgpu **0.33.0**）上实测。裸 `python` 是 3.12.10 + wgpu **0.32.0**；换解释器复跑会得到不同结论，不要混用。

| 写法 | 结果 |
|---|---|
| GLSL 直喂 wgpu（含任何 sampler） | ❌ `NotImplemented("variable qualifier")` |
| GLSL → glslang → SPIR-V（无描述符/UBO/SSBO） | ✅ |
| SPIR-V 用**合并采样器** `sampler2D` | ❌ `invalid id %14` |
| SPIR-V 用**分离采样器** `texture2D`+`sampler` | ✅ **必须这样写** |
| 比较采样器 | 必须 `uniform samplerShadow`（写 `sampler` → `inconsistent comparison sampling`） |
| `texture2DShadow` 类型 | ❌ 不存在，glslang 语法错 |
| WGSL 的 `inverse()` / 矩阵÷标量 | ❌ 不支持（曾用伴随矩阵+行列式绕过） |

### 5.2 实例数据的两条打包路径（重要）

| 路径 | 触发 | 打包内容 |
|---|---|---|
| 慢路径 `_prepare_bucket_frame`（Python） | 无快路径时 | `st` staging 24 f32 |
| **快路径** `_bucket_pack_frame` → C `loom_bucket_pack` | A/B 夹具与常规播放 | `main_st`：world16+sat1+color4+**matv 3**（2c 补上） |

→ 往 staging 里写字段时，**必须同时改快路径**，否则该字段永远不会进 GPU。

### 5.3 阴影采样

- GL 与 VK 都是 **9 tap 手工比较**（GL 从 `sampler2DShadow` 硬件 PCF 改过来，边缘 ≤3e-5 软化）。
- GL 的 `texture(uv)`+NEAREST 与 `texelFetch(floor(uv*size))` **逐像素一致**（实测 MAE 0）。
- VK 的点光阴影是 `texture_2d_array` + `texelFetch`，**需要 non-filtering sampler（binding 4）**。

### 5.4 宏层维护

- `loom_shader_compat.glsl` 里 `#ifdef LOOM_VK` **只允许出现在这一层**。
- **不要用字符串替换改宏**：续行/缩进容易匹配失败，且会产生 `C7101: Macro redefined`。**整文件重写**更快更稳（本轮已踩过两次）。
