## 3. 怎么跑（顺序固定）

```powershell
# 解释器固定用 py -3.13（3.13.15 + wgpu 0.33.0）；裸 python 是 3.12.10 + wgpu 0.32.0，T3 结论不可混用
# 非交互执行一律先设 LOOM_NO_DIALOG=1（防 VK 回退等阻塞弹窗卡管道）
$env:LOOM_NO_DIALOG='1'
# 1) 回归（单实例！并发跑会互相踩音频设备与 %TEMP% 文件）
Push-Location Loom; py -3.13 tests/run_all.py; Pop-Location

# 2) 冒烟（只回答「能不能跑」，<60s，红了不许打包）
py -3.13 tools/smoke.py                       # 源码模式
py -3.13 tools/smoke.py --dist <引擎目录>      # 编译版，会盖 smoke_passed_at

# 3) 测量（只记录，默认不判阈值）
py -3.13 tools/measure_engine.py --runs 3 --ab "LOOM_BUCKET_PACK=0" --json out.json

# 4) 编译三件（release = 发布档；dev = 带控制台）
py -3.13 tools/build_engine.py --mode release

# 5) 打包（要求 build_info.smoke_passed_at 存在且晚于 built_at）
py -3.13 tools/package_engine_compiled.py --version 0.1.0.beta6 \
   --editor-dist C:\loom_build\engine\build_entry.dist \
   --builder-exe C:\loom_build\builder\build_game.exe
py -3.13 tools/package_engine.py --version 0.1.0.beta6 --allow-missing-runtime

# 6) 包与代码对拍（source 0 不一致 / compiled 引擎等价）
py -3.13 tools/verify_pkg_vs_head.py <source.zip> <compiled.zip>
```

**门序**：编译 → 冒烟（盖章）→ 打包 → 对拍。冒烟红或对拍不一致，**停下报告，不许硬交**。

## 4. 三条硬纪律

1. **四层分工不混**：冒烟只测「能不能跑」；回归测功能；测量只出数字；一次性验证验完必须**收进回归 / 收进测量 / 删掉**。详见分层文档。
2. **组件不互相兜底**：环境适配型降级（VK→GL、可选依赖缺失）可以但要**可见**；缺陷型失败（C 内核错误码、坏字段、坏索引）必须**显式失败**，不许静默降级。
3. **任务后倒查**：任何任务完成后，派**未参与实现**的新子代理独立验证「目标是否达成」（带反例矩阵、复跑数字、不许引用自报值）。

**非交互执行一律设 `LOOM_NO_DIALOG=1`**（run_all/smoke/measure 已内置；自写探针要自己设，否则 VK 回退等对话框会弹到用户桌面并卡住管道）。

## 7. 已知坑（都是本轮真踩过的）

1. **锁源码字符串的测试**会随重构误红（`grep draw_frame`、`if self.effective_skybox()...`）→ 一律改**行为断言**。
2. **只调 helper 的测试**证明不了「引擎用没用上」→ D 批曾因此虚高（helper 2.29x vs 入口 0.79x）。
3. **非密闭夹具**：`ab_env.json` 曾引用 `_tmp/env_*.png`（从未提交）→ 清理 `_tmp` 即挂。夹具必须能由测试自己生成。
4. **盘根污染**：某个探针在 `D:\` 建过 `Assets/assets.json`，之后 D 盘所有工程都被认成项目根 → 已加守卫（盘根不算项目根）。
5. **`core.autocrlf`** 让「包 vs HEAD」对拍出现 24 处假阳性 → 必须 CRLF 归一后比。
6. **并发跑 `run_all`** 会互相踩（音频设备、`%TEMP%` 同名文件）→ 单实例。
7. **弹窗**：任何拉起真实引擎的脚本都要 `LOOM_NO_DIALOG=1`。
8. **`Loom/tests/_tmp/` 里有受跟踪文件**（24 个测试夹具，如 `env_*.png`、ab 脚本）：**清理前先 `git ls-files Loom/tests/_tmp`**，别当成垃圾整目录删（2026-11-11 已踩过一次）。
9. **解释器必须 `py -3.13`**：本机裸 `python` = **3.12.10 + wgpu 0.32.0**，`py -3.13` = **3.13.15 + wgpu 0.33.0**，`Loom/Loom.py` shebang 也是 `python3.13`。T3 的全部 naga/SPIR-V 能力结论（SPIR-V 被接受、分离采样器、`samplerShadow`、`texture2DShadow` 不存在）都是在 **wgpu 0.33** 上实测的；用 3.12 跑像素门/回归会得到不同结果或假失败。
