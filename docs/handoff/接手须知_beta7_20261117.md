## 2. 冷启动清单（照做，别跳）

```powershell
# 0) 环境自检：解释器必须是 py -3.13（3.13.15 + wgpu 0.33.0）
#    裸 python = 3.12.10 + wgpu 0.32.0 —— T3 的 naga/SPIR-V 结论全部建立在 0.33 上，混用会得到假失败
py -3.13 -c "import sys,wgpu;print(sys.version);print(wgpu.__version__)"

# 1) 仓库状态：期望干净；不干净先问清楚再动
git status --short
git log --oneline -5

# 2) 非交互执行一律先设（否则 VK 回退等对话框会弹到桌面并卡住管道）
$env:LOOM_NO_DIALOG='1'

# 3) 全量回归（**单实例**，并发跑会互相踩音频设备与 %TEMP% 同名文件）
Push-Location Loom; py -3.13 tests/run_all.py; Pop-Location

# 4) 着色器链路自检（glslang → SPIR-V，EXIT=0 且产出 13 个 .spv）
py -3.13 tools/build_shaders.py

# 5) 冒烟（只回答「能不能跑」，<60s，红了不许打包）
py -3.13 tools/smoke.py
```

**门序固定**：编译 → 冒烟（盖章）→ 打包 → 包与代码对拍。任一环红，**停下报告，不许硬交**。

## 5. 三条硬纪律

1. **四层分工不混**：冒烟只测「能不能跑」；回归测功能；测量只出数字；一次性验证验完必须**收进回归 / 收进测量 / 删掉**。
2. **组件不互相兜底**：环境适配型降级（VK→GL、可选依赖缺失）可以但要**可见**；缺陷型失败（C 内核错误码、坏字段、坏索引）必须**显式失败**，不许静默降级。
3. **任务后倒查**：任何任务完成后，派**未参与实现**的新子代理独立验证「目标是否达成」（带反例矩阵、复跑数字、**不许引用自报值**）。

**另加两条（beta7 特有）**：

4. **修前必红**：先证明缺陷存在（能复现的红），再修；**修缺陷不许移动基线**。
5. **跳过要留痕**：任何「这次不查/不修」的决定都必须写进文档并说明理由，否则视为系统性放水。

## 7. 已知坑（都是真踩过的）

1. **锁源码字符串的测试**会随重构误红（`grep draw_frame` 之类）→ 一律改**行为断言**。
2. **只调 helper 的测试**证明不了「引擎用没用上」→ D 批曾因此虚高（helper 2.29x vs 入口 0.79x）。
3. **非密闭夹具**：测试引用了从未提交的 `_tmp/env_*.png` → 夹具必须能由测试自己生成。
4. **盘根污染**：某个探针在 `D:\` 建过 `Assets/assets.json`，之后 D 盘所有工程都被认成项目根 → 已加守卫（盘根不算项目根）。
5. **`core.autocrlf`** 让「包 vs HEAD」对拍出现假阳性 → 必须 CRLF 归一后比。
6. **并发跑 `run_all`** 会互相踩（音频设备、`%TEMP%` 同名文件）→ **单实例**。
7. **弹窗**：任何拉起真实引擎的脚本都要 `LOOM_NO_DIALOG=1`。
8. **`Loom/tests/_tmp/` 里有受跟踪夹具**：清理前先 `git ls-files Loom/tests/_tmp`，别当垃圾整目录删。
9. **解释器必须 `py -3.13`**（见第 2 节）。
10. **不要用字符串替换改宏文件**（`loom_shader_compat.glsl`）——整文件重写；**不要只改慢路径**（`_prepare_bucket_frame`），快路径 `_bucket_pack_frame` 才是常态；**不要为了让测试变绿去调阈值或放宽承诺**。
11. **在 DSH 沙箱里跑测试时 `process.env` 是空的**（2026-11-17 实测）：子进程缺 `USERPROFILE` 时 `os.path.expanduser('~')` 退化成一个字面量 `~`，
    于是 `agent_commands._write_roots()` 的白名单根变成「引擎目录\~」→ **`test_agent_commands` 的白名单断言假红**，`test_hub_eai` / `test_hub_interp_cache` /
    `test_hub_interp_switch` 一起假红（共 4 个）。**判据：这 4 个一起红先查环境，别先改代码。**
    做法：从注册表重建真实环境（`HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Environment` + `HKCU\Environment` + `HKCU\Volatile Environment`），
    或直接在真机 PowerShell 里跑。**本次全量回归的真实基线：173.3s 全绿。**
12. **归档 `docs/` 会让「引用 docs 路径的测试」假红**（2026-11-17 实测）：`test_pacman_scene_contract.py` 硬编码 `docs/audit/pacman2d_scene.json`，
    归档把它移进 `docs/archive/v0.1.0-beta3/` 后该测试变红。已改成**候选路径查找**（归档位优先、旧位兼容、两处都没有才 FAIL）。
    **下次再动 `docs/` 结构，先 grep 测试与 `tools/` 里的 `docs/` 路径。**
