# Loom 项目文档总索引

> 本文件是 `docs/` 的**唯一入口**。找设计资料先看这里，不用逐个目录翻。

## 一、接手必读顺序（新 Agent / 新成员）

1. **【最新入口】** `handoff/下一阶段接手总纲_B线收官版_20261016.md` —— **必读第一份**（B 线逃生门退役完成后的靶点清单 + 铁律 + 流程）
2. **【AI 协作规范】** `guides/AI协作实践指南_VibeCoding工程思维落地.md` —— 白盒契约/黑盒实现/人类掌舵（六层纪律）
3. **【架构总览】** `design/架构互联协议总表.md` —— 全工程 8 层互联协议（改动定位速查）
4. **【架构参考】** 工作区根 `代码架构.txt` —— 分层、数据模型、渲染管线、踩坑清单
5. **【设计定案】** `design/DLL化改造可行性方案与执行路径报告.txt` —— DLL 化总纲（v1.3 纯 DLL 架构）
6. **【前 50 项审计事实】** `audit/DLL化工程改造完成度与无损复核审计清单.md` —— 50 项原子审计（二值判定）
7. **【M5 前序交接】** `handoff/下一阶段开工交接与统一接手总纲.md` —— M5 阶段状态（前序；已被新入口续接）
