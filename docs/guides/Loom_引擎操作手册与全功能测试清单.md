# Loom 引擎操作手册与全功能测试清单

> 版本：2026-10-12（代码重构后）
> 项目路径：`D:\my-project\Loom(py源代码-工作区)\Loom\`
> 用途：本手册面向实机测试——逐项操作、逐项打勾。全部测过后可放心继续开发。
> 定位：Loom = Python/PySide6 宿主 + C ABI 动态库 + 嵌入式 Lua 5.4 的 3D 游戏引擎。

---

## 〇、先说实话：Loom 能做什么 / 不能做什么

### ✅ 已支持
- 3D 场景搭建（基元 + .obj 导入），层级父子
- 组件化物体（变换 / 网格 / 材质 / 碰撞 / 刚体 / 音频 / 动画 / 脚本）
- 光照（平行光 / 点光 + 阴影贴图 + 光束截面）
- 摄像机（玩家视角 / 挂父 / 俯仰限制 / 预览）
- 物理（Jolt/Culverin 桥 + 自研回退；碰撞/重力/摩擦/弹性/滚动）
- 脚本（12 内置 + Python 自定义 + Lua 5.4 自定义）
- 输入动作层（可重映射键位）
- 运行时 HUD UI（文字/按钮/进度条）
- 播放模式（编辑态↔播放态切换，改动可丢弃）
- 打包发布（玩家 exe + 加密游戏包）
- MCP 协议（给 AI Agent 全自动操作引擎）

### ❌ 当前不支持（重要，避免误期待）
- **骨骼 / 蒙皮 / 骨架动画**：无。动画系统是"物体级关键帧变换动画"（AnimationClip 插值位置/旋转/缩放），**没有骨骼绑定、没有顶点蒙皮、没有权重**。
- **模型导入**：仅 Wavefront `.obj`（含可选 .mtl 颜色）。不支持 `.fbx / .gltf / .dae`。
- **模型导出**：无（不能把场景物体导出成 .obj）。
- **纹理贴图渲染**：材质仅"颜色 + 饱和度"，不支持贴图。
- **地形/植被/粒子系统**：无。
- **多场景运行时切换**：v1 单场景启动（API 已备，脚本层未接）。

## 一、启动与三种模式

三种入口（都在 `Loom` 目录下执行 `py -3.12 <脚本>`）：

| 模式 | 命令 | 说明 |
|------|------|------|
| **编辑器** | `py -3.12 Loom.py` | 默认 Qt 编辑器，做游戏 |
| **播放器** | `py -3.12 Loom.py --run 场景.json` | 直接跑一个场景（无编辑 UI） |
| **打开项目** | `py -3.12 Loom.py --open 场景.json` | 编辑器打开指定场景 |

其他参数：
- `--benchmark [三角形数] [迭代数]` —— 数学管线基准（不弹窗）
- `--ui qt`（默认）/ `--ui minimal`（极简只读视图）
- `--agent` —— 启动 EAI 命令桥（HTTP 127.0.0.1 + 端口文件，供 MCP/Agent 用）

**AI/自动化调用**（MCP）：见第十三节。

## 二、编辑器界面全貌（Qt 原生）

布局：**工具栏 / 左列（层级+资源）/ 中间视口 / 右列（检查器）**

### 2.1 顶部工具栏
从左到右：
- **→播放** —— 进入播放态（脚本跑起来）
- **⏸暂停TPS**（F9）—— 暂停/恢复逻辑时钟（渲染照跑，世界冻结）
- **⏭步进1帧**（F10）—— 暂停态下步进 1 逻辑帧
- **场景名** 输入框 —— 改场景名
- **保存 / 另存为 / 加载 / 新建**
- **撤销 / 重做**（Ctrl+Z / Ctrl+Y，100 步）
- **移动 / 旋转** —— gizmo 模式切换
- **立方体 / 球体 / 平面 / 导入.obj** —— 加物体
- **复制 / 删除**
- **Prefab 名 + 存模板 / 放实例**
- **发布游戏** —— 打开构建对话框
- **插件**（下拉菜单）—— 插件注册的编辑器按钮

### 2.2 左列上半：层级树
- 顶部按钮行：**+ 平行光 / + 点光源 / + 摄像机 / 显隐**
- 树：显示全部物体/光源/摄像机，父子缩进
- 交互：
  - 左键单击 = 选中
  - 拖到另一物体上 = 挂父（世界位置自动保持）
  - 拖到空白 = 脱父
  - 右键 = 重命名 / 复制 / 删除 / 脱父

### 2.3 左列下半：资源面板
- 显示 `assets/` 下的资产（材质 / 网格 / prefab）
- 双击 = 预览
- 拖到物体 = 应用（材质可拖到层级行上）
- 底部按钮：**应用到选中 / 放入场景**

### 2.4 中间：视口
- 左键 = 点选物体 / 拖 gizmo
- Alt+左键 或 中键 = 轨道相机
- 右键按住拖 = 转视角（Unity 风格，拖出视口仍持续）
- 滚轮 = 缩放

### 2.5 右列：检查器
选中目标后显示对应组件表单（见第四节）。数值框支持：
- 聚焦后底部弹出**拖拽块**，左右拖动调值（每像素 = 行步长）
- 直接输入数字

## 三、物体与建模

### 3.1 添加基元
工具栏 **[立方体] [球体] [平面]** —— 点击即出现在场景中心，自动命名（立方体1/球体1/平面1）。

### 3.2 摆放物体（三选一）
1. **检查器数字框**：位置 x/y/z、旋转 rx/ry/rz（**度**）、缩放 sx/sy/sz
2. **视口 gizmo**：选中后拖手柄（工具栏 [移动]/[旋转] 切换模式）
3. **层级拖拽**：挂父/脱父（见 2.2）

### 3.3 导入外部模型（.obj）
- 工具栏 **[导入.obj]** → 文件对话框选 `.obj`
- 同目录有 `.mtl` 则读取材质颜色
- **轴向**：OBJ 惯例 Y-up 与 Loom 一致，不缩放不转轴
- 导入后作为普通物体，可加组件/挂脚本
- ⚠️ 仅 .obj 静态网格，无骨骼动画

### 3.4 复制 / 删除
- 工具栏 [复制]/[删除]，或层级右键菜单
- 撤销可回退

## 四、组件系统（检查器逐项）

每个物体是一个容器，行为来自挂载的组件。选中物体后检查器自上而下：

### 4.1 变换（Transform）—— 必有
位置 / 旋转(度) / 缩放。写入会自动标记插值快照失效。

### 4.2 网格渲染（MeshRenderer）
- 网格（mesh）
- **材质**：颜色 + 饱和度（共享引用，多物体引用同一材质改一处全变）
- 法线模式：`flat`（面法线）/ `vertex`（顶点径向）
- 基元类型 / 参数（序列化用）
- 显隐开关

### 4.3 材质资产（Material）
- 检查器 [＋新建材质] → 生成共享材质
- 改颜色 / 饱和度 → 所有引用它的物体一起变
- [存材质为资产] → 落 `assets/`

### 4.4 碰撞体（Collider）
- 启用 / 禁用
- 形状：`box`（AABB）/ `sphere` / `none`（纯装饰）
- 摩擦系数 / 弹性 restitution / 滚动摩擦
- **同一棵父子树互相不碰撞**
- 球体网格自动用球体碰撞体

### 4.5 刚体（Rigidbody）
- [＋加刚体] / [移除刚体]
- 质量 mass / 受重力 / 运动学
- 摩擦 / 弹性 / 滚动摩擦
- 速度（运行时）
- 需配合碰撞体才有碰撞体积

### 4.6 音频源（AudioSource，M34）
- [＋加音频源]
- clip（文件路径，wav/ogg）
- 循环 / 音量 / 播放开关

### 4.7 动画（Animator，M35）—— 关键帧变换动画
- [＋加动画]
- clips：`{'动画名': AnimationClip}`，每帧含 time + position/rotation/scale
- 当前动画 / 播放 / 循环
- ⚠️ 这是**物体级关键帧插值**，非骨骼蒙皮

### 4.8 脚本（Script，M27）
- 脚本下拉（12 内置，见第六节）
- 可挂多个，每个有参数行（拖拽滑块调节）
- 参数值随场景序列化

## 五、光照与摄像机

### 5.1 光源
层级顶部 **[+ 平行光]**（太阳）/ **[+ 点光源]**（灯泡）。

检查器可调：
- 强度 / 颜色（r,g,b）
- 平行光：**朝向 / 俯仰 / 倾斜**（度）
- 模式：`full`（全场景）/ `beam`（光束，带截面形状 circle/rect + 尺寸）
- 阴影开关（默认开；关 = 光穿墙）

⚠️ **场景默认无光源 = 全黑**（设计如此，提醒手动加光）。

### 5.2 摄像机
层级顶部 **[+ 摄像机]**。

检查器可调：
- 位置 / yaw / pitch / roll（度，roll = 侧头）
- FOV（视角广度）
- 玩家可调开关（fov_locked）
- 俯仰角限制
- [设为激活相机]（决定玩家视角）/ 再点取消
- [用此相机预览]（编辑器视口切到该相机，Esc 退出）
- 可挂父（拖到物体行 = 随物体走）

没有激活相机 → 默认轨道视角。

## 六、脚本系统

### 6.1 内置脚本（12 个）

| 脚本名 | script_id | 作用 | 主要参数 |
|--------|-----------|------|----------|
| 自转 | `rotate` | 绕自身轴转 | X/Y/Z 速度° |
| 公转 | `orbit` | 绕中心转圈 | 中心 X/Y/Z、转速 |
| 浮动 | `bob` | 上下正弦浮动 | 幅度、频率 |
| WASD移动 | `wasd_move` | 沿世界轴移动（演示） | 速度 |
| 相机跟随 | `camera_follow` | 相机盯住物体 | 高度偏移、距离偏移 |
| 重力落地 | `fall` | 自由落体 | 重力 |
| 弹跳 | `bounce` | 落地反弹 | 重力、弹力 |
| 第一人称 | `first_person` | WASD+鼠标转向+跳跃（需刚体） | 速度/眼高/灵敏度/跳跃速度 |
| 第三人称 | `third_person` | 同上+相机跟后方 | 速度/距离/高度/灵敏度 |
| 跳跃 | `jump` | 按'跳跃'给向上速度（需刚体） | 跳跃速度 |
| 触碰计数彩球 | `count_touch` | 玩家碰到 → 消失+HUD 计数 | 无 |

**玩家角色标准件**：立方体/球体 + [＋加刚体] + [第一人称]（或[第三人称]）→ 播放后 WASD 走、鼠标转视角、空格跳。

### 6.2 自定义 Python 脚本（热加载）
在 `scripts.py`（或游戏脚本目录）加一个类：

```python
from engine import Point3D

@register
class MyHudScript(Script):
    script_id = 'my_hud'          # 小写蛇形，序列化用
    name = '我的HUD'
    params = (('n', '文字', 6.0, 0.0, 99.0, '%.0f'),)   # (key, label, default, vmin, vmax, fmt)

    def on_start(self):           # 播放开始
        self.v = 0.0

    def update(self, dt):         # 每帧 (dt 秒)
        e = self.engine
        e.ui.text("你好游戏: %d" % self.v, 20, 60, 24)
        self.v += 1
```

保存后编辑器脚本下拉立刻出现（不用重编译）。

### 6.3 自定义 Lua 脚本（M4，嵌入式 Lua 5.4）
- 放 `.lua` 到 `scripts/` 目录，引擎自动生成动态脚本类注册
- 通过 `script_glue.LoomLuaScript` 桥接至 script.dll 的 Lua VM
- 可绑定 entity 位置/旋转、读输入动作、绑相机

### 6.4 脚本可用引擎 API
```python
e = self.engine
e.get_action('跳跃')              # 输入动作 (推荐)
e.is_key('w')                    # 直接查键
e.mouse_rel                      # 鼠标相对移动
e.pressed                        # 当前按下的鼠标键
e.move_with_collision(obj, dx,dy,dz)   # 带碰撞移动 (被挡返回 True)
e.get_collisions(obj)            # 当前重叠物体列表
e.add_model(...) / e.remove_model(obj)
e.play_sound(path, vol)
e.ui.text(...) / e.ui.button(...) / e.ui.bar(...)
e.camera_target / camera_yaw / camera_distance   # 轨道相机
```

## 七、输入动作层（M30b）

**动作**（玩家想做什么）绑定到键名。默认：

| 动作 | 默认键 |
|------|--------|
| 向前 | w / Up |
| 向后 | s / Down |
| 向左 | a / Left |
| 向右 | d / Right |
| 跳跃 | space |
| 交互 | e |
| 加速 | Shift |

- 改键：编辑 `输入配置.json`（`{"向前": ["w","Up"], ...}`），缺失/坏文件回退默认
- 脚本恒写动作名，改键不动脚本

## 十、打包发布全流程（Unity Build 对标）

### 10.1 整车流程
```
游戏材料(场景/物体/脚本/插件)
  → 编辑器制作 (Loom.py)
  → [发布游戏]
  → 发布夹 = MyGame.exe (玩家运行时, 无编辑器) + 游戏包.lsc
      (场景+游戏脚本+插件+配置, 加密打包; 与 exe 同夹不可分离)
  → 玩家双击即玩, 无明文素材/脚本
```

### 10.2 材料开发
- 用编辑器摆场景、挂内置脚本
- 游戏自定义脚本放 `Loom\scripts\`（或游戏脚本目录），引擎启动自动加载注册
- [→播放] 试玩 → 保存（开发期场景明文，发布时才加密）

### 10.3 发布（二选一）
**A. 编辑器 [发布游戏] 按钮** → 对话框（游戏名/公司名/窗口标题/启动场景/脚本目录/输出目录）→ [构建]

**B. 命令行（CI 可用）**：
```powershell
py -3.12 build_game.py --name 跳台试炼 --company "DSH实验室" `
    --scene 场景.json --game-scripts scripts --output 发布夹
```
首次或引擎更新：`py -3.12 build_game.py --build-runtime`（Nuitka 打玩家运行时）

安全模式：`--protection secure|open`（默认 secure = 加密+哈希互验防作弊；open = 明文放行 MOD，需加 `--no-encrypt-content`）

### 10.4 构建器内部（build_game.py）
读明文场景 → 收集脚本目录 .py 源码 → 加密打包 `游戏包.lsc`（config + scene + scripts + externals + 插件哈希）→ 拷贝玩家运行时 → 组装发布夹。

### 10.5 玩家启动链（game_player.py）
```
load 游戏包.lsc (缺包报错 = _Data 缺失)
  → register_sources (脚本注册, 未注册脚本静默跳过)
  → install_game_plugins (玩家插件 .lpc 装入, 与 .lsc 哈希互验)
  → PlayerApp(scene_data, title) 直接喂场景 (场景不出明文)
  → 运行; 窗口标题 = 游戏名
```

### 10.6 发布夹与玩家操作
- `MyGame.exe + 游戏包.lsc`（同夹不可分离；obj/音频素材引用相对路径时整夹放）
- 玩家：双击即玩 / WASD / 鼠标视角 / 空格跳 / Tab 鼠标锁 / F11 全屏 / 关窗退出

### 10.7 限制
- 单场景启动 / 无 exe 图标 / 多场景列表 v1 未做
- 保护等级 = secure（压缩+XOR+base64，防窥非绝对加密）/ open

## 十二、MCP 协议接入（给 AI Agent）

Loom 内置 MCP 服务 `loom_mcp.py`（JSON-RPC 2.0 over stdio），让大模型全自动操作引擎。

### 架构
```
LLM 客户端 ──MCP stdio──▶ loom_mcp.py ──HTTP 127.0.0.1──▶ 引擎进程内 AgentService
```

### 前置
引擎需以 `--agent` 启动 → 在引擎目录写 `.agent_port.json`（port/token/pid）。

### 配置（Claude Desktop / Cursor）
```json
{
  "mcpServers": {
    "loom": {
      "command": "py",
      "args": ["-3.12", "D:\\my-project\\Loom(py源代码-工作区)\\Loom\\loom_mcp.py"]
    }
  }
}
```

### 24 个工具（Unity 对齐）
- **场景**：`unity_scene_new/save/load`
- **实体**：`unity_gameobject_create/list/select/delete/duplicate/set_parent`
- **组件**：`unity_transform_set / unity_material_set / unity_collider_set / unity_rigidbody_set`
- **脚本**：`unity_script_add/remove/write_file`
- **测试**：`unity_playmode_toggle / unity_capture_viewport`（截图）
- **发布**：`unity_build_player`
- **排查**：`diag_get_engine_metrics / diag_get_console_logs / diag_inspect_gameobject / diag_check_dll_integrity / diag_check_crash_dumps`

### Resources
`loom://scene/active` / `loom://engine/metrics` / `loom://engine/logs` / `loom://engine/dll_registry`

### Prompts
`diagnose_engine_issue` / `create_player_character`

## 十四、常见问题

**Q: 场景全黑？**
A: 没加光源。层级顶部 [+ 平行光]。

**Q: 物体掉下去穿透地面？**
A: 检查：① 地面有碰撞体且启用；② 物体加了刚体；③ 两者不在同一父子树。

**Q: 脚本改了没生效？**
A: Python 脚本改 `scripts.py` 后需重启编辑器；游戏脚本放 `scripts/` 目录随启动加载。

**Q: 播放后改动丢了？**
A: 设计如此（Play Mode 隔离）。想保留就停止后手动改，或复制 Prefab。

**Q: 能导入带骨骼的 FBX 吗？**
A: 不能。Loom 不支持骨骼蒙皮，也不支持 FBX/glTF。仅 .obj 静态网格。

**Q: 怎么做角色动画？**
A: 用 Animator 关键帧变换动画（整物体移动/旋转/缩放），或脚本程序化驱动。无骨骼级动画。
