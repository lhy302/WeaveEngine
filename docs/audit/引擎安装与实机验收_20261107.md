# 引擎安装与实机验收（LoomHub 流程，2026-11-07）

## 流程（按既有文档《使用操作指南.txt》与 LoomHub 既有代码）

1. `python tools/package_engine.py --version 0.1.0.beta3` → `tools/dist/Loom-0.1.0.beta3.zip`（298MB，含嵌入式 Python 3.12 + 引擎源码 + Loom.bat）；
2. 把 zip 交给 **LoomHub**（`HubController.do_install_zip`，与 LoomHub GUI 的"安装 .zip"同一入口）→ 解压到 `C:\Program Files\Loom\0.1.0.beta3\` 并登记解释器；
3. 用**安装后的引擎**启动编辑器（`<安装目录>\python\python.exe <安装目录>\Loom\Loom.py --agent`）；
4. 用**安装后的 MCP**（`loom_mcp.py`）经 stdio JSON-RPC 操作，做一个简单游戏并试玩。

## 修复的流程缺陷（本次发现）

`package_engine.py` 的 `--version` 只改 zip 文件名，**没写进包内 `解释器.json`** → LoomHub 按元数据登记，
实测把 beta3 包装成了 `0.1.0.beta2`（安装目录/版本号错乱）。已在 `make_zip()` 里把请求的 version 回写包内元数据，
重打后安装目录为 `C:\Program Files\Loom\0.1.0.beta3\`，元数据 `version=0.1.0.beta3`，LoomHub 解释器列表正确。

## 一个被安全设计拦住的"测试错误"（记录，非缺陷）

首轮把视口截图路径放在 `<安装目录>\_e2e_shots\`，被引擎的截图白名单拒绝：
`screenshot 越域: ... (白名单: 程序目录/场景目录/用户目录)`。改到场景目录 `Loom\Projects\_shots\` 后通过。
说明白名单**真的在生效**。
