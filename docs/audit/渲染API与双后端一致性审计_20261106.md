# 渲染 API 与双后端一致性审计（2026-11-06）

> 审计对象：渲染 API 选择/切换链路 + OpenGL / Vulkan 双后端行为一致性
> 判定基准（白盒契约）：`GPU性能优化-Vulkan双后端方案.txt` §4/§5、`docs/design/架构互联协议总表.md` §3/§4
> 方法：粗筛 → 双向推演 → 可执行探针；两名独立子代理交叉复核（只读）

---

## 0. 结论

- **切换链路**：修复后可用（`--backend` > 游戏配置.json > 设置 > 默认；`auto` 真的会回退）。
- **"自由切换"尚未达标**：Vulkan 后端在**输入、场景相机、动画/音频组件、材质(PBR)/天空盒/LOD、Canvas UI/HUD** 上与 OpenGL 不对等，切换后同一游戏"少东西"，且多数是**静默降级**。

## 2. 未修复（需排期，按严重度）

### P0（阻断"自由切换"语义）
1. **Vulkan 无任何输入回调**：`vk_player.py` 未注册 glfw key/mouse callback → `key_state` 永不写入，`is_key/get_action` 恒 False（GL 有完整输入层）。
2. **Vulkan 忽略场景相机**：`scene_driver` 只用轨道相机参数，不应用 `active_camera`（GL 在 `runtime.py:56-62` 应用）。
3. **组件静默丢失**：`scene_driver.build_models` 不恢复 `animator / audio_source / material(PBR) / LOD`；实测 `m.animator=None`、`m.audio_source=None` → 切到 Vk 后动画不动、无声、材质降级且无告警。
4. **默认 `render_api=vulkan` + 无 GUI auto 选项 + 静默闪退**：无 Vk 的机器双击即退；`auto` 只在启动期 `Exception` 生效，`SystemExit` 与 `vk_player` 的 `os._exit()` 绕开回退。

### P1
5. `loom_render` 有、`vk_renderer` 无：**PBR(metallic/roughness)、环境反射 cubemap、天空盒、LOD、Canvas UI(`ui.draw_all`)、HUD 文字、聚光灯**。
6. 灯上限 4（Vk） vs 8（GL），超出静默丢弃；点光无阴影、仅首盏平行光有阴影。
7. 脚本 API 面：Vk 17 项 vs GL 87 项（缺 `raycast/draw_lines/add_model` 等）。
8. `WGPU_BACKEND_TYPE` 用 `setdefault` 可被环境静默改写真实后端，且不打印 `backend_type`。

### P2
9. 设置文件按 `argv[0]` 定位，仓库内散落 3 份 `设置.json`。
10. 非法值静默归一；`nan/inf` 钳制回落到 default。
11. 相机距离上限 1000 == far 1000，正好落在远平面（深度测试边界，见 P-14/H-01）。

## 5. Vulkan 渲染对齐进展（2026-11-06，逐项 A/B 验收）

**验收工具**：`Loom/tests/_tmp/ab_gl_vk.py` —— 同一场景/相机/分辨率，GL 离屏与 Vk 离屏各渲一遍，
输出 MAE / MAX / NCC 与并排图、差异热图。**这是"渲染效果一致"的唯一口径**。

| 场景 | 对齐前 MAE | 对齐后 MAE | 说明 |
|---|---|---|---|
| 单个立方体（无阴影） | 0.0000 | 0.0000 | 基线：几何/投影/实例缓冲完全一致 |
| 平行光 | 0.0000 | 0.0000 | 基线 |
| 平行光 + 点光 | 0.0046 | **0.0016** | 补点光 range 衰减 |
| 仅点光 | 0.0074 | **0.0026** | 同上 |
| 仅聚光 | 0.0394 | **0.0085** | 补聚光内外锥 |
| 平行光 + 阴影 | 0.0690 | **0.0001** | 修阴影采样 V 轴镜像（见下） |
| 混合场景（4 物体/2 灯/阴影） | 0.0616 | **0.0001** | 补灯光字段白名单 + 深度附件后重测 |
| **PBR 材质（metallic 0.9 / rough 0.25）** | 无（Vk 无 PBR） | **0.0000** | 双路累加与 GL 逐式一致 |
| **天空盒（纯色）** | 无（Vk 无天空盒） | **0.0000** | 全屏三角 + 反投影 cube 采样 |
| 聚光（含 range/锥角） | 0.0394 | **0.0000** | 修正灯光字段白名单 |
| **点光阴影**（6 面） | 无（Vk 无点光阴影） | **0.0001** | 仅 44 px >0.05（PCF 边缘，GL 是 3x3 软阴影） |
| **贴图（棋盘 albedo，含 mip）** | 无（Vk 无纹理） | **0.0000** | 逐像素一致；mip 生成修过一次 uv 归一错误 |

### 本轮修复的 5 个 Vk 缺陷

| # | 缺陷 | 证据 | 修复 |
|---|---|---|---|
| V-01 | 灯数上限 4（GL 8），超出静默丢弃 | `_pack_scene` 固定 4 灯 + `SceneC` 只到 l3 | 扩到 8 灯（cnt/cnt2 + l4..l7），场景块 720B→1392B，绑定尺寸同步 |
| V-02 | 聚光灯被当作点光（无锥角） | `kind` 只有 0/1；A/B 仅聚光 MAE 0.039 | `kind=2` + `extra=(cos_inner,cos_outer,range)` + WGSL 锥角衰减 |
| V-03 | 点光缺 Unity `range` 边缘衰减 | 与 GL `fade=(1-d²/r²)²` 对齐前差异 0.005 | 补 fade |
| V-04 | **阴影采样 V 轴镜像**（严重） | wgpu 纹理 v=0 在顶部、GL 在底部；A/B 平行光阴影 MAE 0.069 | uv.y 取反 → MAE 0.0001 |
| V-05 | 真窗口交换链用 `*-srgb`，与着色器手工 `pow(1/2.2)` 叠加 → 二次伽马 | `vk_player` 实测 format=`bgra8unorm-srgb` | 改用非 srgb 格式（失败才回退并告警） |
| V-06 | **无 PBR**：PBR 材质切到 Vk 静默退化为 Blinn-Phong | `vk_renderer` 无 metallic/roughness | 实例槽 8 余量存 (metal, rough, pbr) + WGSL Cook-Torrance 双路累加；A/B MAE 1e-5 |
| V-07 | **无 LOD**：Vk 播放器远处物体不降模（画面/性能不一致） | `scene_driver` 无 `_update_lod` | 逐行照搬 GL 判定（距离/屏幕占比/bias），世界位置用同一套 S@R@T；对拍 GL/VK 选模一致 |
| V-09 | **无天空盒**：Vk 播放器背景恒为清屏色 | `vk_renderer` 无天空管线 | 全屏三角 + 反投影采样 cube；A/B MAE 0 |
| V-10 | **灯光字段白名单丢参**：`range/spot_inner/spot_outer` 未透传 → 点光 range 恒 10、聚光锥恒 30/60 | `scene_driver.build_lights` 白名单 | 补三项；聚光 A/B 从 MAE 0.0085 → **0.0000** |
| V-11 | **A/B 工具自身缺陷**：GL 侧离屏 FBO 无深度附件 → 天空盒覆盖全屏（假差异） | harness 现象 | 加 depth_renderbuffer，全部场景重测 |
| V-12 | **Vk 无键盘输入**：`key_state` 恒空 → 脚本 `is_key/get_action` 恒 False | 复核 B | 首帧注册 GLFW 回调，按 `_KEYMAP` 反查键名写 driver.key_state |
| V-13 | **无点光阴影**：Vk 只支持首盏平行光阴影 | 复核 B / 目标清单 | 6 层 2d-array 深度 + 复刻 GL 的"面/UV 手算" + textureLoad（避开 cube 约定差异）；A/B MAE 0.0001 |
| V-14 | **无贴图**：GL 有 albedo 采样管线，Vk 主 pass 无纹理绑定 | 目标清单"纹理" | 顶点加 UV(loc13) + 按纹理分桶 + 每纹理完整 bind group（单组同时绑，规避多组死锁）+ 逐级 mip 生成；A/B MAE **0.0000** |
| V-15 | **无法线贴图**：GL 有导数 TBN + u_normal_map，Vk 无 | 目标清单"纹理" | 扩 UV(已备) + binding 7/8（法线贴图 + 每桶 has_nrm）+ 导数 TBN 同式；A/B MAE 0.0000 |
| V-16 | **无 PBR 环境反射**：场景会序列化材质 env_map，GL 有 u_env 采样，Vk 无 | 目标清单"PBR" | 材质 cube env 上传（含逐面 mip）+ binding 9 + 每桶 has_env/max_lod；A/B MAE 0.0000（修复过"占位 cube 让 has_env 恒为 1"的 bug） || V-17 | **Vulkan 无 Canvas UI / HUD**：UIManager 元素树只在 GL 主 pass 绘制 | 复核 B P0 | 新增 `vk_ui.py`（独立 2D 管线 + 单 bind group + 文本纹理 LRU）+ `vk_renderer.draw_ui()`（主 pass 后 load 叠加）；driver 加载场景 `ui` 段 || V-18 | **Vk 播放器无 active_camera / 鼠标输入**；且**键鼠回调注册从未成功**（wgpu 画布上 glfw.get_current_context() 返回无效句柄，异常被 except 吞掉） | 复核 B P0 + 子代理实测 OSError | scene_driver 复刻 apply_camera/父链/roll/fov + 鼠标锁定状态机；vk_player 改用画布 `_window` 并验证句柄存活；17/17 场景 VP 差 0；新增 tests/test_vk_camera_align.py（86 断言） || V-19 | **接线偏差**（我自己引入又修掉）：HUD 无条件开启、开发者右键/滚轮视角 | GL PlayerApp `_draw_hud = pass`、PlayerApp 无开发者鼠标 | HUD 与 dev 鼠标改为默认关闭（LOOM_VK_HUD=1 / LOOM_VK_DEVMOUSE=1 显式开启） || V-20 | **world Canvas 未实现**（`canvas_type=world`：离屏纹理 + 世界空间 quad + 深度） | 子代理残差清单 R1 | 新增 `VkWorldUIPipeline`（离屏 target/世界 quad/深度测试/target 懒绑定）；A/B **MAE=0.000156**，离屏 RGBA 与 GL 逐位一致 || V-21 | **UI 输入未分发**（命中测试/焦点/相机互斥） | 子代理残差清单 R3 | `UIInputBridge` + GLFW 回调（光标/键/鼠标键/滚轮/char）；UI 消费时 `wants_camera=False`；`tests/test_vk_ui_input.py` 33 项断言进 run_all || V-22 | **引擎缺陷**：`loom_ui` 松开时写 `self._dragging_elem._dragging = False if ... else None`，赋值目标先求值 → `_dragging_elem=None` 时 AttributeError（GL editor 在外层吞异常，一直未暴露） | 子代理实测 | 改为显式 `if ... is not None`；配套把"松开当帧即释放相机"的测试断言纠正为 GL 语义（当帧仍消费、下一帧释放） || V-08 | **场景驱动丢组件**：`build_models` 不恢复 material_id / audio_source / animator | 复核 B 实测 `m.animator=None`、`m.audio_source=None` | 新增 `build_materials()`，`build_models` 恢复材质库引用/音频源/动画剪辑 |
