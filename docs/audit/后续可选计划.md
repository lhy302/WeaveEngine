# Loom 后续可选计划（Backlog，非当前承诺）

> 记录"值得做但当前不做"的想法，避免丢失。每条含：动机 / 方案 / 代价 / 前置条件。
> 状态标记：`待评估` / `已设计` / `暂缓` / `已实现`。

## 1. Agent 操作回放面板（替代已移除的"步进模式"）

- **状态**：待评估（2026-11-07 记录）
- **动机**：用户希望"人能看到 AI 每一步在做什么"。原"步进模式"要求人点下一步才执行，
  与 MCP 同步工具调用模型冲突（工具调用会超时，放宽超时又导致 Agent 重试重复提交），已移除。
  正确形态是**事后回放**：不阻塞工具调用，把每一步记录下来供人回看。
- **方案**：
  1. `AgentService` 每执行一条命令，追加一条结构化记录到环形缓冲：
     `{ts, cmd, args, ok, ms, done, total, before_snapshot?, after_snapshot?}`；
  2. 新增工具栏「AI 操作历史」面板：列表显示每条命令，点击某条 → 把场景恢复到该条**之前**的状态并高亮受影响对象；
  3. 提供「回放」按钮：按原节奏（120ms/条）重放一轮，人可随时暂停/单步（**本地播放**，不涉及 MCP 调用）；
  4. 与批次撤销联动：一轮 AI 操作对应一个 `BatchCommand`，面板里按"轮"分组。
- **代价**：需要命令级场景快照（复用 `undo.snapshot`），内存随轮次增长 → 环形上限（如最近 200 条/20 轮）。
- **前置**：A~D（逐条执行/状态栏/聚焦/批次撤销）已实现。

## 2. 场景快照 diff 可视化
- **状态**：待评估
- **动机**：回放面板需要"这条命令改了什么"的直观展示。
- **方案**：对前后快照做字段级 diff（位置/旋转/缩放/颜色/可见性/父子关系），面板里以 `旧 → 新` 展示。

## 3. VK 阴影容量扩展
- **状态**：暂缓（已文档化已知限制）
- **动机**：当前 VK 平行光阴影最多 2 张、点光阴影仅 1 套；第 3 盏起打印一次警告。
- **方案**：阴影图池化（按需分配/回收），bind group 按槽位动态重建（注意本项目驱动的多 bind group 死锁史）。

## 4. Shape 描边逐像素等价
- **状态**：暂缓（图元级差异，已契约化 `STROKE_PIXEL_EQUIVALENT=False`）
- **动机**：GL `GL_LINES` 与 VK 三角带覆盖规则不同；实测 line-list 也无改善（WebGPU 线宽恒 1px）。
- **方案**：若必须逐像素，需要在 GL 侧也改成三角带（改变参考基线），或引入几何着色器式扩边 + 半像素偏移。

## 5. 离屏 RenderTexture 型 Canvas
- **状态**：待评估（引擎本无此功能，非 VK 缺口）
- **动机**：当前 `loom_ui` 只有 `screen` / `world` 两种 Canvas。
- **方案**：新增 `canvas_type="offscreen"` + `target` 材质槽，渲染到纹理再作为贴图使用（两后端都要做）。
