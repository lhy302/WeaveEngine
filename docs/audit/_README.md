# audit/ —— 当前版本的审计记录

> **本目录只放当前版本（beta7）的审计 / 倒查 / 修复记录。**
> 一个版本发包后，**整个目录的内容整体移入** `../archive/v<版本>/`，本目录清空重来。
> 历史版本记录见 `../archive/`（beta6 及以前全部已归档）。

---

## 命名约定

```
<轮次>_<编号>_<主题>.md      # 例：round1_01_时钟传播.md
```

| 前缀 | 含义 |
|---|---|
| `scan_` | 审计扫描（粗筛 → 双向逻辑推演 → 四象限 → 探针） |
| `fix_` | 修复记录（修前红 → 修 → 修后绿，含反例） |
| `verify_` | 独立复核（**未参与实现**的子代理复跑，不许引用自报值） |
| `final_` | 版本收尾倒查（目标是否达成） |
| `impl_` | 实施记录（某项重构/单源化的逐步落地） |
| `_` 开头 | 汇总台账（`_ledger` 逐条状态、`_summary` 总账） |
