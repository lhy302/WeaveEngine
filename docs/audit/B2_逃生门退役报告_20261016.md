## 三、退役的逃生门清单（A 类）

| 变量 | 原语义 | 处置 |
|---|---|---|
| `LOOM_NO_PIPELINE` | 接线层整体禁用 | 删 |
| `LOOM_NO_PREP` | 回退"渲染帧现算"路径 | 删 |
| `LOOM_NO_SHADOW_CACHE` | 禁用静态阴影 VP 缓存 | 删 |
| `LOOM_NO_INTERP_POSE_DLL` | 禁用 C 插值姿态 | 删 |
| `LOOM_NO_INTERP_WORLD_DLL` | 禁用 C 插值世界矩阵 | 删 |
| `LOOM_NO_INTERP_DLL` | 禁用 C 插值 | 删 |
| `LOOM_NO_BUCKET_PACK_DLL` | 禁用桶打包 | 删 |
| `LOOM_NO_DIRTY_MASK_DLL` | 禁用脏检测 | 删 |
| `LOOM_NO_LOCAL_MAT_DLL` | 禁用局部矩阵 | 删 |
| `LOOM_NO_DEPTHS_DLL` | 禁用深度 DP | 删 |
| `LOOM_NO_ANCESTRY_DLL` | 禁用祖先 DFS | 删 |

**保留项**（非 A 类，蓝图 §2.5）：
- `LOOM_NO_DLL`（B 类运行时兜底门）
- `LOOM_NO_NUMBA`（诊断用，编译版降级模拟）
- `LOOM_NO_PARALLEL`（测试守卫）

## 六、方案偏差记录（调研后确认，属实现细节非路线分叉）

| 蓝图原文 | 实际做法 | 差异说明 |
|---|---|---|
| 「删 LOOM_NO_PIPELINE + 子门」 | 一并删 `disabled()`/`error()` 函数 + 9 处 `rc != 0` 改硬 raise | 官方件不兜底纪律的必然延伸 |
| 「删 numpy 回退段」 | `_sched_wm_local` 成死代码一并删 | 唯一调用点在回退段内 |
| 「fastpath depths/ancestry 走 C」 | 保留 `_depths_impl`/`_ancestry_dfs_impl` 纯 Python 参考（同 B1 保留 `_aabbs_minmax_np`）| 测试基准用，不进生产分派 |
| 「A/B 对照探针删 off 档」 | editor_core/compiled_verify 的回归闸改绝对阈值（保留 [GATE-*] 前缀供 build_all 消费）| build_all.bat 依赖判定行 |

无路线分叉。
