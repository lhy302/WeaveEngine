## 1 缺陷机理（逐层推到底）

| 层 | GL | VK（修前） |
|---|---|---|
| 算平行光 VP 的条件 | {BT}light.shadow or light.mode == "beam"{BT}（{BT}loom_lighting.py:163{BT}） | 只有 {BT}l.shadow{BT}（{BT}vk_renderer.py:1582{BT}） |
| beam 灯关阴影时 | 照算 VP → {BT}orthos[i]{BT} 有值 | **不算** → 场景块里该灯 {BT}ortho{BT} 保持全零 |
| 着色器 | {BT}main.frag:198{BT} {BT}if (kind<0.5 && mode>0.5){BT} → {BT}lp = ortho * world_pos{BT} → {BT}SHADOW_UV(lp){BT} | 同 |
| 后果 | 截面遮罩正常 | {BT}lp.w = 0{BT} → {BT}SHADOW_UV{BT} 除 w 得 NaN/inf → 两个区间比较都 false → {BT}in_shape{BT} 保持 {BT}0.0{BT} |
| 最终 | 该灯照亮 | {BT}g_in_shape=0{BT}、{BT}sh=0{BT} → {BT}main.frag:230{BT} {BT}radiance = color*intensity*atten*sh = 0{BT} → **该灯一点光都不出** |

**注意措辞**：不是「整帧黑」，而是「这盏灯完全不出光」。黑天空场景下看起来像画面整体变暗，
所以最初容易被误判成「亮度没对齐」。

## 2 修前必红（实测原文）

同一场景（黑天空 + 白地板 + 单盏 beam 平行光，只有它能照亮），只切换 {BT}shadow{BT}：

```
shadow=False  GL mean=0.454512 | VK mean=0.338061 | MAE(G,V)=0.116452 MAX=0.710
shadow=True   GL mean=0.454512 | VK mean=0.454512 | MAE(G,V)=0.000000 MAX=0.000
数据面 shadow=False: light guid in _light_vps ? False
```

**这一对数字本身就是最强的归因**：开阴影时两端**逐字节相同**（MAE=0），
关阴影时差 0.1165 —— 说明差异**只**来自「关阴影时没算 VP」这一处，不掺任何其它因素。

## 3 修法（补齐 GL 的同一个条件，不碰阴影预算）

```python
# 修前
if l.kind == 'directional' and l.shadow:
    vp = self._dir_light_vp(l, worlds, vis)
    if vp is not None:
        self._light_vps[l.guid] = vp
        _n_dir += 1
        if len(self._dir_shadow_slots) < _SHADOW_SLOTS:
            self._dir_shadow_slots[l.guid] = len(self._dir_shadow_slots)

# 修后
if l.kind == 'directional' and (l.shadow or l.mode == 'beam'):   # ← 与 loom_lighting.py:163 同条件
    vp = self._dir_light_vp(l, worlds, vis)
    if vp is not None:
        self._light_vps[l.guid] = vp
        if l.shadow:                       # ← 计数与贴图槽位仍只给真投影灯
            _n_dir += 1
            if len(self._dir_shadow_slots) < _SHADOW_SLOTS:
                self._dir_shadow_slots[l.guid] = len(self._dir_shadow_slots)
```

**两个「没动」是刻意的**：

1. {BT}_n_dir{BT}（超限警告的计数）**不把 beam 灯算进去** —— 警告文案是「当前场景有 N 盏平行光**要求投影**」，
   beam 关阴影的灯并不要求投影，算进去会打出假警告；
2. {BT}_dir_shadow_slots{BT}（1024² 贴图槽位，VK 只有 2 张）**不给 beam 关阴影的灯分配** —— 与 GL 一致
   （GL 的 {BT}b["slots"]{BT} 只在 {BT}if light.shadow{BT} 里赋值）。

## 4 修后绿（同一门，实测原文）

```
PASS beam + shadow=False（缺陷本体）：两端 MAE <= 2e-03  GL mean=0.454512 VK mean=0.454512 MAE=0.000000
PASS beam + shadow=True（对照组）：两端 MAE <= 2e-03  GL mean=0.454512 VK mean=0.454512 MAE=0.000000
PASS beam + rect + shadow=False：两端 MAE <= 2e-03  GL mean=0.462208 VK mean=0.462208 MAE=0.000000
PASS beam + shadow=False：VK 必须算出 VP（截面遮罩要 ortho）  in _light_vps=True
PASS beam + shadow=False：不占阴影贴图槽位  dir_shadow_slots={}
PASS beam + shadow=True：VK 必须算出 VP  in _light_vps=True
PASS beam + shadow=True：不占阴影贴图槽位  dir_shadow_slots={guid: 0}
PASS full + shadow=False：VK **不得**算 VP（M3-N5 优化）  in _light_vps=False
总结果: ALL PASS
```

**两端从「差 0.1165」变成「逐字节相同 MAE=0」**，不只是「看起来差不多」。

## 6 反向保护（防止「顺手改成无条件算 VP」）

门里有一条断言：**{BT}full{BT} 灯 + {BT}shadow=False{BT} 时 VK {BT}_light_vps{BT} 必须没有它**。

为什么必须钉住：GL 的 {BT}loom_lighting.py:157-162{BT} 记录了 M3-N5 的实测 —— 无条件兜底算 VP 时，
{BT}_dir_light_vp{BT} 内部要做全场景包围盒 + 场景界计算，**main_pass 0.65 → 18.16 ms/帧（FPS 158 → 37.5）**。
如果将来有人为了「保险」把条件改成「所有平行光都算 VP」，这条断言会红。
