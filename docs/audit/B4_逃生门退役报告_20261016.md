---

## 一、目标

退役 physics 组件的 A 类开发期门（`LOOM_NO_PHYSICS_DLL` / `LOOM_NO_BATCH_PHYS`），
删逐体回退段，使 physics.dll 成为唯一生产路径（与 B1/B2/B3 同纪律）。

**注**：`LOOM_NO_PIPE` 独立成 B4c 后置（用户拍板）。

---

## 二、调研发现的偏差（施工前已交用户审核）

| # | 偏差 | 结论 |
|---|---|---|
| A | physics.dll 不是物理引擎本体（真引擎是 Jolt/Culverin）；physics.dll 只提供 3 个纯函数 | 已确认，退役面收窄 |
| B | `LOOM_NO_PHYSICS_DLL` 与 `LOOM_NO_BATCH_PHYS` 语义重叠（最终都走同一段逐体回退）| 一起删 |
| C | `LOOM_NO_PIPE` 归属不明（§3 未列，§2.3 归脚本/物理组件类）；其回退面叠加"管线降级"功能边界 | 独立 B4c |
| D | `physics_dll_val_check.py` 不在 build_all 对拍网 | 补入 |
| E | `physics_dll_val_check.py` docstring 说第 5 条逃生门测试但 main 里没有 | 随退役删该条说明 |

用户拍板：**方案 B（彻底退役）**，并明确核心原则：
> "所有功能只在一个组件上留实现……不在外部重复功能为组件兜底；实现的稳定性应该在组件内部保证。"
