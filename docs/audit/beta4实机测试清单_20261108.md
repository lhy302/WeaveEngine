## 0. 测试前准备

- 关闭所有 LoomHub / Loom 进程。
- 记录基线：`%LOCALAPPDATA%\Loom` 应**不存在或为空**；`C:\Program Files\Loom\0.1.0.beta4\Loom` 下只有安装时的模板文件。
- 想验证"只读安装也能存配置"：把整个引擎目录设为只读（或直接装在 Program Files，本身就是普通用户不可写）。

## 1. 配置落点（本轮最大改造）

| # | 操作 | 期望 |
|---|---|---|
| 1.1 | LoomHub 打开项目 → 改任意一个设置（如 GUI 皮肤/op_py）→ 关掉 Hub | 生成 `%LOCALAPPDATA%\Loom\hub\settings.json`，内容只含**改过的键**（delta）；`C:\Program Files\LoomHub` 下**不新增**文件 |

### 包体积裁决（2026-11-09）

- beta5 编译版包 **125.94 MB**（beta4 为 109.34 MB，+16.5 MB）。
- 原因：C5=B（给 VK 补上屏健康判据）后，播放器运行时为了"auto 降级 → 离屏回读"需要 Qt，
  `player_runtime` 因而打入 PySide6 + Qt DLL（解压后约 +43 MB）。
- **人类裁决：接受该体积**，不为此去掉播放器侧的 remote 回退。
