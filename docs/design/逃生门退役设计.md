# 逃生门退役设计

> **性质**：白盒契约 + 退役计划。落实"开发期回退兜底不留，死磕组件稳定性"的决策。
> **决策依据**：用户定案 —— 开发期回退不留；新组件崩了直接抓报错码分析（逐组件稳定）；
> 实在做不出来就 git 回退。官方件出厂即稳定；外部件全兜底回官方。
> **取证来源**：全工程 `grep LOOM_NO_`（.py 中 250+ 处）。

---

## 1. 逃生门三分类

| 类型 | 定义 | 代表 | 处置 |
|---|---|---|---|
| **A 开发期 A/B 对比门** | 为"新实现 vs 旧实现逐位对拍"而留的回退分支 | LOOM_NO_CKERNELS / NO_PIPELINE / NO_SAP / NO_PBR / NO_FRUSTUM / NO_SPLIT / NO_PREP / NO_INTERP_* / NO_BATCH_PHYS / NO_SHADOW_CACHE / NO_NUMBA | **退役** |
| **B 运行时兜底门** | 外部件坏了弹回官方 | LOOM_NO_DLL | **保留** |
| **C 测试守卫** | 保证测试确定性 | LOOM_NO_PARALLEL | **保留** |

## 3. 退役顺序（一个组件一个组件来）

**原则**：最成熟优先；每步独立 git 提交做锚点；每步跑全量对拍。

| 顺序 | 组件 | 移除内容 | 验证探针 |
|---|---|---|---|
| 1 | **ckernels** | numpy AABB 回退段 + `LOOM_NO_CKERNELS` | ckernels_val_check / aabb_f32_check |
| 2 | **pipeline** | 各 numpy 回退段 + `LOOM_NO_PIPELINE` 及子门 | pipeline_val/base/world_check |
| 3 | **script** | Python 运动回退 + `LOOM_NO_SCRIPT_DLL` | script_val_check / lua_integration |
| 4 | **physics** | legacy 物理回退 + `LOOM_NO_PHYSICS_DLL` / `LOOM_NO_BATCH_PHYS` | physics_dll_val_check / physics_c_check |
| 5 | **SAP 粗筛** | `LOOM_NO_SAP` 对拍门 | collide_val_check |
| 6 | **interp C 化** | `LOOM_NO_INTERP_*` | interp_pose_check / pipeline_world_check |
| 7 | **帧调度** | `LOOM_NO_SPLIT` / `LOOM_NO_FRAMEBUF` | split 相关探针 |
| 8 | **渲染特性** | `LOOM_NO_FRUSTUM` / `LOOM_NO_PBR` / `LOOM_NO_SHADOW_CACHE` | 渲染相关探针 |

---

## 4. 每步执行纪律（铁律）

```
1. 确认该组件当前对拍全绿
2. git commit 一次（回退锚点）★关键
3. 删除回退分支（含对应 LOOM_NO_* 读取）
4. 跑全量回归 (build_all 对拍网 + tests/_tmp)
5. 全绿 → 下一步；出问题 → git checkout 回步骤 2
```

**用户授权**：做不出来直接 git 回退到该组件修改前版本，不硬撑。

---

## 5. 退役后的配套（关键）

删掉回退后，组件崩了**没有软着陆**——这正是要的（暴露问题）。但必须配套：

| 配套 | 现状 | 要求 |
|---|---|---|
| 崩溃转储 | crash_reporter.py 已有 | 保留，抓 .dmp 分析 |
| 报错码清晰 | DLL 返 -1~-6 | 报错要能定位到具体组件/函数 |
| 逐组件隔离 | 注册表槽位 | 一个组件崩不影响其他 |

**目标**："崩了"= "有信息的崩"，而非"莫名其妙的崩"。

---

## 6. 与"哈希清单+启动自检"的配合

- 退役 A 类 = 删除代码里的**冗余实现**
- 内嵌哈希基准（见《稳定性与启动自检设计.md》）= 保证**留下的唯一实现**是官方原件
- 两者配合：**只有一份实现 + 它必须未被改 = 出厂必稳**

---

## 7. 风险与边界

| 风险 | 应对 |
|---|---|
| 删回退后某环境 C 件不可用 | 该场景本就是"官方件坏"，应报警而非静默降级（符合决策） |
| 删早了暴露未发现的 bug | 逐组件 + git 锚点，随时回退 |
| 某些 LOOM_NO_* 被测试引用 | 删前 grep 引用，测试里同步清理或改用 C 路径 |
| 冻结环境（Nuitka）无 numba | 已由 LOOM_NO_NUMBA 诊断路径覆盖，非 A 类退役对象 |
