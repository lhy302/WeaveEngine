## 六、维护规则

1. 新增设计文档**必须**在本文登记，并同步到 `../README.md`。
2. 设计被推翻或被新文档取代 → **移到 `../archive/被取代的设计/`**，并在该目录 `_README` 登记，不要留在本目录。
3. 一个版本发包后，把当期"计划/研究"类文档一并移入归档（它们的作用在发版时结束）。
