# T2 差异清单（beta6 · 2026-11-13 建立；2026-11-13 按 Q-T2-1/Q-T2-2 裁决更新）

> **这份文件回答一个问题**：GL 与 VK 之间有哪些语义面**没有**共享，为什么不能共享，靠什么门控，以及**用哪条可复跑探针**证明它没坏。
> 目标是计划 §9.31 的 **T2**；清单由人类裁决维护。**探针红 = 清单失效**，必须更新条目而不是改探针。

## 0. 口径（先说清楚，避免再发生「重新分桶」）

- 本清单**不算分、不折算**。§9.28 的 14 项分母与 11.5/9.5 折算已按 §9.29 提案废除；§9.31 里「现 4 项不共享 + 1 项合理差异」是**当时的快照**，不是标准答案。
- 条目只按**证据**增删；§9.31 快照与本清单条数不同（见 §4），差额逐条列明，**不做等价换算**。
- 「不共享」= 同一语义两端各写一份实现，改一处不会自动改另一处。
- 「合理差异」= 受 API/硬件语义限制**无法**共享，且已把差异**关进一层**（宏层 / 描述层 / **场景级容差 + 独立探针**）。
- 「实现细节」= 语义面已共享、执行体天然两份；按 **Q-T2-2 = 不算**，不进清单（见 §2.1）。

## 1. 条目格式

```
| 编号 | 语义面 | 为什么不能共享 | 门控方式（差异关在哪里） | 可复跑探针 | 当前证据 |
```

## 2. 不共享（D 组，4 条）

| 编号 | 语义面 | 为什么不能共享 | 门控方式 | 可复跑探针 | 当前证据 |
|---|---|---|---|---|---|
| **D-01** | 主目标的 load/clear | GL 的主目标就是默认帧缓冲，清屏走特例函数 `loom_render.py:396 _clear_main_fbo`；VK 是显式 attachment，走 `clear_value`（`vk_renderer.py:1168/1338/1523`） | 清屏**颜色/深度语义**来自 FramePlan 的 `TargetDecl/PassSpec`，两端只负责各自的 API 写法 | 改 plan 的清屏色/深度清除值 → 两端同向变化（T1 反例矩阵第 7 类，`Loom/tests/test_frame_plan_vk.py`） | 已有受跟踪测试；`§9.28 #4` 判「不共享」 |
| **D-03** | 天空几何与参数注入 | GL 用 6 顶点 TRIANGLES 全屏 quad（`loom_render.py:176-229`）；VK 用 `_SKY_WGSL` 自己的顶点/参数注入路径 | 时机与存在性由 plan 的 sky pass 定；`RasterState.cull` 两端已接线（§9.28 #6 反例 0.24656） | `ab_sky` 三向 MAE + sky.cull 反例 | `ab_sky` 1.2e-5/1.2e-5/0（2026-11-13 实测） |
| **D-04** | 实例桶布局与提交粒度 | GL 每桶一个 VBO 直接 `render(instances=cnt)`（`loom_render.py:1002`）；VK 重排为统一 96B 实例布局 + 每桶一次 submit | 实例字段表 `INSTANCE_LAYOUT`（`loom_shader_bindings.py`）是**单点表**，两端按同一张表写字节 | 改实例字段/桶数 → 两端像素同向（`ab_*` 场景 + `Loom/tests/test_bucket_pack.py`） | §9.28 #13；字段表统一已落盘（T3c-3） |
| **D-05** | UI 光栅化 | GL 走 `loom_ui` 元素树 + moderngl `TRIANGLE_STRIP`（`loom_render.py:369-390`）；VK 在 `vk_ui.py` 里自建三角带 + 自己的管线 | 两端共享**元素树与场景数据**，不共享三角化与提交；用**纯 UI 全屏场景**把差异单独量出来 | `cd Loom; LOOM_AB_SCENES=ab_ui_only.json py -3.13 tests/test_ab_gl_vk.py` 的 **[UI] 子项**（整帧被不透明 UI 覆盖，无可见 3D 像素稀释） | `ab_ui_only [UI]` **2.72581e-3**（ui 门限 5e-3，余量 2.27419e-3 / 门限的 45.5%）；MAX 0.9137、NCC 0.955957、diffpx 1333/153600（0.87%）；3×3 全差异内部=0、1333/1333 在 GL 边缘 1px 内（边缘覆盖差，不是块状缺陷）；2026-11-13 实测 |

## 2.1 实现细节（不入清单；Q-T2-2 = 不算不共享）

| 编号 | 项 | 为什么不算「不共享」 | 证据 |
|---|---|---|---|
| **I-01（原 D-02）** | 绘制源的**执行体** | `buckets`/`skybox`/`world_canvas` 的语义面（名字/顺序/存在性）已由 FramePlan 共享；每个 source 的执行体两端各一份，属任何双后端实现的固有实现细节，改语义只需改描述层 | 已有 `test_frame_plan_vk` 7 类反例；T1 达成。2026-11-13 人类裁决 **Q-T2-2 = 不算**，从 D 组移出 |

## 3. 合理差异（R 组，4 条：无法共享，但已关进一层）

| 编号 | 语义面 | 为什么无法共享 | 门控方式 | 可复跑探针 | 当前证据 |
|---|---|---|---|---|---|
| **R-01** | 阴影目标编码 | GL 用硬件深度纹理；VK 用 `r32float` + 手工比较（API/硬件语义限制，wgpu 无等价 depth-compare 采样路径） | **比较算法**已统一为 9-tap 显式比较（§9.32），差异只剩**存储格式** | `ab_c_dir_shadow` / `ab_point_shadow` 三向 MAE | 2.9e-5/5.1e-5/2.9e-5 与 5.7e-5/4.6e-5/1.1e-5（2026-11-13） |
| **R-02** | 采样器/绑定模型 | GL 是组合采样器（`sampler2D`），wgpu/naga 只接受**分离采样器**（`texture2D`+`sampler`），比较采样器必须 `samplerShadow` | **`Loom/shaders/loom_shader_compat.glsl` 单层吸收**：`#ifdef LOOM_VK` 只允许出现在这一层，正文只用宏 | `tools/build_shaders.py`（SPIR-V 能建模块）+ **25 场景**像素门 | 6 个 shader 已单源化；`#ifdef LOOM_VK` 全仓仅 compat（grep 实证） |
| **R-03（原 D-06）** | mip 生成 | GL 走驱动 `glGenerateMipmap`（`loom_texture.py:182` / `loom_cubemap.py:203`）；VK 走 `shaders/mip_downsample.frag` 逐级降采样（`vk_renderer.py:1273 _gen_mips`）——GL 侧没有可单源化的 shader 阶段 | **场景级容差** `mae_abs=1e-3`（Q-T2-1=A）+ 漂移门 `基线+5e-5`；全局 2e-4 **不动**，GL/参考仍走 2e-4 | `cd Loom; LOOM_AB_SCENES=ab_mip_minify.json py -3.13 tests/test_ab_gl_vk.py` | `ab_mip_minify` GL/ref=0、VK/ref=GL/VK=**5.8264e-4**（场景门限 1e-3，余量 4.174e-4 / 门限的 41.7%）、MAX 0.1608、NCC 0.988519；**mip 关时 GL/VK≈4.3e-7（6 位打印 0.000000），mip 开/关 GL 1.36052e-3 / VK 1.16709e-3** → 差异确实来自 mip 链；2026-11-13 实测 |

| **R-04** | **UI 描边光栅化差**（D-05 的视觉后果，Q-PAR-1=A） | GL 的描边走 `GL_LINES`（1px 硬线，无宽度、无连接规则）；VK 用三角带近似。两个 API 的线光栅化规则不同，`vk_ui.py` R2 契约已注明 `STROKE_PIXEL_EQUIVALENT=False` | **既有 UI 门 `ui_mae_abs=5e-3`**（`test_ab_gl_vk.py:80`，**本轮未改**；2e-4 只是主图门，`ab_ui_only` 主图 = 0/0/0）+ 独立探针 `ab_ui_only` | `ab_ui_only [UI]` MAE=**2.726e-3**（门限 5e-3，余量 45.5%）；差异像素 **1333/153600 = 0.87%**，**100% 落在高梯度边缘 1px 内、3×3 全差异内部 = 0 个** → 边缘覆盖翻转，非块状缺陷 |

## 4. 与 §9.31 快照的差额（逐条列明，不折算）

§9.31 写「现 4 项不共享 + 1 项合理差异」。T3 完成后重算，再按 Q-T2-1/Q-T2-2 裁决：

| 变化 | 条目 | 依据 |
|---|---|---|
| **消失（并入共享）** | 原 #11 着色器语言（GLSL vs WGSL） | T3 已单源：一份 GLSL → SPIR-V；剩余差异降级为 **R-02**（采样器写法，关进 compat） |
| **消失（并入共享）** | 原 #12 参数块布局 | T3c-1/2a：Scene UBO / Bucket UBO 由表生成，两端同一份 |
| **新增/拆出** | D-05 UI 光栅化；原 D-06 mip（裁决后归 **R-03**） | 原表把它们压在「#14 UI」「#12 mip」里；本清单按「改一处是否要改两处」独立成条 |
| **移出 D 组（实现细节）** | 原 D-02 绘制源执行体 → **I-01** | Q-T2-2 = 不算：语义面已由 FramePlan 共享 |
| **移出 D 组（合理差异）** | 原 D-06 mip → **R-03** | Q-T2-1 = A：接受为合理差异 + 场景级容差 + 独立探针 |
| **未变** | D-01 / D-03 / D-04 | 与 §9.28 #4/#10/#13 一一对应 |

→ 当前 **4 条不共享（D-01/D-03/D-04/D-05）+ 4 条合理差异（R-01/R-02/R-03/R-04）+ 1 条实现细节（I-01，不入清单）**。与快照「4+1」不同是**口径细化 + 两条裁决**，不是目标退步：T2 的判据是「每条都有原因/门控/探针」，不是条数。

## 5. 已裁决（2026-11-13）

1. **Q-T2-1 = A（mip 生成接受为「合理差异」+ 容差）**：GL 驱动 mip 与 VK shader mip 不可能逐像素相等；人类裁决接受，并要求一条能**真正暴露**它的探针。落地：原 D-06 归入 **R-03**；`ab_mip_minify` 绑定场景级 `mae_abs=1e-3`（实测 5.8264e-4），**全局 2e-4 与 GL/参考门不变**。
2. **Q-T2-2 = 不算（绘制源执行体降级为实现细节）**：`buckets`/`skybox`/`world_canvas` 的名字/顺序/存在性已由 FramePlan 共享，执行体天然两份。落地：原 D-02 移入 §2.1 **I-01**，不再是清单条目。

3. **Q-PAR-1 = A（UI 描边 1px 覆盖差接受为「合理差异」）**：`ab_ui_only` 首次把这条**一直存在但没有观测者**的差异测出来——旧 `ab_ui_scene` 整帧 MAE 只有 1.10e-4，因为 UI 只占一小块、被背景稀释。裁决接受并登记为 **R-04**（D-05 的视觉后果）。若将来改成两端都走三角带，则 D-05 与 R-04 同时消失。

## 7. 维护规则

1. 新增任何「两端各写一份」的语义面 → 必须在本表登记，否则视为违规。
2. 条目对应探针变红 → **先判定是清单失效还是产品坏了**；不许改探针阈值了事。
3. 条目删除必须给证据（「已并入共享」要指向哪次提交/哪张表）。
4. 场景级容差只允许绑定**已裁决的合理差异**（当前仅 `ab_mip_minify`）；新增容差必须走人类裁决，不得为了让测试变绿自行追加。
