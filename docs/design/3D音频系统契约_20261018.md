## 二、数据模型契约

### 2.1 AudioSourceComponent 新增字段

现有字段（不变）：clip / loop / volume / playing / _key

新增字段：

    category: str        # 'music' | 'sfx' | 'voice'，默认 'sfx'
    min_distance: float  # 最小距离（内不再衰减），默认 1.0，仅 sfx/voice 生效
    max_distance: float  # 最大距离（外完全听不见），默认 500.0，仅 sfx/voice 生效
    rolloff: float       # 衰减曲线强度，默认 1.0，仅 sfx/voice 生效

- **前置条件**：无（构造后即存在）
- **后置条件**：category ∈ {'music','sfx','voice'}；min_distance > 0；max_distance > min_distance；rolloff > 0
- **不变量**：category='music' 时永远按 2D 播放，3D 参数被忽略

### 2.2 空间化判定规则（唯一权威）

    is_spatial(a) = (a.category in ('sfx', 'voice'))

- music → 2D（无位置、无距离衰减）
- sfx / voice → 3D（有位置、有距离衰减）
- **不存在 spatial 布尔开关**（B-新1 决策：类别决定行为，不做双层）

### 2.3 音源位置来源

音源世界位置 = 宿主 GameObject 的世界坐标（复用现有世界矩阵计算，
与相机 camera_world_position 同款父链变换逻辑）。

## 三、AudioListener 契约（A1 隐式跟随相机）

### 3.1 监听器状态

    listener_position: Vec3      # 每帧从 self.camera 同步
    listener_direction: Vec3     # 相机前向向量（由 camera_yaw/camera_pitch 计算）
    listener_up: Vec3            # 固定 (0, 1, 0)

### 3.2 同步时机

update_audio(dt) 开头执行一次：

1. 读 self.camera（相机世界位置）
2. 由 camera_yaw / camera_pitch 计算前向向量
3. 调 game-audio set_listener_position / set_listener_direction / set_listener_up

**前置条件**：仅 game-audio 后端；pygame 后端跳过（无此能力）
**后置条件**：监听器状态与当前相机一致

### 3.3 无相机时的行为

self.camera 未初始化或场景无相机 → 监听器保持原点 + 前向 (0,0,-1)，不报错。

## 四、AudioBackend 接口契约

### 4.1 新增方法

    set_listener(position, direction, up) -> None
        # 转发 game-audio 的三个 set_listener_*；pygame 后端静默 no-op

    play_spatial(path, position, loop, volume, min_distance, max_distance,
                 rolloff, owner) -> None
        # 3D 播放：设位置 + 开空间化 + 设距离参数 + 播放
        # pygame 后端：警告一次 + 按 2D 播放

    update_sound_position(path, position, owner) -> None
        # 更新已播放音源的位置（物体移动时每帧调）

### 4.2 3D 参数映射到 game-audio

| Loom 字段 | game-audio API |
|---|---|
| position | set_sound_position(handle, Vec3) |
| 空间化开关 | set_sound_spatialization_enabled(handle, True) |
| min_distance | set_sound_min_distance(handle, v) |
| max_distance | set_sound_max_distance(handle, v) |
| rolloff | set_sound_rolloff(handle, v) |

### 4.3 错误处理

- game-audio 调用异常 → 捕获，静默回退 2D 播放（与现有 per-file 回退同风格）
- 句柄无效 → 跳过该帧位置更新，不抛异常

## 五、update_audio 改造契约

### 5.1 现有行为（保留）

按 (clip, playing) 变化才 play/stop，不重复操作。

### 5.2 新增行为

对每个模型：

1. 若 audio_source 为 None 或 clip 为空 → 跳过
2. **若 is_spatial(a) 且 a.playing**：
   - 计算宿主世界位置
   - 若位置较上帧变化（容差 1e-4）→ 调 update_sound_position
3. 播放/停止逻辑按 is_spatial 分流：
   - is_spatial → play_spatial(...)
   - 否则 → 现有 play(...)

### 5.3 性能约束

位置更新只在"playing 且 spatial 且位置变化"时调用；
未播放的音频源零开销；非 spatial 音频源零开销。

## 六、序列化契约

### 6.1 _emit_object 的 audio_source 段

    "audio_source": {
        "clip": ..., "loop": ..., "volume": ...,
        "category": a.category,
        "min_distance": a.min_distance,
        "max_distance": a.max_distance,
        "rolloff": a.rolloff
    }

### 6.2 _apply_object 读取

- 缺字段 → 默认值（category='sfx', min=1.0, max=500.0, rolloff=1.0）
- category 非法值 → 回退 'sfx' + 警告
- min/max 关系非法（max <= min）→ 回退默认 + 警告

## 七、EAI 命令契约

### 7.1 新增命令

    set_audio_3d   {name?, category?, min_distance?, max_distance?, rolloff?}
        → {category, min_distance, max_distance, rolloff}
    get_audio_3d   {name?}
        → {category, min_distance, max_distance, rolloff}

（name 缺省 = 当前选中物体；物体无音频源 → 返回 error）

### 7.2 错误模型

| 场景 | 返回 |
|---|---|
| 物体不存在 | {"ok":false,"error":"object not found: X"} |
| 物体无音频源 | {"ok":false,"error":"物体无 AudioSource 组件"} |
| category 非法 | {"ok":false,"error":"category 只能是 music/sfx/voice"} |
| max <= min | {"ok":false,"error":"max_distance 必须大于 min_distance"} |

## 十、错误模型汇总

| 错误类型 | 位置 | 处理 |
|---|---|---|
| category 非法 | 组件 setter / sceneio / EAI | 回退 'sfx' + 警告（sceneio）/ 返回 error（EAI） |
| max <= min | 组件 setter / sceneio / EAI | 回退默认 + 警告 / 返回 error |
| pygame 后端遇 spatial | AudioBackend.play_spatial | 警告一次 + 2D 播放 |
| game-audio 调用异常 | AudioBackend | 捕获 + 回退 2D |
| 无相机 | update_audio | 监听器保持默认，不报错 |
