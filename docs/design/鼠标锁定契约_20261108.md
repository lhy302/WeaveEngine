# 鼠标锁定契约（2026-11-08 定稿）

> 面向**游戏开发者**：怎么决定"这个游戏锁不锁鼠标、什么时候锁、按哪个键解"。
> 面向**引擎维护者**：这是白盒契约，改实现必须守住下面的语义。

## 0. 默认 = 不锁（2026-11-08 变更）

| 配置键 | 默认 | 含义 |
|---|---|---|
| `mouse_lock_allowed` | **false** | 本游戏**是否允许**锁定鼠标。false = 全程不锁，解锁键也不响应（彻底关闭该功能） |
| `mouse_locked` | **false** | 启动时是否直接锁定（仅 `allowed=true` 时有效） |
| `key_bindings.解锁鼠标` | `["Tab"]` | 解锁/回锁的动作键（仅 `allowed=true` 生效） |

改这两项的位置：打包游戏的 `游戏设置.json`（开发者随游戏发布的**只读默认模板**）。
玩家侧实际配置在 `%LOCALAPPDATA%\Loom\games\<game_id>\settings.json`（只存 delta）。

**为什么默认不锁**：beta4 实测——吃豆人这种完全不用鼠标的游戏被"默认锁定"锁死，玩家只能 Alt+F4。
"需要才锁"比"默认锁、不要的自己去关"安全得多。

## 1. 三层控制

### 1.1 游戏级（配置文件，玩家可见）
```json
{ "render_api": "opengl", "mouse_lock_allowed": true, "mouse_locked": true,
  "key_bindings": { "解锁鼠标": ["F10"] } }
```

### 1.2 脚本级（运行期，开发者代码里决定）
```python
e.set_mouse_lock_allowed(True)     # 整个游戏是否允许锁定（可运行期开关）
e.set_mouse_locked(True)           # 立即锁定（allowed=False 时无效并告警一次）
e.set_mouse_locked(False)          # 立即解锁
e.set_ui_capture_mouse(True)       # 进入"需要鼠标操作"的特殊场景（背包/菜单/对话框）
e.set_ui_capture_mouse(False)      # 退出该场景
```

**没有"检测到 UI 就自动解锁"**（人类 2026-11-08 明确裁决）。原因：像《燕云十六声》这类游戏，
界面上**常驻**可点 UI，但平时仍然锁着鼠标做视角操作；只有玩家**打开交互面板**时才需要光标。
所以"什么时候该给光标"属于**设计决策**，只能由开发者判断，引擎不猜。

### 1.3 键位级
解锁键是**动作** `解锁鼠标`，不是硬编码键：
- 默认 `Tab`，可在 `游戏设置.json` 的 `key_bindings` 改；
- 脚本若在 `Script.keys_used` 里声明了同一键，`set_action_binding` 会**拒绝保存**并指出是哪个脚本占用；
- 引擎独占该键的翻转逻辑（内置 first/third_person 不再自己 toggle，否则同帧翻两次=净无效）。

## 2. 典型配方

| 游戏类型 | 配置 | 脚本 |
|---|---|---|
| 2D 无鼠标（吃豆人/塔防） | 不写任何 mouse 键（默认不锁） | 什么都不用做 |
| 第一人称 / 第三人称 | `allowed=true, locked=true` | 打开背包/菜单时 `set_ui_capture_mouse(True)`，关闭时 `False` |
| 常驻 HUD + 视角锁定（燕云类） | `allowed=true, locked=true` | 只在"打开可交互面板"时 `set_ui_capture_mouse(True)`；常驻 HUD 不需要解锁 |
| 想给玩家一个"永远能放鼠标"的逃生键 | `allowed=true` | 引擎自动提供 `解锁鼠标` 动作，无需脚本 |

## 3. 失败可见性（本轮加固）

- 解锁后会**回读** `glfw.get_input_mode`，不是 `CURSOR_NORMAL` 就打告警；
- 补 Win32 兜底：解锁时 `ClipCursor(NULL)` + `ShowCursor(TRUE)`，锁定时 `ClipCursor(窗口矩形)`；
- 每次状态变化打一行：`[鼠标] locked=True/False (glfw_mode=..., clip=..., showing=...)`。
  玩家反馈"光标出不来/动不了"时，**先看这一行**。

## 4. allowed=False 的硬语义（实现必须守）

1. `set_mouse_locked(True)` 无效（一次性告警，带"本游戏不允许锁鼠标"）；
2. `toggle_mouse_locked()` 与解锁键轮询**完全不响应**（不翻转、不打印"切换"）；
3. 启动时必为未锁；退出/异常路径不得留下锁定态。
