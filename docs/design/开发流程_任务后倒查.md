# 开发流程：任务后「倒查」（强制环节）

> 2026-11-10 由人类定为**固定流程**：任务完成后，必须**单独派一个新的子代理**去倒查「任务究竟完成没有」。
> 起因：beta6 期间，多轮「测试全绿」的交付在倒查中被打回——实现加自测，不能证明目标达成。

## 1. 为什么要这一步（实录数据）

| 批次 | 自测状态 | 倒查发现 |
|---|---|---|
| A 渲染 | 313 项测试绿、像素门 23/23 | **VK 对 FramePlan 引用 0 行**，目标完成度 14.3%；后处理两份实现（204 vs 202 行） |
| B 资产 | 46 项断言绿、126 文件绿 | **保存会永久销毁 guid 引用**；一条坏条目冻结全库；delta 崩加载 |
| C 动画 | 42 项断言绿 | **常量通道写成 plain tuple** → 编辑器 `.x` AttributeError（P0） |
| D 热点 | 128 文件绿、bench 提升 | 能力查询假阴（hasattr=True 但 has_module=0）；mt_mp_draws 40x 归因到驱动 |

**结论：倒查抓到的 P0/P1，没有一个是「全绿测试」能发现的。**

## 2. 规则

1. 实施者不自查结案：任何批次/任务完成后，由**未参与实现的新子代理**做倒查。
2. 倒查的目标不是找 bug，而是判断**目标是否达成**：先核对原定目标的每一条，再查是否引入回归。
3. **以能否证伪为标准**：对每条「已完成」的宣称，先构造反例试图打破；打不破才算成立。
4. **必须量化**：完成度要给出分子/分母（例：14 个语义面中 2 个共享），不接受「基本完成」。
5. 产物：`docs/audit/final_<编号>_<主题>.md`（范围与基线 / 目标达成判定表 / 引入问题 / 统计 / 待裁决）。
6. 结论回写：未达成的目标不得口头豁免，必须写进版本计划，并决定「补做 / 上调 / 明确不做」。
7. 豁免：纯文档错别字、纯注释改动可免倒查；**任何改变行为的改动都不豁免**。

## 3. 倒查清单（每次照抄）

- [ ] 原定目标逐条：达成 / 部分 / 未达成（带证据）
- [ ] 是否有「只修一条路径」的遗漏（GL/VK、编辑器/播放器、源码版/编译版、三入口）
- [ ] 是否有「修复引入新问题」（双写者、状态污染、死代码、文档撒谎）
- [ ] 文档承诺 vs 代码实现是否一致（含数字：命令数/版本号/测试数）
- [ ] 新增 env / 开关 / 全局状态是否都有默认值、文档、重置路径
- [ ] 测试是否「过拟合」（只调 helper、锁源码字符串、阈值悄悄放宽）

## 4. 与既有流程的关系

- 扫描协议（`docs/audit/SCAN_PROTOCOL.md`）是「任务中的取证方法」，倒查是「任务后的验收」；二者叠加使用。
- 阶段性审核按批次触发；倒查按**每个任务**触发（可合并成一次执行，但结论要分开写）。

## 5. 稳定性原则（2026-11-10 人类补充，含 11-11 边界澄清）

> 底线：**组件之间不互相兜底；自己的稳定性自己死磕。**
> 但「兜底」分两类，性质完全不同——判据是：**这个失败是不是环境带来的、设计内就预期要应对的？**

### 5.1 允许：环境适配型降级（设计内，但必须可见）

| 例子 | 为什么允许 | 硬要求 |
|---|---|---|
| **VK 不可用 → GL 回退** | 两者同属渲染后端设计，就是为不同运行环境准备的 | 必须**可见**：弹窗写明原因（驱动/API 不满足）、日志留痕、必要时把选择写进用户层配置 |
| 可选依赖缺失（cupy/profiler） | 设计内可选项 | 必须有**默认实现**，不是「失败后跳过」 |
| 用户显式关闭（`LOOM_POST=0`） | 用户选择 | 走同一份代码路径，不做特殊分支 |

### 5.2 不允许：缺陷掩盖型兜底（一律显式失败）

| 例子 | 为什么不允许 | 正确做法 |
|---|---|---|
| C 内核返回错误码 | 说明**内核自己不稳定**，上层降级会掩盖真 bug | 直接 raise（可加日志便于定位），死磕内核稳定性 |
| 坏索引条目 / 坏字段 | 数据损坏 | 拒绝加载 + 明确原因（U-02 裁决 B） |
| 双写者冲突（动画 vs 物理） | 归属没定清 | 定清归属并断言，不「谁快谁赢」 |
| 渲染后端之间共享语义不一致 | 抽象没做到位 | 对齐语义并加反例测试，不倒向任一侧 |

**一句话区分**：环境不给力 → 可以换条路走，但要**说出来**；自己写错 → 不许换条路走，要**修好**。
