====================================================================
Loom 使用操作指南 (2026-08-11, 原名 3D引擎)
====================================================================
面向"想用它做出东西的人"。开发/接手看 《代码架构.txt》。
整个工具的核心一句话:
    [布置场景] -> [挂脚本给行为] -> [按播放试玩] -> [打包发布 exe]
本指南按这条闭环一步步教。

====================================================================
〇、安装与启动
====================================================================
软件命名 (2026-08-11 更名):
   解释器 = Loom (引擎编辑器, 源码在 Loom(py源代码-工作区)\Loom\)
   项目管理器 = LoomHub (Unity Hub 角色, 源码在 Loom(py源代码-工作区)\LoomHub\)
目录: D:\my-project\Loom(py源代码-工作区)\ 下有 Loom\ + LoomHub\ (双文件夹工作流:
   开发在 -工作区, 验收后用户手动覆盖到稳定版本备份区; 文档 *.txt 放
   工作区根与项目根; 2026-08-31 起编译版/开源版已删除, 等重打指令)。
   可选加速库: numba (fastpath 静态编译) / culverin (Jolt 物理) / wgpu
   (Vulkan 后端) —— 缺哪个都自动降级, 功能正确性不受影响。

环境要求:
  Python 3.12 (py -3.12 命令; .py 默认打开应用已绑定 3.12.10)
  pip 安装:  moderngl  pygame  numpy  PySide6 >= 6.6  game-audio  (打包还要 nuitka)
  (编辑器界面 = LoomGUI: PySide6 Qt 原生控件, 必装; pygame 仅取键值常量;
   game-audio (2026-08-30 B2 音频主后端, miniaudio): 缺失时自动回退 pygame
   音频, 功能零丢失, 但 wav/mp3/flac 与低延迟/组音量特性需装它才有)

启动 Loom 解释器 (在项目根下运行):
  py -3.12 "Loom\Loom.py"                    打开编辑器 (默认 = LoomGUI, Qt 原生界面)
  py -3.12 "Loom\Loom.py" --ui qt            显式指定 LoomGUI (同默认)
  py -3.12 "Loom\Loom.py" --run 场景.json    直接运行一个场景(播放器)
  py -3.12 "Loom\Loom.py" --open 场景.json   编辑器打开项目场景 (LoomHub 打开项目用)
  py -3.12 "Loom\Loom.py" --benchmark        无头性能自检
  py -3.12 "Loom\Loom.py" --agent            额外启动命令桥 (EAI: 端口令牌 +
                                             命令行内部可达, 见《Loom-EAI与HUB-EAI说明书.txt》;
                                             常用搭配 --auto-close N: N 秒后自动关闭)
  (2026-08-28: 旧 pygame 即时模式视图已删除, "LoomGUI" 之名回归 Qt 原生核心视图;
  --ui default 走 guiloader 自定义 GUI 机制, --ui minimal 是极简只读第二实现)

启动 LoomHub 项目管理器:
  py -3.12 "LoomHub\LoomHub.py"               (默认 = TkHubView, tkinter 官方视图)
  py -3.12 "LoomHub\LoomHub.py" --ui tk       (显式 tkinter, 同默认)
  py -3.12 "LoomHub\LoomHub.py" --ui pygame   (旧自绘视图, 已弃用仅参考)
  功能: 解释器多版本扫描/导入/.zip安装/设默认 + 项目文件式管理 +
  用默认解释器打开项目 + 底部"命令行"区 (Hub-EAI 命令表)。
  界面换肤: 设置行"界面:"下拉可换 NovaHubGUI (星辉 Nova) / ColorHubGUI 等
  自定义视图 (重启后生效); "打开项目用 .py/.exe" 复选框 控制启动用源码还是 exe。

换用别的 Python 版本: 把 -3.12 换成目标版本号 (如 py -3.13),
  或直接写 python / python3 (用 PATH 里默认的)。
双击 Loom.py 启动: 文件头有 shebang 行 `#! python3.12`; .py 默认打开应用
  已绑定 3.12.10 解释器, 双击即用 3.12.10 运行。

本指南只讲 GUI 手工操作; 全部操作也都能用命令行完成 (编辑器 F12 打开
底部命令行坞, 或 Agent 经 --agent 驱动), 见《Loom-EAI与HUB-EAI说明书.txt》。

一、界面布局 (编辑器)
====================================================================
    ┌──────────────────────────────────────────────────────────┐
    │ 工具栏: →播放 | 场景名 | 保存/另存为/加载/新建/撤销/重做    │
    │          [移动][旋转] | 立方体/球体/平面/导入.obj/复制/删除 │
    │          Prefab名框+存模板+放实例 | 发布游戏 | 插件         │
    ├──────────┬───────────────────────────────┬──────────────┤
    │ 层级面板  │           3D 视口             │   检查器      │
    │ 顶按钮行: │        (主场景, 可旋转/平移)    │ (选中物体)   │
    │ +平行光   │        (与 Qt 检查器联动)      │ 名称/变换    │
    │ +点光源   │                               │ 材质/组件    │
    │ +摄像机   │                               │ 脚本/参数    │
    │ — 物体树 —│                               │              │
    │ — 光源 —  │                               │              │
    │ — 摄像机 —│                               │              │
    ├──────────┤                               │              │
    │ 资源面板  │                               │              │
    │ 网格/材质/│                               │              │
    │  Prefab   │                               │              │
    ├──────────┴───────────────────────────────┴──────────────┤
    │ 状态栏: FPS 对象 光源 摄像机 选中 相机距离 →播放中 [命令行][设置] │
    └──────────────────────────────────────────────────────────┘

操作一览 (Qt 界面):
  鼠标右键按住拖动 转动视角 (Unity 场景视图风格, 环绕看)
  滚轮            缩放 (往上推 = 放大/拉近, 往下滑 = 拉远)
  中键+Shift/Alt、WASD/QE  平移视角 / 方向键微调
  Alt+中键(或左键) 轨道旋转
  点选            点选物体/光源 (视口点它 或 层级列表点名字)
  Ctrl+Z / Ctrl+Y 撤销 / 重做
  Tab             循环选中物体
  0 (主键盘)      重置相机姿态 (对准目标; 2026-08-28 从空格迁移, 空格易误触)
  删除物体         工具栏 [删除] 按钮 或 层级右键菜单 → 删除
  F11             编辑器已是窗口模式 (最大化/拖边自由缩放);
                  封装后的游戏 (MyGame.exe) 里 F11 = 全屏/窗口切换
                  (无边框假全屏, 不切显示器分辨率; 再按 F11 还原)
  F12 或 状态栏[命令行]  开/关底部命令行坞 (命令操作, 见 EAI 说明书)
  退出            关窗口会弹"保存/不保存/取消"三态确认 (X/Esc = 取消)

====================================================================
二、从零搭一个场景 (布置环节)
====================================================================
1. 新建场景: 工具栏 [新建] (或直接开编辑器, 已是空场景)。
2. 加物体: **工具栏** [立方体][球体][平面] 按钮, 点一下就在场景中心加一个。
3. 移动/缩放/旋转:
   - 先点选物体(视口点它, 或层级列表点名字)。
   - 检查器数值行 = 可点击直接输入数字, 或聚焦该行后在检查器底部弹出
     拖块、按住左右拖动调值 (松手即生效, 可撤销)。
   - 或选中后拖视口的 gizmo 手柄 (工具栏 [移动]/[旋转] 切换模式;
     gizmo 只有平移/旋转两种)。
4. 加光源: 层级面板顶部按钮行 [+平行光][+点光源] (旁边还有 [＋摄像机][显隐])。
   - 平行光: 方向在检查器调 (向哪照); 选中后视口有指向线+圆锥, 光束模式有截面线框。
   - 点光源: 位置在检查器/视口 gizmo 调, 像一盏灯。
   - 没加光源时场景是暗的 —— 这是设计如此, 提醒你自己加光。
   - 检查器可调强度/颜色。
4.1 光源新控件 (M29 阴影/光束, 2026-08-12):
   - 阴影 [开/关]: 开 = 物体真实遮挡光线 (被挡区变暗)。默认开。
   - 平行光 模式 [全场景]/[光束]: 全场景=整场景平行光+遮挡(太阳);
     光束=从光源位置、垂直于光方向的截面 (圆/矩形) 发出平行光, 只照截面内。
   - 光束模式下 截面 [圆]/[矩形] + 尺寸 (圆=半径 / 矩形=半边长, 视口有截面线框可看范围)。
5. 调材质感 (M23 材质资产): 检查器 "材质" 区 = 下拉框 + 两个按钮。
   - 下拉框列场景全部材质, ✓ 标记当前材质, 下拉选别的 = 换材质 (可撤销)。
   - [＋ 新建材质]: 以当前颜色/饱和度起底建一个新材质, 自动挂到本物体。
   - [存材质为资产]: 把当前材质写进 assets/ 资源面板 (配合面板"应用到选中")。
   - 关键: 材质是"资产"—— 多个物体可以共用同一个材质(共享引用)。
     一个材质挂到多个物体后, 改这个材质的 颜色/饱和度, 几个物体一起变。
   - 想调单个物体的外观? 给它 [＋ 新建材质], 就独立了。
   - 饱和度行在材质区下方 (0=灰 1=原色 >1 更艳), 调的是"当前材质"。

5.5 碰撞体 (M28 简单物理): 检查器 "碰撞体" 区 [切换 启用/禁用]。
   - 默认: 球体 = 球形碰撞体, 其他形状 = 盒形碰撞体 (自动派生, 无需设置)。
   - [切换 启用/禁用] 让这个物体"能被挡住 / 完全穿过去"。
   - 同一棵父子树的物体之间永远不互相碰撞 (不会撞到自己的零件)。
   - 想做出"落地/反弹"效果: 选中物体, 脚本区挂 [重力落地] 或 [弹跳]。
     (见第四节: 这就是"能被物理挡住的物体"的快捷方式。)
   - 自己写脚本做物理: 脚本里调 engine.move_with_collision(物体, dx,dy,dz)
     代替直接改 position, 移动会自动被其他碰撞体挡住、防止穿透薄物体。

5.6 资源面板 (M24 资源浏览器): 左下角"资源"面板列出可复用资产。
   - 面板内容: ◆内置立方体/球体/平面 + assets/ 下的 网格资产、
     材质资产、Prefab 模板 (assets/meshes|materials/*.json, assets/*.prefab)。
   - 点选预览: 点一行, 面板底部预览条显示详情
     (材质 = 色块+名称, 网格 = 类型+参数, Prefab = 物体数)。
   - 拖进场景: 按住资产行拖到 3D 视口松开 —— 网格/Prefab 在鼠标
     指到的地面生成 (Prefab 自动贴地), 可 Ctrl+Z 撤销。
   - 拖材质: 拖材质资产到视口 = 应用到选中物体 (共享引用, 所有
     用它的物体一起变)。
   - 存资产: 选中物体后, 检查器里 [存网格为资产] / [存材质为资产],
     资产写入 assets/ 并在资源面板出现; 改完再存 = 覆盖更新 (同 guid)。
   - 不拖也行: 选中资产点底部 [放入场景] / [应用到选中] 按钮, 效果同拖放。
   - 播放期资源面板禁用 (拖放/保存被拦截)。

6. 重复 2~5.6, 摆出你的场景。层次关系: 想把 A 变成 B 的子物体?
   层级面板点 A 的名字, 按住拖到 B 上(见下"层级"小技巧)。
   **挂父/脱父那一下子物体原地不动** (世界位置自动保持, 内部按新父空间换算局部坐标);
   之后拖/转父物体, 子物体跟着一起动 (父子绑定行为)。

常用小技巧:
  - 多个物体一起动: 暂时把几个物体挂到同一个父物体下, 拖父物体。
  - 复制物体: 工具栏 [复制] 按钮, 或层级右键菜单 [复制] (可撤销)。
  - 方向搞不清: 看状态栏相机坐标, 或加一个点光源定位。
  - **层级右键菜单 (2026-08-16, 对齐 Unity)**: 在层级里对物体/光源/摄像机行点右键,
    弹出菜单——物体: 重命名/复制/删除/脱父(有父时); 光源: 重命名/删除;
    摄像机: 重命名/用此相机预览/设为激活相机/脱父(有父时)/删除。Esc 或菜单外点击关闭。
  - **单击挂父行绝不脱父** (2026-08-16): 单击(不拖动)只选中; 想脱父 = 把行**拖到空白处**
    松开, 或行上右键菜单选"脱父"。

====================================================================
三、保存 / 加载 / 撤销
====================================================================
  [保存]  有对应文件直接存 (不弹框); 从未保存过 = 弹"另存为"对话框。
  [另存为] 总是弹框选位置保存。
  [加载]  打开的 .json 场景。
  [新建]  清空当前场景 (有未保存改动会先弹三态确认)。
  Ctrl+Z  撤销上一步 (改位置/加物体/加光/挂脚本全都能撤)。
  Ctrl+Y  重做。
  撤销可回退到 100 步, 放心大胆操作。

  退出确认 (2026-08-22 A01): 场景有未保存改动时, 关窗口/加载/新建都会弹
  [保存][不保存][取消] 三态框 —— 点弹框右上角 X / Esc = 取消, 回到编辑器;
  [保存] 成功后继续, [不保存] 丢弃改动继续, [取消] 中止当前操作。

  工具栏 "Prefab 名框 + [存模板] + [放实例]":
  [存模板] 把选中物体(含子树)存成可复用模板 .prefab (用前缀名框里的名字)。
  [放实例] 把一个 .prefab 模板放进场景 (新实例)。
  改 Prefab 不影响已放实例, 重新放实例才是新样子;
  检查器里 [与 Prefab 断开连接] 让实例不再跟模板更新。

====================================================================
四、给物体挂脚本 (行为环节 —— 让东西动起来)
====================================================================
1. 选中一个物体, 检查器滚动到 "脚本" 区。
2. 点一个脚本名, 物体就挂上了 (M25: 一个物体可挂多个脚本)。
   - 自转      物体绕自身旋转 (参数: X/Y/Z 度每秒)
   - 公转      绕场景中心点转圈 (参数: 速度)
   - 浮动      上下正弦浮动 (参数: 幅度/频率)
   - WASD移动  按 W/A/S/D 沿世界轴移动 (参数: 速度) —— 供试玩操作
   - 相机跟随  相机始终盯着这个物体 (参数: 高度偏移)
   - 重力落地  受重力下落, 碰到下面有碰撞体的地面/物体就停下 (参数: 重力g)
   - 弹跳      重力下落 + 触地反弹 (参数: 重力g / 弹性rest 0~1)
3. 脚本参数: 挂上后每个脚本下面出现自己的参数条, 拖数值即可调。
4. 去掉脚本: 点脚本那行的 ✕。
5. 挂多个脚本: 重复点其他脚本名即可 ("自转+浮动"直接一个物体搞定)。
6. 改脚本参数就是实时行为调优: 挂上 -> 按播放 -> 边看边拖参数。
7. 想写"碰到就动/反弹/触发"的新脚本: 脚本里用
     engine.get_collisions(物体)      查询当前和谁重叠
     engine.move_with_collision(物体, dx,dy,dz)  带碰撞地移动 (会被挡住)
     (见《代码架构.txt》碰撞系统一节)

内置脚本已满足基础演示。想要全新行为 (比如按空格跳、碰到就停):
  改 scripts.py 里加一个类, 用 @register 注册即可(见《代码架构.txt》),
  保存后编辑器里立刻能用 —— 不用重编译, 这是 Python 引擎的优势。

====================================================================
五、按播放试玩 (试玩验证环节)
====================================================================
工具栏最左侧 [→播放] 按钮 (播放中文字变 [■停止]):
  - 按播放: 编辑器进入"游戏模式", 场景里的脚本开始跑,
            你可以用 WASD/方向键操作挂 WASD移动 的物体。
  - 按停止: 场景自动还原成编辑时样子 —— 你在播放期乱跑乱撞的
            改动全部丢弃, 不会弄脏你摆的场景。
  - 播放期检查器只显示"→ 播放中", 编辑操作被禁用。

这就是"所见即所得"闭环:
  摆好 -> 挂脚本 -> 按播放 -> 看效果 -> 停 -> 调参数 -> 再播放。
  全程不用退出编辑器, 迭代最快。

小例子 (30 秒试玩):
  1. [立方体] 一个, 位置 (0,0,0)。
  2. 检查器挂 WASD移动, 速度设 3。
  3. [点光源] 一个, 放高处 (0,5,0) 照下来。
  4. [→播放] -> 按 W/A/S/D 移动立方体, 感觉手感。
  5. [■停止] -> 立方体回到原位。改速度再试。

碰撞小例子 (看物理):
  1. [平面] 一个 (当底板, 位置 (0,-2,0)) + [球体] 一个, 位置 (0,2,0)。
  2. 球体检查器脚本区挂 [弹跳], 弹性设 0.8。
  3. [→播放] -> 球落到底板, 弹起来又落下, 越弹越低最后停住。
  4. [■停止] -> 球回到原位。试试把底板的碰撞体 [切换 禁用] -> 球直接穿过去。

====================================================================
六、相机操作脚本 (做"跟随视角"小游戏)
====================================================================
想做"第三人称跟着角色走"的效果:
  1. 角色物体挂 WASD移动。
  2. 同一个物体再挂 相机跟随 (偏移高度设 3, 距离设 8)。
  3. [→播放] -> WASD 走动, 相机自动跟着转/拉近。
停播后视角还原。

注: 相机跟随是"目标跟随", 视角朝向仍可用鼠标转; 想完全锁定
就少用鼠标。简单追逐/演示够用了。

====================================================================
六·四、摄像机 (Unity Camera) —— 玩家视角由摄像机决定 (2026-08-11)
====================================================================
场景里的"摄像机"实体决定玩家看到什么视角。一个场景可放多个摄像机
(自动编号), 哪个是当前玩家视角由场景的 active_camera 决定,
播放/运行时玩家看到的就是它。这是"创建多个摄像机对象、编号并切换
玩家看到的视角"的实现方式。

层级面板"— 摄像机 —"区:
  - 添加: 层级面板顶部按钮行 [+摄像机] (默认在 (0,1,-5), 朝向原点)。
  - 点行选中; 删除 = 层级右键菜单 [删除] 或工具栏 [删除] (可撤销)。
  - **相机物体化 (2026-08-16): 摄像机可挂到普通物体上** (如玩家/车辆):
    把摄像机行**拖到物体行上松开 = 挂父** (相机跟随父物体, 树形缩进显示);
    把摄像机行**拖到层级空白处松开 = 脱父** (回到根);
    保存/加载自动保留父关系。挂父后的摄像机, 其图标、"用此相机预览"、
    设为激活相机的播放视角都会**随父物体移动** (第一人称做法: 把相机挂到玩家上)。
检查器 (选中摄像机后):
  - 位置: 数值行点击输入或聚焦弹出拖块拖动, 或**直接在视口拖平移 gizmo**
    (同光源定位点, 旋转不支持)。
  - 朝向 yaw/pitch/roll (度): 数值行即调 (2026-08-16 M41 改度制)——
    yaw 拖过 360° 会环绕归零; roll 是**倾斜** (绕视线自旋, FPS 侧头/被击倒歪斜用),
    调 roll 时朝向线**中点会出现一个 1/4 大小黄色小箭头**指向倾斜方向。
  - 视角广度 FOV (度): 数值行即调。
  - 玩家可调视角广度: [玩家锁定] / [✓ 玩家可调] —— 是否允许玩家运行时改视角广度。
  - 俯仰角限制 (M41): [启用俯仰角限制] 后设 [最低俯角] / [最高仰角] (度), 玩家可调
    俯仰被夹在 [俯角, 仰角] 含两端; 输入俯角>仰角 (交集为空) 会被拒绝并提示。
  - [用此相机预览]: 编辑器视口切到这台相机的视角看效果, 再点按钮或按 Esc 退回轨道视角。
  - [设为激活相机]: 设为场景 active_camera, 播放时自动从这台相机的视角观看。

播放/运行时: 用场景 active_camera 作为玩家视角 (位置/朝向/FOV 全用它);
  没有摄像机就用默认轨道视角。想切换视角, 改 active_camera 指向哪台即可。
退出播放: 干净还原编辑器轨道视角 (玩家摄像机不污染编辑视角)。

视口外观 (光源/摄像机专属): 图标始终朝向玩家 (billboard), 大小随
  距离缩放 (近大远小); 选中的摄像机显示一根视角线 (沿朝向, 世界长度固定)。
开发端视角操作: **按住鼠标右键拖动 = 转动视角** (Unity 场景视图风格);
  中键+Shift/Alt = 平移, 滚轮 = 缩放, WASD/QE = 平移目标点, 方向键 = 微调。

图像素材: Loom\assets\图像素材\ 下有 light_directional.png / light_point.png /
  camera.png / logo.png / ground.png / character.png 空白占位图,
  可以自己画图替换 (当前视口图标用色块渲染, 素材留作后续 UI 使用)。

六·五、LoomHub 项目管理器 (Unity Hub 角色, 2026-08-11)
====================================================================
LoomHub = 项目管理器 ("解释器名 + Hub", 类似 Unity -> Unity Hub)。
它把"项目管理"从解释器里分离: 解释器只管编辑/运行, LoomHub 管
项目列表、启动项目、解释器(编辑器)多版本管理。

启动:  py -3.12 "LoomHub\LoomHub.py"   (默认 = TkHubView tkinter 官方视图)

界面 (左=解释器, 右=项目):
  左侧 [解释器] 面板:
    - 扫描 Program Files: 扫 C:\Program Files\Loom\<版本号> 多版本目录,
      按版本目录逐个分析 (读版本目录里的 解释器.json: 版本/主程序名),
      已装解释器登记到 interpreters.json。第一次运行先点它。
    - 导入目录: 手动选一个解释器目录 (含 解释器.json) 登记 (.py 源码或
      .exe 封装都支持, 主程序按 解释器.json 里的 main/main_exe 定位).
    - 安装 .zip: 选解释器安装包 (.zip) + 输入版本号, 解压到
      安装根\<版本号> (默认 C:\Program Files\Loom\, 可 [改安装根])。
      装完自动登记。远程下载安装接口已预留 (暂未开放)。
    - 列表点选一个解释器, [设为默认] / [移除]。
  右侧 [项目] 面板:
    - 新建项目: 点 [新建项目] 弹"另存"对话框选场景文件位置 ->
      生成空场景文件并登记 (项目 = 场景文件, 文件式管理)。
    - 导入项目: 选一个目录 (内含 场景_场景.json 或 *.json) 登记;
      双击项目行 = 直接用默认解释器打开编辑器。
    - 打开项目: 用默认解释器启动编辑器加载该项目场景 (--open);
      用 .py 源码还是 .exe 启动, 由设置行 "打开项目用 .py/.exe" 决定。
    - 移除: 从列表移除 (不删磁盘文件)。
  底部设置行: "界面:" 下拉 (TkHubView/NovaHubGUI 星辉 Nova/ColorHubGUI 绿意等,
    重启后生效) + "打开项目用 .py/.exe" 复选框 + "默认解释器: ..." 状态行。
  底部 [命令行] 区 (2026-08-27): 输入 Hub-EAI 命令直接执行
    (如 interpreter_list / project_list / status; 空行回车 = 帮助清单),
    与远程 Agent 调用同一条命令表, 见《Loom-EAI与HUB-EAI说明书.txt》。

配置文件 (LoomHub\ 目录, 都是 JSON 可手改):
  interpreters.json   解释器列表 {name,version,kind,dir,main,path,default}
  projects.json       项目列表 {name,scene,version}

七、用 exe 版引擎制作游戏并封装发布 (标准流程, 2026-08-22)
====================================================================
整个链路 (Unity: 材质/场景/脚本 → 编辑器 → Build → 玩家 exe):
    场景+物体+脚本(游戏材料) → Loom.exe 编辑器 → [发布游戏]
    → 发布夹 = MyGame.exe(玩家运行时, 无编辑器) + 游戏包.lsc
      (场景+游戏脚本+配置混淆打包, 与 exe 同夹不可分离) → 玩家双击即玩
★ 标准要求 (为什么这样设计):
  - 玩家 exe 不含编辑器 (游戏_player 只带运行时, 玩家看不到场景内部);
  - 场景/脚本没有明文 (游戏包.lsc = LOOMSC1 混淆打包, 同 Unity _Data 里
    的二进制资源/编译 DLL: 玩家拿不到源码);
  - 发布夹两件套同夹不可分离 (缺游戏包.lsc = _Data 缺失, 启动报错);
  - 游戏包由"构建器"生成 —— 玩家运行时 exe 只需打包一次, 每次发布
    秒级完成 (Unity 每次 Build 也是拷贝资产+打包场景, 同语义)。

1. 目录与材料准备 (全部在 Loom 引擎目录 或 你选的项目目录):
  Loom.exe                    编辑器 (制作游戏)
  build_game.exe              构建器 (命令行/CI 用; 编辑器 [发布游戏] 也调它)
  scripts\                    游戏脚本目录 (自建: 每个 .py 放着就自动加载注册,
                              检查器"脚本"区可挂; 发布时被收集加密打包)
  plugins\                    插件目录 (编辑器扩展/脚本注册, 发布时同样收集)
  (场景 .json 明文存在哪里都行, 发布构建时读入加密打包)

2. 制作游戏 (全程双击 Loom.exe 即用, 不碰源码):
  a. LoomHub 打开项目 或 Loom.exe 直接 [新建] → 摆场景 (见本指南第二~六节:
     物体/光源/摄像机/材质/刚体/内置脚本)。
  b. 游戏脚本目录 scripts\ 放你自己的 .py (如 reset_fall.py 示例),
     存盘后编辑器检查器"脚本"区立刻能挂 (Python 热加载)。
  c. [→播放] 试玩 → [■停止] 还原 → 调 → 保存 (Ctrl+S; 场景明文留着,
     发布时才加密 -- 开发期要能继续编辑)。

3. 发布 (二选一):
  A. 编辑器一键: 工具栏 [发布游戏] → 打开 "发布游戏 (Build Settings)" 对话框,
     填 游戏名/公司名/窗口标题/启动场景/脚本目录/输出目录 → [构建] →
     完成自动打开发布夹。
  B. 命令行 (CI 也可):
     build_game.exe --name 我的游戏 --company 工作室 --scene 场景.json \
         --game-scripts scripts --output D:\游戏发布 --force
     首次/引擎更新时先打玩家运行时 (build_game.exe --build-runtime)。

4. 发布夹 (拷给玩家 = 整夹):
  MyGame.exe     玩家运行时 (无编辑器; 只读游戏包)
  游戏包.lsc     场景+游戏脚本+配置, 混淆加密 (无明文)
  (素材如 obj/音频: 引用相对路径时整夹一起放 -- streaming assets 语义)
  玩家双击 MyGame.exe 即进游戏; 缺 游戏包.lsc 启动即报提示。

5. 玩家操作: WASD/鼠标视角 (第一/三人称控制器), 空格跳跃, Tab 鼠标锁定
   切换, F11 全屏 (无边框假全屏), 关闭窗口退出。

6. 定向测试建议 (验证封装环节):
  a. 拿"跳台试炼"示例游戏 (见《制作游戏完整流程教学.txt》配套): 材料 =
     明文场景(或 Loom.exe 里现做)+ scripts\reset_fall.py;
  b. build_game.exe 构建 → 检查发布夹: 应只有 MyGame.exe+游戏包.lsc (+素材),
     **无任何 .py/.json 明文**;
  c. 双击 MyGame.exe 玩 10 秒 (WASD/跳/碰彩球 HUD 计数); 跌出世界玩家
     自动回出生点 (reset_fall 脚本在包里运行 = 脚本加密包有效);
  d. 把 游戏包.lsc 改名 → 双击 → 应报"缺少游戏包"而不是静默黑屏;
  e. 试着改 Loom.exe 旁 游戏包.lsc / 与其同目录混淆文件——注意玩家发布夹
     需独立目录 (别和 Loom.exe 放一起, 见下方"注意")。

7. 注意:
  - 玩家发布夹单独目录。build_entry 打包的 Loom.exe 旁若有 游戏配置.json
    会被当玩家启动 (Unity Build 语义), 发布夹别与 Loom.exe 同夹;
  - 游戏脚本收集范围 = 构建时 --game-scripts 指定的目录 (默认 Loom 目录
    scripts\)+ 场景挂载的所有脚本; 自定义脚本请放这, 别改内置 scripts.py;
  - exe 图标/多场景构建 v1 未做 (限制)。

九、常见问题 (FAQ)
====================================================================
Q: 场景全是暗的?
   A: 没加光源。层级面板 "— 光源 —" 区加 [平行光]。
Q: 物体点不中 / gizmo 拖不动?
   A: 确认选中了它(层级面板名字高亮), 再在视口拖。
Q: 播放时按 WASD 没反应?
   A: 检查那个物体是否挂了 WASD移动 脚本 (检查器脚本区 ✓)。
      注意 WASD 是"世界轴"移动, 不受相机朝向影响。
Q: 播放完物体位置变了, 还原不回去?
   A: 正常现象不该发生。若出现, 是 bug —— 确认停的是 [■停止] 按钮;
      播放期乱改不会弄脏你的场景。关窗口会弹"保存/不保存/取消"三态
      确认 (保存=存盘再关 / 不保存=丢弃改动 / 取消=X/Esc 中止退出)。
Q: 挂脚本时提示脚本出错?
   A: 脚本抛异常会打印在控制台并自动禁用该脚本(标记坏脚本),
      其他物体不受影响。把控制台报错截图发给开发者。
Q: 如何让别人也能打开我的场景?
   A: 把 .json 场景文件 + exe(或源码文件夹)一起给, 用 --run 运行。
Q: 修改颜色后场景变灰/发白?
   A: 饱和度往低调(0 是灰白), 颜色三通道调到你想要的色。
      发白大概率是光源太强或没加光被压暗, 调强度/加光即可。
Q: 球/物体直接穿过地面或互相穿过, 没有物理?
   A: (1) 目标物体的"碰撞体"是否被禁用了 (检查器碰撞体区切换启用);
      (2) 地面默认有盒形碰撞体, 除非你切换禁用了它;
      (3) 自己写脚本时要用 move_with_collision 代替直接改 position,
          直接改 position 是"瞬移", 不参与碰撞 (物理只挡带碰撞的移动)。
Q: 挂了 重力落地 却没落下去?
   A: 确认下面有个物体(比如平面)没被禁用碰撞体, 而且它不在同一棵
      父子树下 (同树物体不互相碰撞是设计如此)。

十·五、本次新增功能 (2026-08-12, M30b~M39 补全)
====================================================================
这次补全了从"摆场景"到"封装玩家游戏"的完整能力, 全部已打包进 Loom.exe。

[1] 输入动作层 + 键位重映射 (Unity Input System 理念)
  - 脚本用 engine.get_action('向前'/'向后'/'向左'/'向右'/'跳跃'/'交互')
    代替 is_key('w') —— 动作是"玩家想干嘛", 不是某个键。
  - 键位可重映射: 引擎目录/游戏目录旁 `输入配置.json` 里改
    {"actions": {"跳跃": ["space","j"], ...}}, 改键不动脚本。

[2] 刚体 + 碰撞事件 (Unity Rigidbody 理念)
  - 检查器"刚体"区 [加刚体]: 物体受重力下落, 碰到碰撞体停住。
  - 脚本可写 on_collision_start(other) / on_collision_end(other)
    (Unity OnCollisionEnter/Exit), 做"碰到就加分/消失/触发"。

[3] 玩家控制器 (第一/第三人称 + 跳跃)
  - 检查器"脚本"区挂 [第一人称] 或 [第三人称]:
    WASD 移动 + 鼠标转视角 + 空格跳跃 (需加刚体受重力)。
  - 播放/运行时鼠标默认锁定(隐藏+捕获), 按 **Tab** 释放(显示鼠标,
    滑动不转视角), 再按 Tab 回锁; 特殊场景(UI 菜单)自动回锁。

[4] 运行时 UI (Unity uGUI 简化)
  - 脚本里 engine.ui.text('得分: 100', x, y) / ui.button(id, rect, '开始')
    / ui.bar(rect, 0.7) —— 游戏内 HUD(分数/生命/菜单), 运行时显示。

[5] 音频 (Unity AudioSource 理念)
  - 检查器"音频"区 [加音频源], 填音频文件路径(.wav/.ogg), 设循环/音量,
    播放/停止; 脚本 engine.audio.play_sound('coin.wav') 一次性音效。

[6] 动画 (Unity AnimationClip 理念)
  - 检查器"动画"区 [加动画组件], 脚本 obj.animator.play('跳') 播放关键帧
    动画 (关键帧: 位置/旋转/缩放随时间插值)。

[7] 模型导入 (obj)
  - 工具栏 [导入.obj] 选 Wavefront .obj 文件 → 网格放入场景。
  - 场景保存时记录 obj 路径, 加载时重读 (文件失效兜底立方体)。

[8] 多场景/场景切换
  - 脚本 engine.load_scene('关卡2.json') 运行时换场景 (菜单→游戏关卡)。

[9] 游戏封装 (Unity Build 模型, 玩家双击即玩)
  - 已编译的 Loom.exe 双击: 若 exe 旁有 `游戏配置.json` ({"scene": "游戏场景.json"})
    则直接进游戏(播放器, 无编辑器); 没有则打开编辑器。
  - 场景可加密: sceneio.save_scene_data(path, data, encrypt=True) 生成
    LOOMSC 混淆场景, 播放器自动解密加载 (玩家不可直接读场景)。
  - 游戏专属脚本: 放 exe 旁 `scripts/` 目录的 .py, 运行时自动加载注册,
    检查器可挂, 随游戏分发 (Unity 项目脚本机制)。
  - 纯玩家 exe: 打包 game_player.py (只含运行时不含编辑器), 玩家拿到
    exe + 游戏配置.json + 场景 + scripts/ 即可双击玩。

[10] 播放器不再显示调试 HUD
  - 玩家运行时只显示游戏自己的 UI (engine.ui), 不再显示相机坐标/FPS 等
    引擎调试信息 (那些只在编辑器里显示)。

====================================================================
十·六、插件 (2026-08-20, L1 插件加载器 —— 一切皆插件, 放目录即用)
====================================================================
想给 Loom 加功能 (新脚本/菜单/面板/导入器……), 不用改引擎源码:
在程序目录的 plugins\ 文件夹放一个插件目录即可, **放进即装, 删掉即卸载**。

插件目录结构 (两个文件起):
  plugins\我的插件\
      plugin.json   {"id": "com.xxx.my_plugin", "name": "插件名",
                     "version": "0.1.0", "entry": "entry.py"}
      entry.py      def register(api): ...   ← 插件入口钩子
                    (例: api.register_script(MyScript) 注册一个脚本,
                    检查器就能挂 —— 和内置脚本一样用)

规则 (坏插件不拖垮引擎, 自动回退官方):
  - 清单缺字段/格式错/入口文件不存在/需要更新的引擎版本 → 该插件跳过, 启动时打印原因;
  - entry.py 抛异常 → 该插件禁用, 其余插件照常;
  - 想卸载 = 删掉整个插件目录, 官方功能自动恢复。

设置对话框里有"插件"挂载区 (2026-08-20):
  - 每个插件一行: 状态 (● 已加载 / ○ 未加载 / × 有问题+原因) + id + 名称 + 版本,
    行尾 [加载][卸载] 两个按钮;
  - 点 [卸载] = 立即卸载 (该插件脚本从检查器消失, 其他插件不受影响);
    卸载是"会话级禁用"——重启后自动恢复; 想永久移除 = 删掉插件目录;
  - 点 [加载] = 立即恢复加载;
  - [重新扫描] = 加载 plugins\ 新增的插件、清掉目录已删除的插件。

写插件: 在 plugins\<id>\ 放 plugin.json (id/name/version/entry) + entry.py
(模块级 register(api) 钩子, api.register_script 注册脚本)。
示例插件 2026-08-21 已从发布移除 (用户指示: 测试用插件影响后续开发);
插件规范详见《Loom模块化插件化分析.txt》L1 节。

帧缓冲实验开关 (2026-09-06, 设置面板)
====================================================================
设置面板提供两个实验开关 (默认关):
- TPS 缓冲: 空闲时提前算好下一逻辑帧 (最多 2 帧), 尖峰帧到点取成品,
  保 TPS 节律稳定。要求: 逻辑帧率 >= 30 (低帧率缓冲延迟过大, 灰置)。
- FPS 缓冲: 限帧等待空窗内把下一渲染帧预画进离屏缓冲, 到点直接上屏。
  要求: 帧率上限 >= 60 且非无上限/自动 (无上限画一帧显一帧, 无节拍可缓冲)。
两个开关独立 (射击类=低TPS高FPS 可只开 FPS 侧; 3A 类=高TPS低FPS 只开 TPS 侧)。
关闭时行为与旧版完全一致, TPS 照常实测。低帧率档位/逻辑帧率不达标时
复选框灰置并提示要求。命令行观测: engine_metrics 查看 frame_buffer /
render_buffer 命中数。逃生门: LOOM_NO_FRAMEBUF=1 环境变量强制关闭。
